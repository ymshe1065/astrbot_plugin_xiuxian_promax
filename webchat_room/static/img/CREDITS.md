## 处理方式

原图 640×640、白底，人物左右与下方均贴出画布。处理步骤：

1. 以 `(320, 330)` 为圆心、半径 `318` 做圆形遮罩，避开原图的直线切边；
2. 缩放至 `320×320`，保留透明通道（圆外透明）；
3. 页面按 `border-radius: 50%` + `background-size: 100%` 使用，白描边与淡蓝光环由 CSS 提供。

## 替换方式

把图片放进本目录，改 `app.css` 里 5 处 `url("/static/img/whale_logo.png")` 与 `app.js` 的 `FAVICON.fish` 即可。
若原图非正方形，先按需要裁成正方形，否则圆形遮罩会切偏。
