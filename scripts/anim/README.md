# 顶部场景条 · 角色动画生成器

网页聊天室顶栏那条横版像素场景，是**用代码生成**的，不是图片资源。整个场景条
（七个场景、七套角色动作）在页面里是约 100 KB 的单文件 HTML，零外部请求。

角色形象来自 PixelLab 生成的像素小人，动作帧由本目录的脚本**按姿态程序化补出来**，
不依赖 PixelLab 的付费动画功能。

## 目录

```
scripts/anim/
├── pose.py            底层像素工具：bob / hem_swing / line / b64
├── rig.py             分层 rig：按行重采样 warp、倾斜函数、调色板
├── acts.py            ★ 动作生成器，产出 gen/_acts.js
├── build_demo.py      生成 webchat_room/static/anim/acts.html（动作查看器）
├── sync_preview.py    把动作数据注入 webchat_room/static/anim/preview.html
├── assets/
│   ├── east_stand_32x48.png   PixelLab 站立（角色占 y=8~44）
│   └── east_sit_32x32.png     PixelLab 跪坐（贴到 y=13 起）
└── previews/
    ├── scenes_7.png           七场景总览
    └── actions_sheet.png      七套动作逐帧总览
```

## 跑一遍

```bash
python scripts/anim/acts.py           # 生成 gen/_acts.js
python scripts/anim/build_demo.py     # 生成 static/anim/acts.html
python scripts/anim/sync_preview.py   # 把新帧注入 preview.html
```

改完 `acts.py` 后 **必须跑 `sync_preview.py`**，否则 `preview.html` 里还是旧帧——
它是单文件、数据内联的，不会自己去读 `gen/`。

`python scripts/anim/build_demo.py --shots` 会额外逐帧截图拼成 `gen/grid_acts.png`。
静态定格看帧比在页面里盯着看更容易发现问题，这一轮改动作全靠它。

## 画布与坐标系

```
48 × 48，角色中心 x=24，脚底对齐 y=44
头部 y=8~21（PixelLab 原图裁切，保脸）
颈 y=22，腰 y=33，脚 y=42~44
```

画布从 32 加宽到 48 是必须的：14px 长的剑在 32 宽画布里会被裁掉半截。

## 七套动作

| 动作 | 帧 | fps | 表达方式 | 对应场景 |
|---|---|---|---|---|
| idle | 4 | 5 | 1px 上下起伏 | 兜底 |
| walk | 8 | 10 | 袍摆摆动 + 脚左右平移 | 旷野、秘境 |
| float | 6 | 8 | 跪坐 -12px + 三团云气 + 环绕光点 | 云台闭关 |
| alchemy | 6 | 7 | 前倾 + 青铜三足鼎 + 跳动火焰 + 药气 | 丹房 |
| slash | 6 | 12 | 前冲 + 悬浮剑 + 极坐标剑气弧 | 断魂崖 Boss |
| look | 6 | 5 | **头部水平镜像**（转头） | 百宝阁、坊市 |
| cast | 7 | 8 | 脚下法阵 + 掌前光球上升 | 静室 |

帧数参照 LPC（Liberated Pixel Cup）标准：idle 2 / walk 8 / slash 6 / cast 7 / sit 3。

## 三条走过并且否掉的路线

记在这里是为了避免以后又走一遍。

1. **纯仿射变换**（整图倾斜、上下浮动）：轮廓不变，看着像僵在原地晃。试到第 5 版仍然不行。
2. **从头程序化重画身体**：没有腰、没有脚、变成钟形，把 PixelLab 画的褶皱和明暗全丢了。
3. **在 32px 上画手臂**：空间不够，手臂必然是一个方块；而且从肩点出发会和躯干脱节，
   放大 16 倍看，袖子和身体之间是断的。

## 最后采用的做法

**原图按行重采样做形变（保住内部细节），动作靠道具和特效表达，不做手臂。**

- 身体：`rig.warp()` 逐行扫描 x 范围，横向缩放 + 偏移；褶皱和 1px 描边原样保留
- 道具：青铜鼎、悬浮剑、拱形云团——这类物件在低分辨率下有明确剪影
- 特效：极坐标剑气弧、脚下法阵、环绕光点

修仙题材本来就该用御剑、剑气、法阵、丹火说话，不画手臂反而更贴题。

## 踩过的坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 剑被裁掉半截 | 画布只有 32 宽 | 加宽到 48 |
| 张望完全看不出动 | 平移 1px 在 32px 尺度上不可见 | 改头部水平镜像 |
| 走路像原地收缩 | `hem_swing` 里乘了 `(x-16)/7`，越靠边位移越小 | 改成整体平移 |
| 云气在白云海上消失 | 白色叠白色 | 云底加 1~2px 深色轮廓 |
| 法阵在浅地板上看不见 | 没有对比度 | 每个点下方加 1px 深色 |
| 炼丹出现两个炉子 | 场景自带一个，角色又带一个 | 删掉场景里那个 |

## 已知不足

- `walk` 单帧看幅度偏小，靠 8fps + 背景滚动才有跑动感
- `alchemy` 的炉子会挡住角色下半身，有点像抱着炉子
- `slash` 剑位偏高，读感是「举剑过头」而不是横斩
- 秘境场景 `dim 0.74` 让角色几乎融进背景
- 坊市、器阁两个场景还没建，目前只有百宝阁
