# 模拟修仙 v6.15 知识库（修订版）

> 适用：AstrBot 插件 `astrbot_plugin_xiuxian_promax`（模拟修仙 v6.15 修订版）
> 用途：给 AI 问答/群聊机器人做知识库，回答玩家关于玩法、指令、规则的问题。
> 说明：数值以游戏内实际显示和插件配置为准；本文只写稳定规则，不写版本更新日志和开发细节。
> 本次修订已同步：世界 Boss、宗门等级/建筑/命令/大比/战争/解散、宗门贡献商店、黑市每小时刷新、贷款部分还款/持有门槛、弃道重修清理、功法效果、境界闭关收益。

## 1. 游戏简介

「模拟修仙」是一个运行在 QQ 群里的放置类文字修仙游戏。玩家在群聊中发送指令，创建角色、闭关修炼、突破境界、加入宗门、炼丹炼器、下秘境、押镖、参与全服 Boss 和魔潮活动，最终飞升转生。

核心循环：

```text
创建角色 → 签到/闭关积累修为 → 突破境界 → 做日常/历练/秘境拿资源
→ 提升装备、丹药、灵兽、宗门 → 挑战世界 Boss / 参与魔潮 → 飞升转生
```

游戏是**按 QQ 号单独存档**的：同一个群里，每个人有自己的角色、境界、灵石和状态，互不共享。

## 2. 快速上手

```text
/我要修仙 剑修     创建角色，选择职业
/签到              每日签到，领灵石和节日福利
/我的信息          查看角色面板（通常附带图片卡片）
/闭关              开始挂机修炼
/出关              结束闭关，结算修为
/修仙帮助          查看完整指令
```

新手创建角色后会获得启动资金和新手引导奖励。之后每天至少做：

```text
/签到
/洞天收取
/收获
/领取利息
/灵眼收取
```

也可以发 `/一键日常`，它会提示你依次完成这些操作。

## 3. 职业与开局

创建角色时可选职业：

| 职业 | 定位 |
| --- | --- |
| 灵修 | 均衡型，灵气/法术路线 |
| 体修 | 高气血、高物伤，突破失败风险更高 |
| 魔修 | 吸血、爆发 |
| 剑修 | 极致物理输出 |
| 鬼修 | 诡道、持续伤害方向 |
| 佛修 | 反伤、肉盾 |
| 御兽 | 依赖灵兽协同作战 |

开局还会随机灵根（如土灵根、单灵根等），灵根影响修炼倍率。职业和灵根在角色创建时确定，后续可通过「弃道重修」重来。

## 4. 核心数值

| 数值 | 作用 |
| --- | --- |
| 修为 | 突破境界的基础，闭关、历练、秘境、丹药等获得 |
| 灵石 | 通用货币，商店、银行、坊市、强化、炼丹等使用 |
| 境界 | 角色成长阶段，决定属性、可去路线、可买物品 |
| 气血/法力 | 战斗中的生命和法力 |
| 物伤/法伤 | 物理与法术攻击 |
| 物防/法防 | 物理与法术减伤 |
| 精神力 | 部分系统和战斗判定使用 |
| 功德/业力 | 影响突破成功率和奇遇概率 |
| 仙缘点 | 飞升/长期系统兑换永久加成 |

### 突破

```text
/突破信息          查看当前突破所需修为、成功率和资费
/突破 [破境丹名]   尝试突破，可带破境丹提高成功率
```

- 突破需要修为，并消耗灵石资费；失败通常也会扣资费。
- 体修突破失败可能死亡，风险更高。
- 功德/业力会修正突破成功率，有上下限。
- 破境丹可以提升成功率；无效或不适用的破境丹不应被消耗。

### 功德与业力

- 行善、救人、做好事会增加功德；偷窃、劫镖、恶行会增加业力。
- 功德提高突破成功率和奇遇触发概率；业力降低突破成功率。
- `/行善` 每天可捐灵石增加功德。

## 5. 修炼与状态

### 闭关

```text
/闭关    进入闭关，开始按时间积累修为
/出关    结束闭关，结算修为
```

闭关收益受灵根、功法、丹药、洞天家具、宗门藏经阁、魔潮、化身等影响。**境界越高，闭关修为收益越高**：默认每提升 1 个境界等级，基础收益 +10%（配置项 `VALUES.LEVEL_EXP_BONUS_PER_LEVEL`，默认 0.10）。这里的“收益”指修为，不是战斗中的灵气。

闭关期间角色处于「闭关中」，大部分会改变状态的操作会被拒绝，但可以查看信息、签到、收菜、领奖。

### 功法效果

- 主修心法和已装备的普通功法都会提供效果；
- 暴击率、暴击伤害、吸血、反伤、连击、额外防御、物伤/法伤倍率都会进入战斗计算；
- 功法的 `exp_multiplier` 会计入闭关修为倍率；
- 「金刚不坏体」的 `defense_bonus` 会加到防御上；
- 暴击伤害目前是加法叠加，例如基础 1.5 + 功法 1.5 = 3.0，实际可能达到 300% 暴击伤害。

### 忙碌状态

游戏里常见忙碌状态：

```text
闭关中、历练中、探索秘境中、宗门任务中、押镖中、渡劫中、掠夺中、宗门大比中
```

忙碌时：

- 可以执行查询、签到、收菜、领奖、排行榜等基础指令；
- 不能开始另一项会占用状态的活动；
- 必须先用对应的退出/完成指令结束当前状态，或用 `/解卡` 强制重置。

### 解卡

```text
/解卡
```

强制把角色恢复为空闲，放弃当前闭关/历练/秘境/宗门任务/押镖等进度，不发放奖励。角色卡住、找不到退出指令时使用。

## 6. 主要玩法系统

### 6.1 签到与日常

```text
/签到        每日签到；修仙节日（如蟠桃会）有额外福利
/一键日常    提示签到、洞天收取、灵田收获、领取利息、灵眼收取
```

签到按自然日计算，每天一次。

### 6.2 商店

```text
/丹阁        丹药商店
/器阁        装备/法器商店
/百宝阁      稀有物品商店
/购买 <物品名> [数量]
/物品信息 <名称>
```

商店商品会随机刷新，有随机折扣和库存。部分天阶物品有境界门槛，低境界买不了。

黑市：

```text
/黑市              查看当前小时的黑市商品
/黑市购买 <编号>   购买盲盒商品
```

- 黑市**每小时刷新**，同一小时展示与购买一致；
- 每次展示 3 件商品，可能是真实物品，也可能是假货；
- 真实物品会显示品阶、类型、效果和黑市价；
- 假货会扣灵石并伤气血，不发放物品；
- 真实物品购买失败（如储物戒满）会退回灵石，不会产生无法使用的“幽灵物品”；
- 旧版本已经产生的黑市幽灵物品，会在插件启动时清理，并按旧价退还灵石。

### 6.3 银行

```text
/银行
/存灵石 <数量>
/取灵石 <数量>
/领取利息
/贷款 <金额>
/突破贷款 <金额>
/还款 [金额]
/银行流水
```

- 存款按日复利，利率约 0.1%/天。
- 普通贷款日利率约 0.5%，期限 7 天；突破贷款日利率约 0.8%，期限 3 天。
- 大额贷款有持有门槛：贷款金额超过 10,000 时，需要至少持有贷款金额的 20%，最低 5,000。持有金额 = 身上灵石 + 银行存款。

| 贷款金额 | 最低持有 |
| ---: | ---: |
| 10,000 以下 | 0 |
| 20,000 | 5,000 |
| 50,000 | 10,000 |
| 100,000 | 20,000 |
| 500,000 | 100,000 |
| 1,000,000 | 200,000 |

### 还款方式

```text
/还款          一次性还清
/还款 1000     部分还款
```

- 部分还款**先还利息，再还本金**；
- 利息始终按**原始本金**计算，不因还了本金而减少；
- 贷款状态在剩余应还为 0 前保持 `active`，清零后才 `closed`；
- 每次还款会显示本次还利息、还本金、支付金额、剩余应还。

### 贷款身份与购买限制

贷款提示会根据**剩余应还金额**显示身份：

| 身份 | 条件 | 购买 |
| --- | --- | --- |
| 🟢 信用良好 | 剩余应还 < 10,000 | 正常 |
| 🟡 负债修士 | 10,000–49,999 | 正常 |
| 🟠 欠款大户 | 50,000–99,999 | 正常 |
| 🔴 老赖 | ≥ 100,000 | 暂停购买 |
| 🔴 紧急欠款人 | 剩余 ≤1 天且 ≥50,000 | 暂停购买 |

被暂停的购买/消费指令包括：`/购买`、`/购买洞天`、`/坊市购买`、`/黑市购买`、`/宗门兑换`、`/切原石`。查看商店、`/还款`不受影响。

- 贷款逾期仍会被全服广播追杀并删除角色，务必按时还款。
- 部分还款后身份会按新的剩余金额重新判定，欠款降到门槛以下会恢复购买。

### 6.4 玩家坊市

```text
/坊市
/坊市上架 <物品名> <数量> <单价>
/坊市购买 <编号>
/坊市下架 <编号>
```

玩家自由定价交易，成交时系统抽 5% 交易税。上架物品来自储物戒，购买时会校验储物戒容量。

### 6.5 储物戒

```text
/储物戒
/取出 <物品名> [数量]
/取出所有 <分类>
/丢弃 <物品名> [数量]
/搜索物品 <关键词>
/赠予 @某人 <物品名> [数量]
/接收
/拒绝
/更换储物戒 <名称>
/储物戒附魔 [数量]
```

- 储物戒有容量限制。
- 空间石可永久增加容量，每颗 +5，上限 +50；附魔跟随角色，换戒指不消失。
- 赠予需要对方 `/接收`，拒绝则退回。

### 6.6 战斗与竞技

```text
/切磋 @某人      友谊赛，有冷却
/决斗 @某人      正式 PVP，有冷却
/挑战世界Boss    参与全服 Boss 讨伐；5 分钟 CD，单次 0.5%-20%，每日不限次
/世界Boss状态    查看 Boss 血量、规则和剩余时间
/传承挑战 @某人  争夺传承加成
/传承信息
/传承排行
```

五行克制：

- 功法/心法/武器名称中含金、木、水、火、土，即获得对应五行属性。
- 金克木、木克土、土克水、水克火、火克金。
- 克制方伤害提高，被克方伤害降低。

世界 Boss：

- 全服共同讨伐，按伤害排名发奖。
- 单次伤害保底 0.5%，上限 20%；
- 每日挑战**不限次数**，但两次挑战之间冷却 **5 分钟**；
- 单次 20% 上限意味着理论上 5 次可以打掉一个满血 Boss；
- 逾期未击杀的 Boss 会逃遁，查询状态时不再显示负数时间。

### 6.7 宗门

```text
/创建宗门 <名称>
/加入宗门 <名称>
/退出宗门
/解散宗门 确认
/我的宗门
/宗门列表
/宗门捐献 <数量>
/宗门任务
/完成宗门任务
/放弃宗门任务
/宗门建筑
/升级建筑 <名称>
/宗门商店
/宗门兑换 <编号>
/宗门命令 @人 捐献 1000 24
/宗门命令 @人 宗门任务 1 24
/宗门命令列表
/宗门命令撤销 <编号>
/宗门大比开启
/宗门大比报名
/宗门大比状态
/宗门宣战 <宗门名>
/宗门战争状态
/踢出成员 @某人
/宗主传位 @某人
/职位变更 @某人 <0-4>
```

- 宗主可发送 `/解散宗门 确认` 解散宗门；所有成员会回到无宗门状态，贡献和欠款清零，宗门资金/建筑/商店/大比记录不保留。
- 宗门任务通常需要挂机约 1 小时，完成后领贡献；放弃宗门任务会扣 500 灵石。
- 宗门贡献来源：捐献灵石、完成宗门任务、参与宗门活动；贡献可用于宗门商店兑换。
- 宗门商店每个宗门独立，每次随机刷新 **5 件**商品，默认 1 小时刷新；价格与百宝阁物品灵石价格 **1:1**，用宗门贡献支付；每件库存 1，卖完等刷新。
- 宗门商店商品来自百宝阁物品池，暂不包含旧格式丹药。
- 宗门等级 1–5，经验来源：捐献（1 灵石 = 1 经验）、宗门任务（贡献×10）、大比、宗门战；等级解锁新建筑并提高命令栏上限。

| 等级 | 经验 | 解锁 |
| ---: | ---: | --- |
| 1 | 0 | 藏经阁、演武场、炼丹房 |
| 2 | 10,000 | 商堂 |
| 3 | 30,000 | 任务堂 |
| 4 | 60,000 | 护山大阵 |
| 5 | 100,000 | 命令栏上限提升 |

建筑可升级上限 = `min(5, 宗门等级 + 1)`；已有高等级建筑保留，不降级。

- 建筑：藏经阁（闭关）、演武场（宗门任务贡献）、炼丹房（炼丹成功率）、商堂（贡献商店 -2%/级，最高 -10%）、任务堂（日常任务奖励 +3%/级，最高 +15%）、护山大阵（宗门战被掠夺 -5%/级，最高 -25%）。
- 宗门命令只能向职位更低的成员下达，每人同时只能被下 1 条；未完成罚 500 灵石，不足记欠款，有灵石自动偿还；欠款未清不能退宗/被踢。
- 宗门大比由宗主开启，30 分钟报名，本宗门成员参加，报名结束自动随机抽签单败淘汰，奇数轮空；冠军 10,000 灵石，系统发放，无亚军/季军。
- 宗门战由宗主宣战，双方至少 3 人；自动 KOF（外门→内门→亲传→长老→宗主），败者换下一位；胜方掠夺败方每人当前灵石 20%，再按胜方贡献百分比分配；宣战费 10,000 宗门资金，宣战方 72 小时冷却，败方 24 小时保护。

### 6.8 洞天

```text
/我的洞天
/购买洞天 1
/升级洞天
/洞天收取
/洞天装修 <家具名>
/进阶洞天 <编号>
```

洞天按时产出修为和灵石，需要定期收取。家具提供永久加成，例如：

- 聚灵蒲团：闭关收益 +5%
- 灵兽窝：喂养消耗 -20%
- 灵泉假山：洞天产出 +10%

### 6.9 灵田

```text
/我的灵田
/开垦灵田
/种植 <灵草> [数量]
/收获
/施肥
/杂交 <灵草A> <灵草B>
/升级灵田
/季节
```

- 灵草需要时间生长，约 48 小时不收获会枯萎。
- 每次收获消耗土壤肥力，肥力过低会减产；`/施肥` 消耗灵石恢复肥力。
- 杂交有概率培育稀有灵草，例如火焰花 + 冰心草 → 冰火双生花。
- 季节每周轮转，影响生长速度和产量：春加速、秋增产、冬减速（冰心草不受影响）。

### 6.10 灵眼

```text
/灵眼信息
/抢占灵眼 <ID>
/灵眼收取
/释放灵眼
```

灵眼是全服 PVP 资源点，占领后按时产出修为，需要定期收取；可能被其他玩家抢走。

### 6.11 灵兽

```text
/我的灵兽
/孵化灵兽 <名称>
/喂养灵兽
/放生灵兽
/吞噬灵兽
```

灵兽在战斗中协助出手、追加伤害。喂养可提升灵兽，消耗灵石和修为；成功提示会显示本次消耗灵石和剩余灵石。放生/吞噬会失去该灵兽，谨慎操作。

### 6.12 任务与悬赏

```text
/任务榜
/接取任务 <黄/玄/地/天>
/放弃任务 <编号>
/领取任务奖励
/悬赏令
/接取悬赏 <ID>
/悬赏状态
/完成悬赏
/放弃悬赏
```

- 日常任务分黄、玄、地、天四阶；每日接取上限：黄 5、玄 3、地 2、天 1，已放弃/已领取也计入次数。
- 任务有进度要求，完成后领奖。
- 放弃日常任务会扣该任务灵石奖励的 80%；灵石奖励不足时改扣 80% 灵气，仍不足则扣 500 灵石。放弃不退当日次数。
- 悬赏是另一套委托系统，接取后查看状态，完成后领奖；放弃悬赏扣 80% 悬赏灵石并进入 30 分钟冷却。

### 6.13 历练

```text
/历练信息
/开始历练 <路线>
/历练状态
/完成历练
/放弃历练
```

- 选择路线后开始挂机历练，路线有风险、时长、推荐境界和疲劳冷却。
- 到时间后 `/完成历练` 结算修为、灵石和物品。
- `/放弃历练` 会扣该路线基础灵石奖励的 80%。
- 历练归来有概率触发奇遇。
- 历练期间处于「历练中」，不能开始其他占用状态的活动。

### 6.14 秘境

```text
/秘境列表
/探索秘境 <ID>
/完成探索
/退出秘境
```

- 进入秘境后需要时间探索，到时间 `/完成探索` 结算。
- 可以 `/退出秘境` 提前离开；提前退出会扣该秘境最低灵石奖励的 80%。
- 秘境归来有概率触发奇遇。

### 6.15 奇遇


不同选择有不同结果：可能获得神装、修为、灵石、功德/业力，也可能受伤或遭反噬。选项有有效期，超时视为离开。

### 6.16 押镖与劫道

```text
/押镖
/完成押镖
/放弃押镖
/劫镖 @某人
```

- 押镖约 30 分钟，期间处于「押镖中」，全服广播。
- 送达后 `/完成押镖` 领镖银和功德；`/放弃押镖` 会扣 80% 镖银并失去本次收益。
- 劫镖消耗【迷神香】触发 PVP；胜者抢走部分镖银，败者赔偿。
- 押镖期间不能开始其他占用状态的活动。

### 6.17 炼丹

## 8. 常见问题

### 为什么我发指令没反应？

- 群聊里通常需要 `@机器人`，或者指令以唤醒前缀 `/` 开头；
- 确认当前群在插件 `WHITELIST_GROUPS` 中，或该配置留空；
- 确认插件已启用、AstrBot 在线。

### 为什么提示「正在闭关中/历练中，无法分心他顾」？

角色处于忙碌状态。先结束当前活动：

```text
闭关 → /出关
历练 → /完成历练
秘境 → /完成探索 或 /退出秘境
押镖 → /完成押镖 或 /放弃押镖
宗门任务 → /完成宗门任务
悬赏 → /完成悬赏 或 /放弃悬赏
```

找不到退出指令或卡住时，发：

```text
/解卡
```

### 为什么图片卡片不出？

- 确认已安装 `Pillow`；
- 确认 `resources/` 目录完整；
- 插件配置 `IMAGE_CARDS` 是否开启；
- 图片生成失败会自动降级为文字，不影响游戏。

### 突破失败会怎样？

突破资费无论成败都会消耗；失败但未死亡会损失当前总修为的 10%，体修突破失败可能死亡。突破前先看 `/突破信息`，带好破境丹。

### 贷款逾期会怎样？

会被全服广播追杀并删除角色，务必按时还款。可以 `/还款 <金额>` 部分还款，先还利息再还本金；利息仍按原始本金计算，剩余应还未清零前贷款保持 `active`。身份和购买限制按剩余应还金额重新判定。

### 宗门怎么升级？

宗门等级靠宗门经验自动提升：捐献灵石、完成宗门任务、参加大比/宗门战都会增加经验。等级解锁商堂、任务堂、护山大阵，并提高命令栏上限；已有高等级建筑不会降级。

### 宗门命令没完成会怎样？

未完成固定罚 500 灵石；灵石不足时扣光现有灵石，剩余记入宗门欠款。欠款无上限，之后有灵石会自动偿还；欠款未清不能退出宗门或被踢出。

### 宗门大比怎么开？

只有宗主能发送 `/宗门大比开启`，本宗门成员在 30 分钟内 `/宗门大比报名`。报名结束后自动随机抽签单败淘汰，奇数轮空，冠军获得 10,000 灵石，没有亚军/季军。每个宗门 24 小时内只能开一次。

### 宗门战怎么打？

宗主 `/宗门宣战 <宗门名>`，双方至少 3 人，宣战费 10,000 宗门资金。自动 KOF：外门→内门→亲传→长老→宗主，败者换下一位。胜方掠夺败方每人当前灵石 20%，再按胜方贡献百分比分配。宣战方 72 小时冷却，败方 24 小时保护。

### 灵田作物为什么没了？

约 48 小时不收获会枯萎。记得定期 `/收获`，并 `/施肥` 维持肥力。

### 世界 Boss 为什么打不出高伤害？

世界 Boss 单次伤害保底 0.5%，上限 20%，每天不限次数，两次之间冷却 5 分钟；提升境界、装备、功法、五行克制和灵兽协同更有效。

### 飞升后角色没了？

飞升是转生重置，角色会重新开始；封印的传家宝可以在转生后达到筑基期解封。

### 换职业/重来？

使用 `/弃道重修 确认`：需要角色空闲、没有未结清贷款，且距离上次重修满 7 天。会清空角色本体、资产、日常任务、世界 Boss 伤害记录、坊市上架和用户冷却；宗主会自动传位或解散宗门。谨慎使用。

## 9. 管理员配置

| 配置 | 作用 |
| --- | --- |
| `WHITELIST_GROUPS` | 允许使用插件的群号列表；留空表示所有群可用；全服事件广播需要配置 |
| `BOSS_ADMINS` | 可使用 `/仙界管理`、生成 Boss、开启魔潮等管理员指令的用户 ID |
| `SHOP_MANAGERS` | 可手动刷新商店的用户 ID |
| `IMAGE_CARDS` | 图片卡片总开关和分界面开关 |

管理员 ID 用 `/sid` 获取；NapCat/OneBot 通常是 QQ 号，QQ 官方机器人是 OpenID。
