# 模拟修仙 · 游戏机制知识库

> 适用：AstrBot 插件 `astrbot_plugin_xiuxian_promax`。
> 定位：面向玩家与 AI 问答的完整游戏规则手册，记录游戏如何运作、各项系统之间如何联动。
> 说明：本文不是版本更新日志，不按版本罗列改动；具体数值以游戏内实际显示和插件配置为准，随机结果以当次结算为准。

## AI 检索说明

- 本文按 `##` / `###` 标题分块，每块只讨论一个主题；做向量化时建议保留标题与所属章节编号，不要把整张长表跨块切断。
- 回答玩家问题时，优先引用与问题最接近的机制块；涉及概率、价格、每日次数、活动时间的，应说明“以游戏内当前配置为准”。
- 不要把随机结果当作固定规则；不要补写本文没有记载的隐藏数值。
- 指令中的 `<>` 为必填参数，`[]` 为可选参数，`/` 前缀可省略。
- 同一个概念在不同系统里可能有不同叫法，优先使用“术语表”中的标准名称。

## 核心术语

| 标准术语 | 别名/玩家说法 | 含义 |
| --- | --- | --- |
| 境界 | 等级、阶段 | 角色成长阶段，决定基础战斗属性、可进入内容和物品门槛 |
| 修为 | 经验、EXP | 突破所需进度；可转化为修为溢出加成 |
| 气血 | HP、血量 | 战斗生命值；气血上限由境界基础与装备/加成决定 |
| 灵气 | MP、法力、真元 | 战斗资源；与气血分开结算 |
| 品阶 | 稀有度、品级 | 凡品到混元先天的统一物品阶梯 |
| 品质 | 装备品质、丹药品质 | 同一物品内部的随机/固定品质档位，影响倍率 |
| 词条 | 附加属性、affix | 装备实例上的额外属性，绑定具体装备 |
| 材料 | 素材 | 按“类别 + 品阶”参与配方或定向洗练 |
| 配方 | 丹方、符图 | 学习后解锁炼丹/制符 |
| 装备实例 | 单件装备 | 同名装备可拥有不同品质、词条和强化信息 |
| 修为溢出 | 经验溢出 | 超过当前境界突破门槛的修为，按分段折算为战斗加成 |

## 阅读约定

- 指令前的 `/` 可以省略；`<>` 表示必填参数，`[]` 表示可选参数。
- “境界索引”是角色成长阶段的内部序号，玩家看到的境界名称以 `/我的信息` 为准。

- 装备、丹药、符箓等物品的最终效果，以物品详情和实际结算为准。

## 1. 游戏简介

「模拟修仙」是一个运行在 QQ 群里的放置类文字修仙游戏。玩家在群聊中发送指令，创建角色、闭关修炼、突破境界、加入宗门、炼丹炼器、下秘境、押镖、参与全服 Boss 和魔潮活动，最终飞升转生。

核心循环：

```text
创建角色 → 签到/闭关积累修为 → 突破境界 → 做日常/历练/秘境拿资源
→ 提升装备、丹药、灵兽、宗门 → 挑战世界 Boss / 参与魔潮 → 飞升转生
```

游戏是**按 QQ 号单独存档**的：同一个群里，每个人有自己的角色、境界、灵石和状态，互不共享。

```text

/签到              每日签到，领灵石和节日福利
/我的信息          查看角色面板（通常附带图片卡片）
```

新手创建角色后会获得启动资金和新手引导奖励。装备购买后先进入储物戒，再用 `/装备` 穿戴；丹药进入丹药背包。之后每天至少做：

```text

/收获
/领取利息
/灵眼收取
```

也可以发 `/一键日常`，它会提示你依次完成这些操作。

## 3. 职业与开局

创建角色时可选职业：

| 职业 | 定位 |
| --- | --- |
| 灵修 | 均衡型，灵气/法术路线 |
| 体修 | 高气血、高物伤，突破失败风险更高 |
| 魔修 | 吸血、爆发 |
| 剑修 | 极致物理输出 |
| 鬼修 | 诡道、持续伤害方向 |
| 佛修 | 反伤、肉盾 |
| 御兽 | 依赖灵兽协同作战 |

开局还会随机灵根（如土灵根、单灵根等），灵根影响修炼倍率。职业和灵根在角色创建时确定，后续可通过「弃道重修」重来。

## 4. 核心数值

| 数值 | 作用 |
| --- | --- |
| 修为 | 突破境界的基础，闭关、历练、秘境、丹药等获得；**不再直接抬高战斗攻防气血** |
| 灵石 | 通用货币，商店、银行、坊市、强化、炼丹等使用 |
| 境界 | 角色成长阶段，决定战斗基础属性、可去路线、可买物品 |
| 气血/法力 | 战斗中的生命和法力，由境界基础模板决定 |
| 物伤/法伤 | 物理与法术攻击；装备提供的是对境界基础的百分比加成 |
| 物防/法防 | 物理与法术减伤；装备同样按百分比加法叠加，减伤随战斗尺度缩放 |
| 精神力 | 部分系统和战斗判定使用 |
| 功德/业力 | 影响突破成功率和奇遇概率 |
| 仙缘点 | 飞升/长期系统兑换永久加成 |

装备普通整套约 25%～35% 主属性，总上限约攻击 40% / 防御 35%；暴击、反伤上限为 100%，吸血上限为 50%，暴击溢出转暴伤、吸血溢出转双攻。突破境界始终比单纯换装备更重要。

### 突破

```text
/突破信息          查看当前突破所需修为和成功率
/突破 [破境丹名] [品质]   尝试突破，可带破境丹提高成功率
```

- 突破需要修为；不再消耗灵石资费。
- 体修突破失败的境界跌落风险更高（默认概率额外 ×1.5，可在插件配置 `VALUES.BODY_BREAKTHROUGH_DEATH_MULTIPLIER` 调整），但不会直接死亡。
- 功德/业力会修正突破成功率，有上下限。
- 破境丹可以提升成功率；无效或不适用的破境丹不应被消耗。

### 功德与业力

- 行善、救人、做好事会增加功德；偷窃、劫镖、恶行会增加业力。
- 功德提高突破成功率和奇遇触发概率；业力降低突破成功率。
- `/行善` 每天可捐灵石增加功德。

## 5. 修炼与状态

### 闭关

```text
/闭关    进入闭关，开始按时间积累修为
/出关    结束闭关，结算修为
```

**修为公式（v7.7 起）**：

```text
每小时修为 = 本境界突破需求 × 0.0025(可配 BREAKTHROUGH_RATE_PER_HOUR)
            × 灵根倍率 × (1 + 功法加成) × 丹药符箓倍率 × 仙缘倍率
```

- 不再用固定基数和「每级 +10%」的等级倍率（`VALUES.BASE_EXP_PER_MINUTE` 只剩旧存档兼容用途），境界差异由「突破需求」这把尺子自动体现：**突破所需时间恒定**，约 `1 ÷ 0.0025 = 400 小时` 无加成，满配约 20 小时。
- 灵根（0.7~3.2）与功法（上限 130%）**只在闭关生效**；丹药与符箓同时作用于闭关与历练；秘境不吃修炼加成。
- 洞天家具、宗门藏经阁、魔潮、化身、仙缘商店加成都在这个乘积之上叠加。这里的“收益”指修为，不是战斗中的灵气。

闭关期间角色处于「闭关中」，大部分会改变状态的操作会被拒绝，但可以查看信息、签到、收菜、领奖。

### 功法体系（双轨）

- **主修心法**：独占 1 个槽位，共 60 本五行战斗心法（金/木/水/火/土 × 凡/黄/玄/灵/地/天/皇/圣/帝/道/仙/混元先天 十二品阶，每阶每系一本）。只提供战斗增益，包括暴击率、暴击伤害、吸血、反伤、连击、闪避、额外防御、物伤/法伤倍率，并决定战斗五行属性。
- **主动绝技**：每本主修心法自带 1 个绝技，战斗第 2 回合起自动释放，不需要手动出招。PvP 每场 1 次，PvE 每 6 回合可再放 1 次；灵气不足时不释放，后续回合蓝量够了会再尝试。五系效果为金破甲、木回春、水冻结、火灼烧、土守御。`/心法 [名称]` 或 `/技能 [名称]` 可查询绝技，`/物品信息 <心法名>` 与 `/我的装备` 同步展示。
- **普通功法**：最多装备 3 本，只提供生活加成，包括灵石收益、修炼效率、掉落几率、冷却缩减、气运；不提供直接战斗特效，但其五行会作为“同属性件数”参与五行共鸣（见后文五行共鸣）。
- 普通功法的「修炼效率」会计入闭关修为倍率；「冷却缩减」会缩短世界Boss、团本、劫镖、决斗、切磋等冷却。
- 主修心法与普通功法都按 12 品阶设置境界门槛；两套功法都不参与装备品质、洗练与随机词条。卸下或替换时功法会返还储物戒。
- 普通功法按 `/我的装备` 显示顺序排列，最多 3 本；`/装备 <功法名> 1~3` 可直接替换指定栏位，`/卸下 功法 1~3` 或 `/卸下 <功法名> <栏位>` 可卸下指定功法。
- 获取途径：百宝阁、宗门商店、历练、秘境、奇遇、Boss、世界Boss、团本；主修心法在商店与掉落中均为稀有产出。
- 生活功法共 203 本，覆盖凡品至混元先天；高阶生活功法按五行提供修炼效率、灵石收益、掉落几率、冷却缩减与气运加成。
- 暴击伤害目前是加法叠加，例如基础 1.5 + 心法 0.55 = 2.05，实际可能达到 205% 暴击伤害。

### 忙碌状态

游戏里常见忙碌状态：

```text
闭关中、历练中、探索秘境中、宗门任务中、押镖中、渡劫中、掠夺中、宗门大比中
```

忙碌时：

- 可以执行查询、签到、收菜、领奖、排行榜等基础指令；
- 查询类包括 `/我的信息`、`/突破信息`、`/丹药信息`、`/丹阁`、`/丹方`、`/秘境列表`、`/秘境详情`、`/历练信息`、`/传承信息`、`/坊市`、`/悬赏令`、`/银行流水`、`/仙缘商店`、`/宗门列表`、`/宗门战报`、`/团本状态`、`/季节`、`/仙界日历`、`/师徒`、`/称号图鉴`、`/我的称号` 等只读指令；
- 不能开始另一项会占用状态的活动，`/突破`、`/炼丹`、`/学习丹方`、`/种植`、购买/报名/兑换等仍会被拦截；
- 必须先用对应的退出/完成指令结束当前状态，或用 `/解卡` 强制重置。

### 解卡

```text
/解卡
```

强制把角色恢复为空闲，放弃当前闭关/历练/秘境/宗门任务/押镖等进度，不发放奖励。角色卡住、找不到退出指令时使用。

## 6. 主要玩法系统

### 6.1 签到与日常

```text
/签到        每日签到；修仙节日（如蟠桃会）有额外福利
/一键日常    提示签到、洞天收取、灵田收获、领取利息、灵眼收取
```

签到按自然日计算，每天一次。

### 6.2 商店

```text
/丹阁        丹药/丹方/材料商店
/器阁        武器商店
/百宝阁      综合商店（丹药/材料/稀有装备）
/购买 <物品名> [数量]
/购买 <物品名> [数量]
/物品信息 <名称>
/装备 <物品名>
```

商店商品会随机刷新，有随机折扣和库存。装备类物品按自身境界要求校验，购买和穿戴使用同一门槛。

- 装备类货架每次刷新只上架 1 件，购买时也只能买 1 件；材料、丹药、符箓可正常多件购买；
- 器阁与百宝阁的刷新品阶按全服最低/最高/平均玩家境界计算；器阁以常规品阶为主、数量较多；
- 百宝阁使用稀有模式：**品阶越高、基础商店权重越低，入选权重越高**，因此高境界服务器会明显偏向圣品/皇品；线上 `PAVILION_TREASURE_COUNT` 当前为 25 件，品阶区间还会被全服最高境界玩家抬高；
- 百宝阁为单张长图，图内按品阶自动排序并分区（如「黄品区」）；器阁同样为一整张长图；
- 显式 `shop_weight=0` 的物品不会出现在百宝阁（含周本专属「天外陨核」与帝品散装材料），只能通过历练、秘境、世界 Boss/团本/江湖事件/周本掉落等途径获取；材料阁仍出售「帝品材料包」。
- 特殊手套/戒指没有面板主属性，详情会展示品质缩放后的特殊效果。

购买后的去向：

- 武器、防具、饰品、功法、材料、符箓 → 储物戒；
- 破境丹、修为丹、功能丹 → 丹药背包；
- 旧版“购买后立即生效”的丹药已统一改为进入丹药背包，使用 `/服用丹药` 服用。

购买的装备不会自动穿戴。购买后装备进入储物戒，再使用 `/装备 <装备名>` 穿戴；储物戒容量不足时装备可能进入溢出仓库，需先用 `/领取溢出` 取回。

黑市：

```text
/黑市              查看当前小时的黑市商品
/黑市购买 <编号>   购买盲盒商品
```

- 黑市**每小时刷新**，同一小时展示与购买一致；
- 每次展示 3 件商品，可能是真实物品，也可能是假货；
- 真实物品会显示品阶、类型、效果和黑市价；
- 显式 `shop_weight=0` 的物品（如周本专属「天外陨核」、帝品材料与炼丹专属增益丹）不会进入黑市，需通过对应高难玩法获取；
- 假货会扣灵石并伤气血，不发放物品；
- 真实物品购买失败（如储物戒满）会退回灵石，不会产生无法使用的“幽灵物品”。

### 6.3 银行

```text
/银行
/存灵石 <数量>
/取灵石 <数量>
/领取利息
/贷款 <金额>
/突破贷款 <金额>
/还款 [金额]
/银行流水
```

- 存款按日复利，利率约 0.1%/天。
- 单个账户存款上限**按大境界递增**，境界越高能存越多：

| 大境界 | 存款上限 |
| --- | ---: |
| 炼气期 | 500 万 |
| 筑基期 | 1,000 万 |
| 金丹期 | 2,000 万 |
| 元婴期 | 5,000 万 |
| 化神期 | 1 亿 |
| 炼虚期 | 2 亿 |
| 合体期 | 5 亿 |
| 大乘期 | 10 亿 |
| 渡劫期 | 20 亿 |
| 地仙 | 50 亿 |
| 天仙 | 100 亿 |
| 大罗金仙 | 200 亿 |
| 混元大罗金仙 | 500 亿 |

- 上限按「余额 + 待领利息」计算，存满后需先取款才能继续存；突破大境界后上限自动提升，已存余额不受影响。
- 分档表在 `config/game_config.json` 的 `bank.deposit_caps`（按 `level_index` 分档），插件配置里的「存款上限倍率」可整体放大缩小。
- 普通贷款日利率约 0.5%，期限 7 天；突破贷款日利率约 0.8%，期限 3 天。
- 大额贷款有持有门槛：贷款金额超过 10,000 时，需要至少持有贷款金额的 20%，最低 5,000。持有金额 = 身上灵石 + 银行存款。

| 贷款金额 | 最低持有 |
| ---: | ---: |
| 10,000 以下 | 0 |
| 20,000 | 5,000 |
| 50,000 | 10,000 |

### 还款方式

```text
/还款          一次性还清
/还款 1000     部分还款
```

- 部分还款**先还利息，再还本金**；
- 利息始终按**原始本金**计算，不因还了本金而减少；
- 贷款状态在剩余应还为 0 前保持 `active`，清零后才 `closed`；
- 已还利息/本金会实时回读，多次部分还款会累计，不会覆盖之前的还款记录；
- 每次还款会显示本次还利息、还本金、支付金额、剩余应还。

### 贷款身份与购买限制

贷款提示会根据**剩余应还金额**显示身份：

| 身份 | 条件 | 购买 |
| --- | --- | --- |
| 🟢 信用良好 | 剩余应还 < 10,000 | 正常 |
| 🟡 负债修士 | 10,000–49,999 | 正常 |
| 🟠 欠款大户 | 50,000–99,999 | 正常 |

| 🔴 紧急欠款人 | 剩余 ≤1 天且 ≥50,000 | 暂停购买 |

被暂停的购买/消费指令包括：`/购买`、`/购买洞天`、`/坊市购买`、`/黑市购买`、`/宗门兑换`、`/切原石`。查看商店、`/还款`不受影响。

- 贷款逾期仍会全服广播，并触发境界跌落（掉落一个大境界）；该笔贷款随即转为坏账，不会重复处罚，但仍需按时还款。

切磋与决斗限制：

- 切磋默认每日 3 次，决斗每日 1 次；次数按实际参战双方分别累计，未接受/被拒绝的邀请不消耗次数。
- 切磋邀请 5 分钟内有效，双方均需处于空闲状态；接受方和发起方都会进入切磋冷却。
- 决斗仍会直接执行，但发起前会检查双方今日决斗次数与冷却。

旧版兼容：`/世界Boss`、`/世界boss` 查询动态Boss；新版统一使用 `/挑战世界Boss` 参与讨伐。

五行克制：

- 主修心法/武器名称或配置的五行属性决定战斗五行（优先主修心法）；普通功法的五行不决定战斗五行、不参与战斗克制，只计入五行共鸣的同属性件数。
- 金克木、木克土、土克水、水克火、火克金。
- 克制方伤害提高，被克方伤害降低。

五行共鸣：

- 主属性由主修心法决定；未装备心法时回退到当前武器，普通功法不改变主属性。
- 已穿戴的 8 个装备部位与 3 本普通功法中，五行与主属性一致的件数会累计五行共鸣加成；不同属性的装备不计入。
- 同属性灵根额外提供灵根共鸣：单灵根按 100%，双/三/四灵根按拥有的五行属性数量分摊。雷/风归木，冰/暗归水，光归火；融合/混沌灵根视为同时拥有五行，按 1/5 分摊；阴阳灵根不额外派生火属性。
- 五系加成方向：金→物攻与暴击，木→气血与吸血，水→法攻与法防，火→双攻与暴伤，土→双防与反伤；各项受上限约束。
- 五行共鸣并入统一战斗面板，与五行克制的伤害乘区独立结算。

世界 Boss：

- 全服共同讨伐，按伤害排名发奖。
- 共 10 种 Boss，分灭世级 / 灾厄级 / 神话级三阶，Boss 带五行属性并有境界门槛。
- 刷新档位随全服境界动态提高：低境界服以灭世级为主，合体/大乘/渡劫玩家出现后神话级概率明显上升（渡劫服约 35%）。
- 单次伤害保底 0.5%，上限随境界提高：基础 **20%**，每提升 1 级境界 +**0.8%**，封顶 **45%**；
- 每日挑战**不限次数**，但两次挑战之间冷却 **5 分钟**；
- 低境界玩家仍为 20% 上限，高境界玩家可打出更高单次伤害，但单次最多约打掉半血；
- 击杀后按伤害排名发放灵石与材料；尾刀/前3/参与均有独立装备掉落机会，神话级使用最高 `legend` 掉落档；`legend` 档（神话级世界 Boss、★★★ 团本、S 级江湖事件与周本共用）除圣品材料外，还会低概率掉落太初道莲、太初道金、太古真龙鳞、太初源液等帝品材料。
- 逾期未击杀的 Boss 会逃遁；到期后由后台任务与查询/挑战入口立即标记，查询状态不会显示负数时间。
- 已过期但仍残留的 Boss 会在生成新 Boss 前先被清理，不会阻塞下一次刷新。

- 建筑：藏经阁（闭关）、演武场（宗门任务贡献）、炼丹房（炼丹成功率）、商堂（贡献商店 -2%/级，最高 -10%）、任务堂（日常任务奖励 +3%/级，最高 +15%）、护山大阵（宗门战被掠夺 -5%/级，最高 -25%）。
- 升级建筑消耗宗门资金，宗门资材可按 1:1 抵扣至多一半资金；资材来自完成宗门任务。
- 宗门命令只能向职位更低的成员下达，每人同时只能被下 1 条；未完成罚 500 灵石，不足记欠款，有灵石自动偿还；欠款未清不能退宗/被踢。
- 宗门大比由宗主开启，30 分钟报名，本宗门成员参加，报名结束自动随机抽签单败淘汰，奇数轮空；冠军 10,000 灵石，系统发放，无亚军/季军。
- 大比每场胜场计入 `sect_battle_win` 称号计数；`/宗门大比状态` 可查看最近一届对战记录，`/宗门战报 [编号]` 可查看详细宗门战战报。
- 宗门战由宗主宣战，双方至少 3 人；自动 KOF（外门→内门→亲传→长老→宗主），败者换下一位；胜方掠夺败方每人当前灵石 20%，再按胜方贡献百分比分配；宣战费 10,000 宗门资金，宣战方 72 小时冷却，败方 24 小时保护。
- 双修需双方空闲且修为差距不超过 3 倍；双方各获得对方当前修为的 10%，1 小时冷却，请求 5 分钟内有效。已结缘仙灵道侣的玩家不能与真人双修。

### 6.8 洞天


### 6.9 灵田

```text
/我的灵田
/开垦灵田
/种植 <灵草> [数量|格号区间|all]
/收获
/铲除 <格号...|1-3|all>
/施肥
/杂交 <灵草A> <灵草B>

```

- 灵草需要时间生长，约 48 小时不收获会枯萎。
- 生长时长：灵草 1h、血灵草 2h、冰心草 3h、火焰花 4h、九叶灵芝 8h、冰火双生花 6h、血玉灵芝 10h、幽冥草/九幽仙芝 12h；最长 12 小时，保证任何灵草都能在 1 个季节（2 天）内成熟，单格单日产出随品阶递增。

- 灵田等级上限为 **Lv.10**：Lv.1~Lv.10 格数依次为 3 / 5 / 8 / 12 / 20 / 24 / 28 / 32 / 36 / 40；Lv.6 起每级追加 4 格。
- 灵田按格管理，`/铲除 <格号...|1-3|all>` 可移除指定格灵草（无产出），并同步取消该格的自动续种。
- 灵田产出的灵草属于炼丹“灵植”材料，可在学习对应丹方后用于炼丹。
- 肥力上限随等级提高（Lv.1~Lv.10：100/100/160/240/400/480/560/640/720/800），满格一茬消耗上限 40%，地板为上限 20%；`/施肥` 花 2,000 灵石恢复上限的 30%，也可用 `/自动代理 施肥 [阈值%]` 自动补肥（回报不足自动跳过）。
- 所有灵草统一“种1收2”，普通灵草可直接种植，杂交灵草需先获得植株。
- 种植参数支持单数字（`/种植 灵草 6`）、格号区间（`/种植 灵草 1-20`，在区间内空格种满）、`all`（`/种植 灵草 all`，种满所有空格）；也兼容 `灵草6`、`灵草1-20`、`灵草all` 紧贴写法。
- `all` 亦可写成 `全部`、`所有`、`种满`、`一键`、`max`；数量/区间可带单位（`20株`、`1-20格`），全角字符与句末标点自动归一化。
- 不写灵草时 `/种植 all` 沿用田里种得最多的灵草（空田默认灵草）并种满空格；已占用或待收获的格子跳过并在结果中提示。
- 杂交配方：冰心草 + 火焰花 → 冰火双生花（Lv.5）、血灵草 + 九叶灵芝 → 血玉灵芝（Lv.4）、九叶灵芝 + 幽冥草 → 九幽仙芝（Lv.5）。
- `/杂交` 消耗父本各1株并占用2个空格，耗时与产物生长时间一致，完成后 `/收获` 领取1株杂交植株。
- 种植杂交植株会从储物戒消耗 1 株；没有植株无法直接种植，可通过杂交或坊市购买获得。
- 季节每 2 天轮转（春→夏→秋→冬，8 天一轮，起点为每年 1 月 1 日），影响生长速度和收益：春加速、夏阳性草加速、秋增产、冬减速（冰心草不受影响）；换季时生长中的灵草，成熟时间会按剩余比例自动伸缩（变快则提前、变慢则延后），不需要重种；`VALUES.FARM_SEASON_DAYS` 可调整为 1-30 天。

### 6.11 灵兽

```text
/我的灵兽
/孵化灵兽 <名称>
/喂养灵兽 [序号/名]
/灵兽出战 <序号/名>
/灵兽改名 <序号/名> <新名>
```

- 非御兽职业的灵兽上限固定为 1 个；御兽槽位随大境界提升（炼气 2、筑基 3、金丹 4……）。
- 灵兽达到 Lv.20、Lv.40 时自动进化，不消耗材料：火灵狐→炎灵狐→九尾天狐；冰晶兽→玄冰巨兽→冰川巨兽；噬金鼠→寻宝金鼠→吞金貔貅；青龙幼崽→青龙→太古青龙。进化后本体数值与加成效果大幅提升，默认名称同步更新。

- 单只灵兽满级被动上限：九尾天狐暴击 +30%；冰川巨兽主人防御 +20%、反伤 +20%；太古青龙暴击 +20%、吸血 +12%；单个吞金貔貅灵石收益 +30%。灵兽被动按等级成长，进化后同步跃升。
- 支持重复品种（默认命名如「火灵狐 1」「火灵狐 2」）并允许改名；可设置主战灵兽。
- 灵兽每回合必定协战并追加伤害，拥有独立的等级攻防与精力（血量）；多宠协战伤害递减，主战宠提供主人被动并优先护主。
- 受到攻击时替主人承伤，精力耗尽则倒下；脱战后精力随时间恢复（每分钟 2% 最大精力，享受自然恢复加成）。

- 御兽首次契约免费、喂养 -20%、复活加速，并按主人修为获得 30% 共享经验（其他职业 10%）；所有灵兽各获得等量经验，不按数量平分。
- 喂养灵兽只消耗灵石，不消耗玩家修为；噬金鼠等生活类加成按每只灵兽分别叠加，复活中的灵兽不提供加成。
- 历练/秘境结算时若存在灵兽空槽，会触发灵兽奇遇：御兽 1 个空槽 65%、2 个 80%、3 个及以上 95%；非御兽只有 1 个槽，单槽按 95% 判定，免费获得随机灵兽；槽位已满不触发。
- `/灵兽吞噬 <序号/名> [灵兽内丹] [数量|all]` 让指定灵兽吞噬储物戒中的【灵兽内丹】，每颗提供当前等级升级需求 10% 的经验（最高 Lv.50），可指定使用数量或填 `all` 一次性用完，经验溢出可正常升级，升级后立即刷新气血/攻击/防御，Lv.20/Lv.40 时照常自动进化；复活中或已满级的灵兽无法吞噬。
- `/吞噬灵兽 [序号/名]` 将指定灵兽炼化放生：该灵兽永久消失，按等级返还 `等级 × 500` 灵石与 `等级 × 250` 修为；它不消耗灵兽内丹，也不会给其他灵兽增加经验，与 `/灵兽吞噬` 是两套不同机制。
- 洞天家具【灵兽窝】只降低喂养消耗；仙灵【灵汐】只提供额外灵兽战斗属性加成，均不改变基础灵兽规则。

### 6.13 历练

```text
/历练信息
/开始历练 <路线>
/历练状态
/完成历练
/退出历练（旧名 /放弃历练 仍可用）
```

- 选择路线后开始挂机历练，全部路线时长压缩到 **15~30 分钟**（`duration` / `reward_duration` / `fatigue_cooldown` 全表 ÷2 后按分钟取整，下限 900 秒），路线有风险、时长、推荐境界和疲劳冷却。
- **列表数据（v7.8）**：`AdventureManager.build_route_list(user_id, product)` 返回 `{subtitle, facets, groups, total, open, filter}`，排序按「境界门槛降序 → 小时灵石降序」（新解锁优先），可走段与未解锁段分开；`/历练信息 [产物]` 与网页端参数候选都读它。
- 修为在同一境界下只与时长成正比（`BASE_RATE_PER_HOUR` 不随路线变），所以路线之间不按修为排序；差别在产物、灵石与风险。
- 历练期间处于「历练中」，不能开始其他占用状态的活动。

**修为模型（v7.7 起，v7.8.2 调基准）**

- `config/adventure_config.json` 的 `exp_model`：`base_rate_per_hour=0.0075`、`pill_talisman_only=true`。
- 每小时修为 = `本境界突破需求 × 0.0075 × 时长(小时) × (1 + 丹药加成 + 符箓修炼加成)`；**灵根与功法不参与**，这是与闭关唯一的分工差异。
- 0.0075 的来历：`闭关零加成 0.25% × 3`。**不是**按满配灵根×功法反推。
  旧值 0.01656 = `0.25% × 7.36 × 0.9`（7.36 = 满配灵根 3.2 × 功法 2.3），本意是「满配时历练 ≈ 闭关 90%」，
  但闭关的值随灵根/功法缩放、历练却是常数，于是零加成时历练变成闭关的 **6.6 倍**、伪灵根 **9.5 倍** ——
  灵根越差越被迫全走历练，与「历练不吃灵根，让差灵根也能跟上」的初衷相反。
- 改成零加成基准后：历练 = 闭关零加成 × **3**。灵根/功法越高，历练相对越慢
  （伪灵根 4.3 倍 → 三灵根 3.2 → 单灵根 2.3 → 天灵根 1.6 → 先天道体 0.94），
  但不再出现旧值那种 9.5 倍的失控区间；分水岭落在先天道体，只有顶级修炼天赋值得纯闭关。
- 灵石 = `(分钟 × base_gold_per_min + 等级 × level_bonus_gold + completion_bonus.gold) × 2.0`。
- 结果：零加成闭关约 400 小时突破，满配约 20 小时；零投入纯刷历练约 **133 小时**（v7.8.2 前为 60 小时）。
- 调到这一档的代价：灵石与材料不受影响，所以单位修为变贵，灵石相对更值钱；若之后灵石花不出去，单独调 `gold_multiplier`。

**一次性结算（v7.7，分段机制已迁至秘境）**

- 走完全程才发奖：`finish_adventure` 在 `scheduled_time` 之前只返回「还未走完 + 剩余时间」，不补发任何分段奖励。
- `_settle_once()` 一次算完修为、灵石、材料、装备、宠物奇遇、探索符次数、休整冷却、悬赏/任务/称号进度、奇遇判定。
- `/退出历练`：未走完直接放弃本次全部奖励，**不收违约金、不加冷却**；已到点则按完成结算。
- 后台任务 `_schedule_adventure_finish` 只负责「到点补结算」，SQL 带 `AND scheduled_time <= ?`，不会提前发奖。
- 受伤（`injury`）在整趟结束时追加一次 10 分钟休整，不按段叠加。
- 奇遇由历练产出（`base_chance=35`），秘境不再触发。

**材料掉落：路线定类别，境界定品阶**

- 60 条路线各有固定 `product`（灵植 / 矿材 / 灵液 / 妖兽 / 全产物）。专精路线只出自己那一类；「全产物」按 `category_weights`（默认 30/30/20/20）抽。
- 品阶由 `realm_bands` 按玩家 `level_index` 决定，与路线门槛无关：0~12 凡品；13~18 黄 40/玄 50/圣 10；19~24 玄 55/圣 45；25~30 玄 25/圣 78/帝 7；31+ 圣 88/帝 12。
- 圣品从 13 级起出现，是为了接住 `pill_recipes` 里从 lv12 就开始需要圣品、而秘境最早 lv18 才产出圣品的缺口。
- `drop_pools` 按「类别 → 品阶 → 材料名」组织。某类别缺该品阶时（例如妖兽类没有凡品材料），`_resolve_pool` 沿 `TIER_ORDER` 向相邻品阶回退，避免某段境界的某条专精路线掉不出东西。
- 数量由 `drop_quantity`（凡 2~5 / 黄 1~4 / 玄 2~4 / 圣 2~4 / 帝 1~1）乘 `category_quantity_scale`（灵植 1.0 / 矿材 0.8 / 灵液 0.5 / 妖兽 0.66）得出；小数部分按概率进位，不会因为取整把 0.66 吃成 1。缩放系数用来拉平四类专精的期望产出 —— 妖兽材料单价约为灵植的 2~3 倍，不缩放会导致全服只刷妖兽路线。
- 事件掉落：稳妥事件 `item_chance` 68~88；`risky` 组 70~80 且带 `extra_rolls: 1`，即每趟多判定一次（综合掉出率约 93%）。风险成本体现在 `exp_mult`/`gold_mult` 打折与 `injury` 追加 10 分钟休整，不再靠降低掉落率惩罚。
- 绝对产出对标秘境：v7.7 时长减半后，用 `ITEM_ROLLS=1`（原 2 次判定 → 1 次）抵消，避免时间减半反而让材料翻倍。
- **材料定位（v7.9）**：历练只负责修为与灵石，材料退化为副产物。`material_model.chance_scale` 由 1.2 收到 **0.33**，单位时间材料价值降到同期秘境最优档的约 **1/5**，单趟空手率约 2/3。修为/灵石不受影响；想再调只改这一个配置项。
- **品阶受路线等级封顶（v7.9）**：材料判定段取 `min(玩家境界段, 路线 min_level 段)`（`_material_band`）。旧逻辑只看玩家境界，于是 lv27 刷 lv0「灵谷采药」（15 分 / 冷却 2 分）的材料产出比刷 lv27「太初之巅」（28 分 / 冷却 18 分）**高一倍** —— 高境界靠短冷却白嫖高阶材料。现在低阶路线无论玩家多高都只出低阶材料，`cap_by_route=false` 可回退。
- 装备掉落（低/中/高档约 5%/8%/12%）与材料独立判定，`_roll_drops` 的 `rolls_bonus` 参数负责冒险事件额外判定。
- **装备品阶受路线等级封顶（v7.9.2）**：基准等级 = `min(玩家等级, 路线 min_level + equipment_model.level_cap_bonus)`，余量现为 **2**。旧逻辑是 `max(玩家, 路线)`，只兜下限没有上限，于是 lv35 刷 lv0「灵谷采药」照样掉混元先天（实测 23.9 万灵石/时，与刷 lv27 太初之巅的 21.5 万持平）；封顶后同一条路线只剩 0.34 万/时、只出凡/黄品。余量配 0 即严格按路线门槛。
- **装备掉率与材料系数解耦（v7.9.2）**：v7.9.0 把 `material_model.chance_scale` 设成 0.33 时，装备概率在同一处也被乘了一次，配置写着 5/8/12 实际只有 1.65/2.64/3.96。现在装备走独立的 `equipment_model.chance_scale`（默认 **1.0**，即配置标称值），想再降只改这个数，不动材料。
- 老配置没有 `drop_pools` / `realm_bands` 时，`_roll_material_drop` 回退到旧的 `drop_tables`（low/mid/high 三档），不会因为缺键直接不掉东西。

### 6.14 秘境

```text
/秘境列表
/秘境详情 <ID>
/探索秘境 <ID>
/探索秘境 <秘境名> <难度>
/完成探索
/退出秘境
```

- 秘境共 15 处，每处「一重 / 二重 / 三重」三档；每个难度在 `rifts` 表里独立一行（`rift_id` 唯一，`rift_key` 归组），境界门槛、时长、修为灵石、掉落表各自独立。
- **列表数据（v7.8）**：`RiftManager.build_rift_list(user_id, product)` 返回同结构的分组数据。排序依据是 `_material_value()` 算出的「单趟期望材料价值 ÷ 分钟」—— 期望 = Σ(权重占比 × 平均数量 × 目录价) × 主掉落率 × (1 + 额外掉落率)，**只计 `material_catalog` 里的材料**（掉落表里混的渡劫增益丹单件 30 万，计进去会把排序彻底带偏）。★ 以「当前可进入段的最高效率」为 100%，保证列表第一条必是 ★★★。
- 配置来源是 `config/rift_config.json` 的 `rifts`；启动时 `RiftManager.sync_rifts()` 幂等写入数据库（缺失补、改动覆盖、配置里没有的旧行删除），不需要手工改库。
- 时长：一重 20 分钟 / 二重 30 分钟 / 三重 45 分钟。**修为在 v7.7 改为象征量**：按「境界段（≤9 / ≤18 / 其余）× 档位系数（1.0 / 1.5 / 2.4）」直接配表，单趟从 50~250（炼气）到 6000~12000（合体），不吃任何修炼加成。秘境定位是材料与灵石副本，修为主产地是历练。
- 灵石维持 v7.6 的原有量级（按 `required_level` 精细缩放，顶级难度单趟 30~70 万），不随修为一起砍 —— 秘境的核心产出就是灵石与材料。
- 掉落：每档自带 `drops`（加权表）、`item_chance`（主掉落概率 70/82/92）、`extra_drop_chance`（额外掉落 0/45/70）、`equipment_chance`（装备 5/9/13~22）、`up_rank_weight`（越阶权重 1.0/0.65/0.55）。圣品材料只在 required_level ≥ 22 的秘境深档出现。
- **深档强度 `tier_yield`（v7.9.8）**：三重时长是二重的 1.5 倍，但掉落按趟判定，配置只涨 12% 的判定基数，于是**每小时**反而倒挂（实测三重 ÷ 二重 = ×0.98，天雷三重 396k/时 vs 二重 444k/时）。`tier_yield` 直接乘在单趟产出的材料数量、灵石、修为上（一重 1.0 / 二重 1.05 / 三重 **1.95**），每小时倍数 = `tier_yield ÷ 时长比`。改完三重普遍是二重的 **×1.24~1.50**（平均 ×1.34）。
- **高阶材料权重 `high_tier_weight_mult`（v7.9.8）**：只放大「该档掉落表里品阶最高」的那几件（三重 **2.0**，二重 1.15）。统一乘总产出稀释不了低阶材料，压权重才能让帝品/圣品的占比真的上升；天雷三重的帝品权重占比从 12.8% 抬到 22.7%。
- **三重装备掉率按秘境单独配（v7.9.8）**：低阶本的材料一件几百灵石，装备占单趟价值的 85~90%，提效只能落在件数上（青云 13、落日/铁狱 18、万妖/丹霞/玄冰 17）；高阶本材料与灵石占一半以上，15~16 就够。`up_rank_weight` 是「基准 +1 档」的权重（**越大越容易出高阶**，0.4 时越阶概率 9%），三重从 0.4 提到 0.55。
- **三重装备门槛 `gear_lock`（v7.9.8）**：三重要求**八格装备齐全且品阶 ≥ 该秘境门槛境界可装备的最高品阶**（`core/rift_gate.py`）。判据用秘境自己的 `required_level`，不跟玩家等级走 —— lv35 回刷青云三重只需玄品全套，否则低阶本会变成永远进不去的死档。没有用战力锁：战力 93% 来自境界基础属性、装备只占 6%，按「全套战力」卡实际是在检查格子有没有穿满，称号/永久丹还能绕过。
- 列表与详情会把这个门槛写出来：图片卡片行前加 🔒、网页行多一行「门槛 需帝品全套」、未达标时按钮置灰并从「进入」换成「需帝品全套」；`/秘境详情` 另外标出 `tier_yield`。
- **帝品秘境（v7.9 整体下移，lv25 起每级都有新帝品副本）**：天雷绝域 `25/26/27`（灵液 + 矿材）、仙墟药园 `26/27/28`（灵植 + 妖兽）、星辰铁狱 `29/30/31`（矿材）、虚空妖巢 `32/33/34`（妖兽）、混沌天渊 `35`（四类齐）。下移前首个帝品秘境要渡劫 lv31，导致合体后期炼「大乘丹」全程无帝品来源；合体期（25-27）现在靠天雷 + 仙墟凑齐四类。
- 主产物（灵植/矿材/灵液/妖兽/混合/全产物）刻意稀疏：同一境界段不会同时开放全部类别，玩家需要按目标材料选本。

**分段结算（v7.7 从历练迁到秘境）**

- `tick_settlement` 配置在 `config/rift_config.json`：`tick_seconds=300`、`tick_share=0.6`、`tick_item_chance_mult=0.6`、`final_item_chance_mult=0.4`（两者之和 = 1.0，保证拆段后整趟掉落期望不变）。
- 进入时用 `_roll_base_rewards()` 一次性 roll 出整趟修为/灵石写进 `extra_data.base_exp/base_gold`，之后再按 `tick_share` / `1 - tick_share` 拆成小结算与大结算 —— 总量守恒，不会因为拆段抖动。
- 掉落按段摊薄：`chance_scale = tick_item_chance_mult / 小结段数`；`extra_drop_chance` 是**条件概率**（在已掉落前提下多掉一份），**不能**跟着摊薄，否则期望会变成 `主×s×(1+extra×s)`。
- `settle_due()` 由 `_schedule_rift_ticks` 后台任务扫描补算，`finish_exploration` 手动结算走同一入口；`_ensure_tick_state()` 为 v7.6 及以前进入的秘境补算 `base_exp` / `ticks_total`，旧存档无需处理。
- 并发安全：大结算用 `UPDATE user_cd ... WHERE type=EXPLORING` 做 CAS 认领，抢不到的那次直接返回；分段小结用 `json_extract(extra_data,'$.ticks_done')` 做 CAS，避免手动结算与后台任务双发。
- 掉落必须先 `_grant_rift_drops()` 再 `update_player()`：`grant_item(external_transaction=True)` 只改 player 对象，由调用方统一落库。
- 进入后到时间 `/完成探索` 结算；`/退出秘境` 提前离开会保留已结算的小结，未走完部分与大结算放弃，不收违约金。
- 秘境不限次数，只受忙碌状态限制。
- **秘境不再触发奇遇**（v7.7 起奇遇统一由历练产出）；灵兽奇遇保留（御兽 1槽65% / 2槽80% / 3槽以上95%；非御兽单槽95%）。
- 装备掉落每次最多 1 件；部位按权重抽取，品阶以「玩家境界」为基准 ±1 阶、优先中间品阶，区间无可用装备时向最近品阶扩展。
- **装备品阶按秘境门槛封顶（v7.9.1）**：基准等级 = `min(玩家等级, 秘境 required_level + equipment_level_cap_bonus)`，余量现为 **2**。旧逻辑只看玩家等级，导致 lv35 刷 lv0 青云秘境也掉混元先天 —— 实测进阶本装备价值 75.5 万灵石/时，与本境界最高秘境持平。封顶后低门槛本只出低阶装备，高阶装备必须刷对应门槛的秘境；按门槛正常推进的玩家不受影响。余量配 0 即严格按门槛。

### 6.15 奇遇

历练/秘境归来可能触发奇遇，机器人给出 3 个选项：


不同选择有不同结果：可能获得神装、修为、灵石、功德/业力/气运，也可能受伤或遭反噬。选项有有效期，超时视为离开。成功抉择还有几率额外积累 1 点气运。

### 6.16 押镖与劫道

```text
/押镖
/完成押镖
/放弃押镖
/劫镖 @某人
```

- 押镖约 30 分钟，期间处于「押镖中」，全服广播。
- 镖银按大境界台阶定价：9000×境界倍率（炼气1.0→混元先天45.0，区间线性插值，±500 浮动）；押镖是经济基准（详见《经济基准表》），劫镖为玩家间转移，不计入产出。
- 送达后 `/完成押镖` 领镖银和功德；`/放弃押镖` 会扣 80% 镖银并失去本次收益。
- 劫镖消耗【迷神香】触发天道压制 PVP；护镖方气血 +10%，平局判护镖方守住。
- 高出对方 2 个大境界时禁止劫镖；分成与失败赔偿随境界差动态调整。
- 同一镖主每天最多被劫成功一次，当日不会再次被其他人劫镖。
- 【迷神香】可在百宝阁常驻轮换中购买，黑市也会较高概率刷出。
- 押镖期间不能开始其他占用状态的活动。

**符箓体系**

- `/符箓`：查看攻击、防御、控制、回复、炼丹、探索、增益、遁术八类符箓及配方；
- `/符箓书`（别名 `/可制符箓`）：只列已掌握的符图，给出实际成功率（含熟练度，符箓师另 +10%）、单张工费、材料拥有/需求、当前可画张数与卡点；
- `/符阁 符图`：符图货架。黄品符图与**全部护劫类符图**（聚灵符、避劫符、混元符）常驻不限量，其余玄品以上稀有刷新；符图与成品符同名，买符图必须写 `/购买 <符名>·符图`（如 `/购买 避劫符·符图`），只写符名买的是成品符；
- `/符箓配方`：发送全部符箓配方总览（品阶/境界/灵石/材料/成功率）；
- `/日常制符`：符箓师每日免费领取境界护劫符（Lv0–8 稳魂符 / Lv9+ 避劫符），熟练阶 ≥ 大成时每日 2 张；
- `/制符 <符名> [数量|all]`：任何生活职业都可绘制，消耗灵石与材料；数量填 `all` 时按材料、灵石与储物戒空间自动停下；不带参数会提示用法；
- `/使用符箓 <符名> [数量]`：从储物戒使用；同名符箓再次使用为**续时**（剩余时间顺延，不覆盖），一次多张按张数叠加且不设封顶；探索类符箓按次数生效且可累加次数；
- 持续时长按「用途分族 × 品阶分档」，口径对齐丹药：增益 60/120/180/360 分，炼丹 60/90/120/180 分，防御 20/30/60/90 分，遁术 20/30/45/60 分，攻击与控制 15/20/30/45 分；回复类使用即刻回血，时长仅作窗口；探索类按次数不按分钟；
- 品质加时按比例（上品 +8%、极品 +15%，不足 5 分钟按 5 分钟保底），探索类改为加次数（上品 +1、极品 +2）；
- `/我的状态`：查看当前所有限时状态的状态名、效果与剩余时间（或剩余次数），并汇总当前修炼/攻防倍率与突破加成；
- 符箓效果接入战斗、炼丹、历练、秘境，可存入储物戒、上架坊市、赠予；
- 任意已有符箓都可用 `/使用符箓`，效果按符名与品级自动推演。

### 6.19 装备强化与洗练

```text
/强化
/洗练 [武器/防具]
/炼器 洗练 <部位> <词条> <妖兽材料> [数量1-5]
```

- 强化消耗强化石，提升炼器等级，有失败风险。
- 洗练消耗洗练石，随机获得 1 条词条（暴击、吸血、反伤、气运等），最多保留 3 条，超过后替换最旧一条。
- 洗练默认优先写入当前武器实例；使用 `/洗练 防具` 可指定洗防具。指定部位没有已装备实例时会拒绝洗练。
- 词条绑定装备实例：换装/卸下后词条跟随该件装备，不会平移到新装备。未穿装备且未指定部位时，兼容旧版会写入角色全局词条。
- `/炼器 洗练` 是定向洗练：消耗妖兽材料与洗练石，成功后必定附加指定词条；同名词条替换，最多 3 条。妖兽材料品阶越高，成功率与数值越高；失败仍消耗材料。

### 6.20 魔潮天灾

全服事件，默认自动开启，管理员也可手动开启：

- 魔潮期间全服修炼效率下降 20%。
- 玩家捐献灵石推进进度；达标后全服庆典并给参与者奖励，抵御成功者获得 24 小时「天道庇佑」。
- 超时未达标会进入余毒期，继续影响修炼。
- 魔潮天灾与天魔入侵互斥，同一时间只能开启一个全服事件。

```text

```

- 活动结束时，仍潜伏的天魔获 50,000 灵石，其他正道修士获 5,000 灵石；若天魔全部被揪出，则天魔奖励取消。
- 与魔潮天灾互斥，同一时间只能开启一个全服事件。

#### 品阶与品质

物品使用统一品阶阶梯，由低到高：

```text
凡品 → 黄品 → 玄品 → 灵品 → 地品 → 天品 → 皇品 → 圣品 → 帝品 → 道品 → 仙品 → 混元先天
```

- 品阶决定物品的默认解锁境界、价格区间、配方门槛和商店稀有度；
- 装备另有“一般/良好/极佳/大师”品质，品质影响主属性倍率；
- 丹药品质影响效果倍率；部分突破丹药的品质影响突破加成；
- 符箓使用时可出现一般/上品/极品品质。

#### 材料与配方

材料配方通常只要求：

```text
类别 + 品阶 + 数量
```

不要求固定材料名。例如“灵植·凡品 ×2”可以由任意凡品灵植凑齐；“妖兽·圣品 ×5”可以由任意圣品妖兽材料凑齐。

材料来源：

- 灵植：灵田收获、历练、秘境、悬赏、百宝阁；
- 矿材：历练、秘境、悬赏、百宝阁、材料包；
- 妖兽：历练、秘境、悬赏、世界 Boss、百宝阁、材料包；
- 灵液：历练、秘境、悬赏、百宝阁、材料包；
- 帝品材料：以高阶秘境为主（天雷绝域 25 起 / 仙墟药园 26 起 / 星辰铁狱 29 起 / 虚空妖巢 32 起 / 混沌天渊 35），合体期即可凑齐四类；历练合体大乘段帝品权重 **25%**、渡劫以上段 **28%**，整体仍只作零星补充（约秘境 1/5）；另有帝品材料包；
- 特殊材料：活动、稀有掉落或特定配方。

材料包按期望材料价值÷0.8 定价，购买后随机开出 1/2/3 个（20%/50%/30%）同类别、同品阶材料；具体池子只包含物品目录中真实存在的材料。材料包共 20 档（凡/黄/玄/灵/地/天/皇/圣/帝品 × 四大类）。

道品以上丹方统一改用帝品材料：道品 2 主料 + 1 辅料、仙品 3 + 2、混元先天 5 + 3，并按用途搭配圣品辅料；混元先天额外消耗 1 枚周本专属材料「天外陨核」。

#### 妖兽材料与定向洗练

妖兽材料除了作为炼丹/制符配方材料，还可以用于装备定向洗练：

```text
/炼器 洗练 <部位> <词条> <妖兽材料> [数量1-5]
```

- 只接受妖兽类材料；
- 消耗洗练石 ×1、妖兽材料 ×数量及灵石；
- 成功后必定附加指定词条；同名词条替换，装备最多 3 条；
- 材料品阶越高，成功率与词条数值越高；失败仍消耗材料；
- 具体成功率、数值倍率和灵石消耗以游戏内结算为准。

## 8. 常见问题

### 为什么我发指令没反应？

- 群聊里通常需要 `@机器人`，或者指令以唤醒前缀 `/` 开头；
- 确认当前群在插件 `WHITELIST_GROUPS` 中，或该配置留空；
- 确认插件已启用、AstrBot 在线。

### 为什么提示「正在闭关中/历练中，无法分心他顾」？

角色处于忙碌状态。先结束当前活动（查询类指令如 `/我的信息`、`/突破信息`、`/丹药信息`、`/银行`、`/坊市` 不受影响，可随时查看）：

```text
闭关 → /出关
历练 → /退出历练（已结算奖励保留）
秘境 → /完成探索 或 /退出秘境
押镖 → /完成押镖 或 /放弃押镖
宗门任务 → /完成宗门任务
悬赏 → /完成悬赏 或 /放弃悬赏
```

找不到退出指令或卡住时，发：

```text
/解卡
```

### 买完装备为什么没有自动穿上？

装备不会自动穿戴。购买后先进入储物戒，再使用 `/装备 <装备名>`。如果提示储物戒中没有，先查看 `/储物戒`；如果提示境界不足，查看 `/物品信息 <名称>` 或 `/我的装备`。

### 洗练词条为什么换装备后还在？

洗练词条绑定在被洗练的那件装备实例上，换装/卸下后词条仍跟随原装备，不会平移到新装备。使用 `/洗练 武器` 或 `/洗练 防具` 可指定部位；未穿装备时的旧版全局词条仍会生效。

### 百宝阁为什么刷出很多高品阶物品？

百宝阁使用稀有模式：品阶越高、基础商店权重越低，入选权重越高。刷新时还会按全服最低/最高/平均境界划定品阶区间，最高境界玩家会把区间上沿抬高；线上当前 `PAVILION_TREASURE_COUNT` 为 25 件，所以高境界服会出现较多圣品/皇品。若需要低品阶更多，应调整稀有模式权重或增加每次刷新的品阶配额。

### 为什么图片卡片不出？

- 确认已安装 `Pillow`；
- 确认 `resources/` 目录完整；
- 插件配置 `IMAGE_CARDS` 是否开启；
- 图片生成失败会自动降级为文字，不影响游戏。

### 突破失败会怎样？

突破不再消耗灵石资费；失败会损失当前总修为的 10%，并有概率掉落一个大境界（不会死亡），体修跌落风险更高。突破前先看 `/突破信息`，带好破境丹。

持有回生丹时，突破失败会优先消耗一颗抵消本次境界跌落（每次突破最多挡一次），不再按比例削减属性。

### 贷款逾期会怎样？

会全服广播并掉落一个大境界（角色不会死亡）；该笔贷款随即转为坏账，避免同一笔欠款重复触发处罚。可以 `/还款 <金额>` 部分还款，先还利息再还本金；利息仍按原始本金计算，剩余应还未清零前贷款保持 `active`。身份和购买限制按剩余应还金额重新判定。

### 宗门怎么升级？

宗门等级靠宗门经验自动提升：捐献灵石、完成宗门任务、参加大比/宗门战都会增加经验。等级解锁商堂、任务堂、护山大阵，并提高命令栏上限；已有高等级建筑不会降级。

### 宗门命令没完成会怎样？

未完成固定罚 500 灵石；灵石不足时扣光现有灵石，剩余记入宗门欠款。欠款无上限，之后有灵石会自动偿还；欠款未清不能退出宗门或被踢出。

### 宗门大比怎么开？

只有宗主能发送 `/宗门大比开启`，本宗门成员在 30 分钟内 `/宗门大比报名`。报名结束后自动随机抽签单败淘汰，奇数轮空，冠军获得 10,000 灵石，没有亚军/季军。每个宗门 24 小时内只能开一次。

### 宗门战怎么打？

宗主 `/宗门宣战 <宗门名>`，双方至少 3 人，宣战费 10,000 宗门资金。自动 KOF：外门→内门→亲传→长老→宗主，败者换下一位。胜方掠夺败方每人当前灵石 20%，再按胜方贡献百分比分配。宣战方 72 小时冷却，败方 24 小时保护。

### 灵田作物为什么没了？

约 48 小时不收获会枯萎。记得定期 `/收获`，并 `/施肥` 维持肥力。

### 世界 Boss 为什么打不出高伤害？

世界 Boss 单次伤害保底 0.5%，上限为 20% + 0.8% × 境界等级（封顶 45%），每天不限次数，两次之间冷却 5 分钟；提升境界、装备、功法、五行克制和灵兽协同更有效。

### 飞升后角色没了？

飞升是转生重置，角色会重新开始；封印的传家宝可以在转生后达到筑基期解封。

### 换职业/重来？

使用 `/弃道重修 确认`：需要角色空闲、没有未结清贷款，且距离上次重修满 7 天。会清空角色本体、资产、日常任务、世界 Boss 伤害记录、坊市上架和用户冷却；宗主会自动传位或解散宗门。谨慎使用。

## 9. 管理员配置

| 配置 | 作用 |
| --- | --- |
| `WHITELIST_GROUPS` | 允许使用插件的群号列表；留空表示所有群可用；全服事件广播需要配置 |
| `BOSS_ADMINS` | 可使用 `/仙界管理`、生成 Boss、开启/结束天魔入侵、开启魔潮等管理员指令的用户 ID |
| `SHOP_MANAGERS` | 可手动刷新商店的用户 ID |
| `IMAGE_CARDS` | 图片卡片总开关和分界面开关 |

管理员 ID 用 `/sid` 获取；NapCat/OneBot 通常是 QQ 号，QQ 官方机器人是 OpenID。
