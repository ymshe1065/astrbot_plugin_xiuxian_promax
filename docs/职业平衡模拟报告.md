## 八、最终结论

### 已通过

- 非御兽七职业在 v13 方案下：
  - PvP 5回合：46.8%～53.9%
  - PvP 10回合：45.1%～53.6%
  - PvE DPS：差距 6.2%
  - EHP：坦克与输出差 5%～7.5%
- 御兽**无宠**：51.9% PvP、285,918 DPS，属于平衡范围。

### 未通过

- 御兽带任意宠物：
  - 1宠 Lv.1：99.3% PvP
  - 3宠/5宠：100% PvP
  - PvE 最高超出其他职业 128.2%
- 当前契约和喂养成本无法抵消强度：
  - 首次契约免费；
  - 1宠 Lv.1 已经 99.3%；
  - 额外3宠/5宠只要20万/40万。

### 不能上线的原因

问题不是“宠物太贵”，而是：

```text
御兽本体已接近平均 + 宠物提供额外气血/攻击/护主/协战
```

即使把宠物成本提高，免费首宠和 Lv.1 强度仍然会破坏平衡。

## 九、建议的修复顺序

1. **先砍御兽本体或宠物基础收益**
   - 降低御兽本体攻击/防御；
   - 或降低灵兽 `hp_ratio` / `atk_ratio`。
2. **多宠强递减**
   - 只有主战宠造成完整伤害；
   - 辅助宠只提供护主/控制/光环；
   - 或设置宠物总 DPS 不超过主人基础 DPS 的 30%～40%。
3. **再调获取成本**
   - 首宠免费可保留，但基础强度必须下调；
   - 额外契约费、喂养费只作为第二层门槛。
4. **复测目标**

```text
御兽无宠：45%～50%
御兽1宠：50%～55%
御兽3宠：52%～57%
御兽5宠：53%～58%
PvE DPS：不超过其他职业平均的 110%
```
