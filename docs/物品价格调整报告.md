# 物品价格调整报告

> 本文是调整方案，不直接改配置。
> 目标：建立统一价格锚点，重点修复材料包套利、炼丹成本/售价倒挂，并让材料、丹方、丹药形成可循环的经济链。

## 一、当前价格体系的主要问题

### 1. 材料包套利

当前材料包价格：

```text
凡品 90 / 黄品 360 / 玄品 1500 / 圣品 6000
```

按材料目录价、每个包平均开出 2 个材料估算：

| 材料包 | 期望价值 | 期望/售价 |
| --- | ---: | ---: |
| 灵植包·凡品 | 195 | 2.17x |
| 灵植包·圣品 | 114,400 | 19.07x |
| 矿材包·圣品 | 102,000 | 17.00x |
| 妖兽包·圣品 | 376,000 | 62.67x |
| 灵液包·圣品 | 384,000 | 64.00x |

这是当前最严重的问题：所有材料包期望值都高于售价，越高阶越夸张。

### 2. 炼丹系统有三套来源

当前实际使用的是：

```text
pill_recipes.json（42条）
```

同时存在：

```text
alchemy_config.json（旧6条）
alchemy_recipes.json（旧6条）
```

问题：

- 三套丹方数据含义重叠；
- `AlchemyManager` 只优先读 `pill_recipes_data`，另外两套实际不生效；
- 调整时容易改错文件；
- 10 条旧丹方仍使用 `灵草` 这种没有对应材料的字段。

### 3. 部分丹方材料字段不完整

`pill_recipes.json` 中：

```text
回春散·凡方 / 聚灵散·凡方
回春散·黄方 / 聚灵散·黄方
回春散·玄方 / 聚灵散·玄方
回春散·地方 / 聚灵散·地方
回春散·天方 / 聚灵散·天方
```

这些配方使用：

```json
{"灵草": 1, "灵石": 100}
```

但材料目录里没有「灵草」这个材料，只有：

```text
灵植 + 品阶
```

结果是：

- 配方成本无法按材料目录价计算；
- 实际炼制可能消耗不到正确材料；
- 商店/拍卖无法准确估价。

### 4. 炼丹利润严重失衡

按材料目录均价 + 灵石成本 + 成功率计算：

| 丹药 | 期望成本 | 当前售价 | 毛利 |
| --- | ---: | ---: | ---: |
| 造化丹 | 28,080 | 500 | **-27,580** |
| 筑基丹 | 3,025 | 6,000 | +2,975 |
| 凝婴丹 | 116,412 | 235,000 | +118,588 |
| 合体丹 | 2,974,300 | 5,530,000 | +2,555,700 |
| 大乘丹 | 3,025,322 | 10,000,000 | +6,974,678 |
| 混元丹 | 3,246,873 | 10,000,000,000 | **+99.9亿** |

问题：

- 造化丹是负收益；
- 高阶丹药利润率过高；
- 高成功率的低阶丹药反而比部分高阶丹药更合理；
- 丹药价格没有体现材料与失败风险。

### 5. 丹药价格跨度过大

当前：

```text
凡品丹药：11～54,000
圣品丹药：11,000～182,000
帝品丹药：190万～800万
道品丹药：1,000万～5,000万
仙品丹药：2亿～100亿
```

仙品内部跨度达到 **500 倍**，而玩家当前财富约 10 万～175 万。

### 6. 装备价格异常

已发现：

- 混元先天武器约 2.667 亿；
- 混元先天防具约 1.778 亿；
- 回春甲/聚灵袍为黄品但价格 43,190；
- 长春冠为玄品但价格 70,220；
- 同品阶同部位价格不单调。

### 7. 材料同类同阶价差过大

例如圣品：

| 类别 | 当前价格范围 |
| --- | ---: |
| 灵植 | 6,000～142,000 |
| 矿材 | 51,000 |
| 妖兽 | 188,000 |
| 灵液 | 192,000 |

同类同阶应该有统一基准，只允许少量稀有溢价。

## 二、新的定价框架

### 1. 材料：类别基准 × 品阶倍率

建议基准：

| 类别 | 凡品基准 |
| --- | ---: |
| 灵植 | 60 |
| 矿材 | 72 |
| 妖兽 | 90 |
| 灵液 | 120 |
| 特殊 | 300 |

品阶倍率：

| 品阶 | 倍率 |
| --- | ---: |
| 凡品 | 1 |
| 黄品 | 2.5 |
| 玄品 | 6 |
| 灵品 | 12 |
| 地品 | 25 |
| 天品 | 50 |
| 皇品 | 100 |
| 圣品 | 200 |
| 帝品 | 500 |
| 道品 | 1,500 |
| 仙品 | 4,000 |
| 混元先天 | 10,000 |

示例：

| 材料 | 品阶 | 价格 |
| --- | --- | ---: |
| 灵植 | 凡品 | 60 |
| 灵植 | 圣品 | 12,000 |
| 矿材 | 圣品 | 14,400 |
| 妖兽 | 圣品 | 18,000 |
| 灵液 | 圣品 | 24,000 |

### 2. 材料包：按期望价值定价

```text
材料包价格 ≈ 期望材料价值 × 0.75～0.85
```

平均开出 2 个材料，因此：

```text
包价 ≈ 平均材料价 × 2 × 0.8
```

示例：

| 材料包 | 建议价格 |
| --- | ---: |
| 灵植包·凡品 | 约 100 |
| 灵植包·圣品 | 约 19,200 |
| 矿材包·圣品 | 约 23,000 |
| 妖兽包·圣品 | 约 28,800 |
| 灵液包·圣品 | 约 38,400 |

所有包的期望/售价应控制在：

```text
0.75～0.90
```

### 3. 丹药：按期望成本定价

```text
材料成本 = Σ(材料价格 × 数量)
总成本 = 材料成本 + 灵石成本
期望成本 = 总成本 ÷ 成功率
建议售价 = 期望成本 × 1.15～1.35
```

要求：

- 不允许负毛利；
- 高阶丹药也不允许百倍级暴利；
- 成功率高的丹药利润略低；
- 成功率低的丹药利润略高；
- 仙品/混元作为超长期目标，可以保留溢价，但不应达到百亿。

### 4. 丹方卷轴：按丹药价值定价

```text
丹方卷轴价格 ≈ 丹药建议售价 × 8%～15%
```

低阶丹方可以有固定下限，避免价格过低。

## 三、炼丹配方调整

### 1. 统一数据源

保留：

```text
config/pill_recipes.json
```

废弃：

```text
config/alchemy_config.json
config/alchemy_recipes.json
```

或把它们保留为历史备份，但不再参与运行。

### 2. 统一材料字段

所有配方必须使用：

```json
{
  "category": "灵植",
  "tier": "凡品",
  "count": 2
}
```

禁止再使用：

```json
{"灵草": 2}
```

### 3. 修复 10 条“灵草”旧配方

| 配方 | 旧材料 | 新材料 |
| --- | --- | --- |
| 回春散·凡方 | 灵草1 | 灵植·凡品 2 |
| 聚灵散·凡方 | 灵草1 | 灵植·凡品 2 |
| 回春散·黄方 | 灵草6 | 灵植·黄品 6 |
| 聚灵散·黄方 | 灵草6 | 灵植·黄品 6 |
| 回春散·玄方 | 灵草12 | 灵植·玄品 12 |
| 聚灵散·玄方 | 灵草12 | 灵植·玄品 12 |
| 回春散·地方 | 灵草18 | 灵植·地品 18 |
| 聚灵散·地方 | 灵草18 | 灵植·地品 18 |
| 回春散·天方 | 灵草24 | 灵植·天品 24 |
| 聚灵散·天方 | 灵草24 | 灵植·天品 24 |

### 4. 配方数量与灵石成本

建议按品阶：

| 品阶 | 材料种类 | 每种数量 | 灵石成本占材料成本 |
| --- | ---: | ---: | ---: |
| 凡品 | 1～2 | 2～4 | 10% |
| 黄品 | 1～2 | 3～5 | 10% |
| 玄品 | 2～3 | 4～6 | 10% |
| 圣品 | 2～4 | 5～8 | 10% |
| 帝品及以上 | 3～4 | 6～10 | 10% |

不要继续使用“材料极多但灵石成本固定很低”的配置。

### 5. 成功率

建议：

| 品阶 | 成功率 |
| --- | ---: |
| 凡品 | 80%～85% |
| 黄品 | 70%～78% |
| 玄品 | 62%～68% |
| 圣品 | 60%～65% |
| 帝品 | 55%～60% |
| 道品 | 52%～58% |
| 仙品 | 50%～55% |
| 混元先天 | 55%～60% |

成功率不再作为唯一价格杠杆。

## 五、装备价格调整摘要

本次先定原则，具体逐件调整后续执行：

- 同品阶、同部位必须有统一基准价；
- 特殊效果装备单独乘特效系数；
- 低品阶高门槛物品（回春甲/聚灵袍/长春冠）改品阶或改价格；
- 混元先天装备从亿级压回百万～千万级；
- 新装备 `items_v2.json` 继续使用总属性预算；
- 旧装备逐步迁移到新定价，不在一次更新中全部重算。

## 六、实施顺序

1. 修复材料包价格，禁止正期望套利；
2. 统一材料目录价格，按类别 × 品阶；
3. 修复 10 条“灵草”旧配方；
4. 统一 `pill_recipes.json` 为唯一丹方来源；
5. 按新材料成本重算丹药价格；
6. 调整丹方卷轴价格；
7. 修正装备价格异常；
8. 更新 README、测试和价格校验。

## 七、验收标准

| 项目 | 标准 |
| --- | --- |
| 材料包期望/售价 | 0.75～0.90 |
| 丹药毛利 | 正毛利，不超过期望成本 40% |
| 丹方价格 | 丹药售价的 8%～15% |
| 材料价格 | 同类同阶有统一基准 |

| 旧配方 | 不再出现“灵草”字段 |
| 数据源 | 只有 `pill_recipes.json` 生效 |
