# 模拟修仙 · 职业重构总方案 v4

> 依据：
> - 《[职业平衡模拟报告.md](职业平衡模拟报告.md)》
> - 《[御兽单宠多宠补测.md](御兽单宠多宠补测.md)》
> - 《[御兽当前环境强度.md](御兽当前环境强度.md)》
>
> 本版核心调整：**被动只强化职业强项，不再用防御去补鬼修、剑修的短板，也不再用攻击去补体修、佛修的短板。**

## 一、被动设计原则

| 职业 | 基础强项 | 被动应强化 | 明确禁止 |
| --- | --- | --- | --- |
| 灵修 | 法术、灵气 | 灵气循环、法术增伤 | 不加防御 |
| 体修 | 气血、防御 | 护盾、减伤、反震 | 不加常驻攻击 |
| 剑修 | 攻击、暴击 | 剑势、暴击、破甲 | 不加防御 |
| 魔修 | 吸血、低血 | 吸血、低血增伤 | 不加防御 |
| 佛修 | 防御、团队 | 护盾、团队减伤 | 不加攻击 |
| 鬼修 | 法伤、低防 | 咒印、法穿、持续伤害 | **不加防御** |
| 御兽 | 灵兽 | 宠物协同 | 不给主人额外攻击 |

核心规则：

```text
基础系数决定职业长板
被动只放大长板
被动不能补掉短板
```

鬼修基础防御低，就不再给鬼修加防御；鬼修应该通过咒印、法穿、持续伤害来体现“低防高攻”的特色。

## 二、六职业最终基础系数

| 职业 | 攻击 | 防御 | 物理占比 |
| --- | ---: | ---: | ---: |
| 灵修 | 1.02 | 1.00 | 20% |
| 体修 | 1.02 | 1.08 | 90% |
| 剑修 | 1.05 | 0.85 | 95% |
| 魔修 | 1.03 | 0.90 | 50% |
| 佛修 | 1.02 | 1.15 | 50% |
| 鬼修 | 1.04 | 0.88 | 20% |

说明：

- 体修攻击回到 1.02，不再靠被动补攻击；
- 佛修攻击 1.02，不再靠被动补攻击；
- 剑修攻击 1.05，低于旧版 1.15；
- 鬼修攻击 1.04、防御 0.88，明确是低防高攻法系；
- 灵修保持均衡基准。

## 三、六职业专属被动

### 灵修 · 灵海回响

- 灵气上限 +8%；
- 法术伤害 +4%；
- 法术攻击恢复灵气；
- 低灵气时法术消耗降低。

定位：持续法系，不开防御，不补生存。

---

### 体修 · 不灭体

- 最大气血 +6%；
- 防御 +4%；
- 战斗开始获得护盾；
- 高气血时减伤；
- 受重击时回复少量气血。

定位：坦克。被动全部服务于承伤，**不提供常驻攻击**。

---

### 剑修 · 剑势

- 暴击率 +2%；
- 物理伤害 +3%；
- 连续攻击可叠剑势；
- 满层提高破甲。

定位：物理爆发。低防是职业代价，**不用被动补防御**。

---

### 魔修 · 噬元

- 吸血 +4%；
- 物理伤害 +2%；
- 法术伤害 +2%；
- 低气血时增伤；击杀回复。

定位：吸血续航。不补防御，靠回复维持。

---

### 佛修 · 金身

- 最大气血 +3%；
- 防御 +6%；
- 受到伤害降低；
- 组队时为队友提供减伤；
- 自身回合回复少量气血。

定位：团队防御。**不提供攻击被动**，输出低是职业代价。

---

### 鬼修 · 咒印

- 法术伤害 +4%；
- 防御穿透 +3%；
- 每次法术攻击叠加咒印；
- 每层提高法伤、降低目标法防；
- 满层造成持续伤害。

定位：低防高攻法系。**绝不补防御**；鬼修的生存来自快速击杀和咒印压制，不是站场。

## 四、六职业模拟结果

### PvP

| 职业 | 5回合制 | 10回合制 |
| --- | ---: | ---: |
| 体修 | 52.3% | 52.8% |
| 鬼修 | 52.2% | 51.4% |
| 剑修 | 51.8% | 52.0% |
| 魔修 | 51.4% | 51.2% |
| 灵修 | 50.0% | 49.2% |
| 佛修 | 49.3% | 47.1% |

全部进入 45%～55%。

### PvE

| 职业 | DPS | 定位说明 |
| --- | ---: | --- |
| 鬼修 | 302,149 | 法系输出最高 |
| 剑修 | 301,633 | 物理单体输出 |
| 灵修 | 291,448 | 法系基准 |
| 御兽（无宠） | 288,917 | 召唤师无宠下限 |
| 魔修 | 283,854 | 综合输出 |
| 体修 | 270,986 | 坦克，DPS 允许低 10% |
| 佛修 | 266,837 | 坦克，DPS 允许低 10%～12% |

这里不再要求坦克和输出 DPS 完全相等：

```text
输出职业：DPS 高，EHP 低
坦克：DPS 低 10%～12%，EHP 高 5%～7%
```

这是职业定位差异，不是数值失衡。

## 五、御兽重做

### 5.1 本体

| 项目 | 旧 | 新 |
| --- | ---: | ---: |
| 攻击 | 0.95 | 1.06 |
| 防御 | 1.00 | 1.05 |
| 物理占比 | 50% | 50% |

说明：5 回合 PvP 对宠物增益非常敏感。为了让无宠不残废、带宠又不致 100%，最终采用“本体接近平均 + 宠物小额增益”的方案，而不是把本体压到 0.85。无宠 PvP 目标 45%～50%。

### 5.2 宠物分工

| 类型 | 输出 | 功能 |
| --- | --- | --- |
| 主战宠 | 100% | 完整协战 |
| 辅助宠 | 20% | 护主、减伤、控制、光环 |
| 宠物总输出 | ≤主人单次攻击 1.5% | 硬上限（5回合PvP校准） |

多宠不再给主人增加攻击，也不再把宠物攻击按数量叠乘。  
由于当前 PvP 是 5 回合气血比例判定，宠物增伤对胜负阈值极其敏感，最终采用较低上限；后续若改成 10 回合或击杀判定，可以再提高宠物输出预算。

### 5.3 获取成本

保留：

```text
首宠免费
额外契约 100,000 灵石/只
御兽喂养 8 折
```

但成本只做门槛，不承担主要平衡。

目标：

```text
无宠：45%～50%
1宠：50%～55%
3宠：52%～57%
5宠：53%～58%
```

## 六、为什么不再用被动补短板

### 鬼修

错误做法：

```text
基础防御低 → 被动加 5% 防御
```

问题：

- 鬼修仍然是最低防御，补 5% 没有改变定位；
- 反而浪费被动预算；
- 玩家感受到的是“鬼修既不肉也不够痛”。

正确做法：

```text
基础防御低 → 保持低防
被动强化咒印、法穿、持续伤害
用输出换生存
```

### 剑修

错误做法：

```text
基础防御低 → 被动加防御
```

正确：

```text
保持低防
剑势叠暴击/破甲
用爆发换容错
```

### 体修/佛修

错误做法：

```text
基础攻击低 → 被动加攻击
```

正确：

```text
保持低攻击
被动加护盾/减伤/反震/团队减伤
用生存和团队价值换输出
```

## 七、实现设计

### 7.1 六职业被动

在统一战斗面板入口读取配置：

```json
{
  "class_passives": {
    "灵修": {"mp_max": 0.08, "spell_damage": 0.04},
    "体修": {"hp": 0.06, "defense": 0.04},
    "剑修": {"crit_rate": 2.0, "physical_damage": 0.03},
    "魔修": {"lifesteal": 4.0, "physical_damage": 0.02, "magic_damage": 0.02},
    "佛修": {"hp": 0.03, "defense": 0.06},
    "鬼修": {"magic_damage": 0.04, "armor_penetration": 3.0}
  }
}
```

注意：

- 鬼修配置中**不允许出现 defense**；
- 剑修配置中**不允许出现 defense**；
- 体修/佛修配置中**不允许出现 attack/physical_damage**；
- 代码层可以加校验，防止后续又补回冲突属性。

### 7.2 御兽宠物

修改 `PetManager.summarize_lineup`：

```text
移除多宠主人攻击加成
移除多宠宠物攻击倍率
主战宠 full
辅助宠 20% 输出
宠物总输出 cap 40%
```

修改 `CombatManager._execute_attack`：

```text
辅助宠按比例结算
达到 cap 后不再增伤
护主/减伤/控制仍生效
```

## 八、实施顺序

1. 六职业基础系数；
2. 六职业被动配置与校验；
3. 跑 PvP/PvE，验收六职业；
4. 御兽本体下调；
5. 宠物主战/辅助输出改造；
6. 单宠/多宠/成本复测；
7. 装备、丹药、符箓、团本全场景复测；
8. 备份后上线。

## 十、最终结论

```text
六职业：被动只强化长板，坦克允许输出低，输出职业不补防御
御兽：本体降为召唤师，宠物主战+辅助，多宠不叠乘
成本：只做门槛，不做主要平衡
```

核心变化：

```text
鬼修不再加防御
剑修不再加防御
体修不再加攻击
佛修不再加攻击
```

这才是“有特色且不与基础系数冲突”的职业重构。
