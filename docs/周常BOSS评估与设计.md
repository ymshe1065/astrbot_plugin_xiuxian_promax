# 周常 Boss 评估与设计（草案）

> 评估对象：当前 `世界Boss` / `团本` 的难度与生存压力。
> 参考角色：`驯兽神王`（炼虚初期）、`我是秦始皇`（化神中期）。
> 本文只做数值评估与方案设计，尚未落地代码。

---

## 0. 结论

**当前 Boss 不是“难”，而是“血厚、无威胁、无失败条件”的伤害木桩。**

| 结论 | 说明 |
|---|---|
| 单人可刷 | 两名参考角色都能单刷当前世界 Boss；其中化神中期角色因动态血量塌缩，反而 5 次攻击、约 20 分钟就能击杀。 |
| 生存压力≈0 | 5 回合内 Boss 对炼虚角色只造成约 **0.9%** 最大气血伤害，对化神角色约 **3.2%**；且结算后气血最低保留 1 点，角色不会真正死亡。 |
| 数值差距被抹平 | 伤害按 Boss 最大血量百分比结算，且有 `0.5% 保底 / 20% 封顶`，高战力角色打不出优势，低战力角色也能稳定蹭伤害。 |
| 组队无意义 | Boss 血量按活跃人数线性增长，每人伤害又按百分比结算，组队只是“并行打同一根血条”，不产生配合、分工或失败风险。 |
| 奖励与伤害脱钩 | 当前按排名档位发奖，不是按实际伤害占比分配；尾刀奖励权重过高，容易出现“抢尾刀”而不是“打输出”。 |
| 团本更简单 | 团本只调用 `calculate_damage`，没有 Boss 反击、没有死亡、没有团灭；`min_players` 只影响奖励倍率，不影响难度。 |

**建议：新增独立的“周常 Boss / 周本”玩法，不要继续在当前世界 Boss 上叠加数值。** 当前世界 Boss 的百分比结算、动态血量和 5 回合 PvP 框架，与“高生存压力、任意人数、按伤害分配”的目标天然冲突。

## 1. 现网实测

### 1.1 参考角色面板

| 物攻 / 法攻 | 2,241,505 / 2,106,071 | 249,393 / 1,068,467 |
| 物防 / 法防 | 691,118 / 694,708 | 223,678 / 209,954 |
| 暴击 / 爆伤 | 55.5% / 225.0% | 39.0% / 166.5% |
| 吸血 / 反伤 | 13.0% / 2.0% | 10.0% / 32.2% |
| 五行 | 金 | 土 |

### 1.2 当前世界 Boss 实测

测试条件：`深渊魔龙`（水属性，物抗 60% / 法抗 20%），使用当前 `WorldBossManager.simulate_battle` 的 5 回合 PvP 规则；玩家按满血、满状态计算。

| 场景 | Boss 动态血量 | Boss 攻击 | 玩家 5 回合伤害 | 占 Boss 最大血量 | Boss 对玩家 5 回合伤害 | 玩家剩余气血 | 击杀所需攻击次数 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 驯兽神王单刷 | 187,446,474 | 187,446 | 26,343,546 | 14.05% | 193,006 | 99.26% | 8 次（约 35 分钟） |
| 我是秦始皇单刷 | 35,028,237 | 35,028 | 7,925,288 | **22.63% → 封顶 20%** | 21,977 | 99.73% | **5 次（约 20 分钟）** |
| 两人同时打 | 222,474,711 | 222,474 | 28,361,480 | 12.75% | 约 0.19M / 0.35M | 均 >95% | 8 次（约 35 分钟） |

关键现象：

1. **化神中期角色单刷更快**：因为动态血量按“当前活跃玩家平均战力 × 人数 × 3”生成，单人时 Boss 只有 35M 血，伤害直接顶到 20% 封顶，5 次击杀。
2. **组队不降低每人负担**：两人时 Boss 血量涨到 222M，两人合计每次 12.75%，仍然要 8 次；和单人 8~9 次几乎一样。
3. **Boss 打不死人**：Boss 攻击力只有最大血量的 0.1%，且玩家防御按境界尺度减伤；5 回合伤害不到玩家气血的 4%，结算后气血还被强制保留至少 1 点。
4. **高战力没有意义**：20% 封顶让炼虚角色和化神角色在“每次最多打 20%”这件事上没有区别；0.5% 保底又让弱号可以稳定蹭奖励。

### 1.3 当前团本

| 项目 | 当前实现 | 问题 |
|---|---|---|
| 伤害 | `calculate_damage` 按阶段血量百分比，`0.3% 保底 / 8% 封顶` | 同样是百分比木桩，装备与境界差距被抹平 |
| Boss 反击 | 无 | 没有生存压力，不需要丹药、防御、治疗 |
| 团灭 | 无 | 人数不足只降低奖励，不影响通关 |
| 人数 | `min_players` 只影响奖励倍率 | 组队没有机制价值 |
| 阶段 | 多阶段血量 | 只是把同一根血条切成几段，没有机制变化 |

### 1.4 根因

| 根因 | 后果 |
|---|---|
| 伤害按 Boss 最大血量百分比结算 | 玩家面板只决定“打几 percent”，不决定“能不能过” |
| `0.5%` 保底 + `20%` 封顶 | 弱号能蹭、强号被封顶；单刷最多 5 次，天然可刷 |
| Boss 血量随活跃人数线性增长 | 人越多血越厚，组队不产生“人越多越容易”的正反馈 |
| Boss 攻击力 = 最大血量 × 0.1% | 攻击力与玩家气血/防御完全不在一个量级 |
| 5 回合 PvP 模拟 | 没有长线资源管理、没有死亡、没有团灭、没有丹药窗口 |
| 结算后气血最低保留 1 | 失败成本为 0，玩家可以无限试错 |
| 按排名档位发奖 | 伤害占比与奖励不挂钩，尾刀权重过高 |

## 2. 周常 Boss 设计

### 2.1 设计目标

| 目标 | 设计手段 |
|---|---|
| 每周刷新 | 周一 00:05 刷新，持续 7 天；每周一个 `cycle_id`，每个玩家每周只能领取一次奖励 |
| 任意人数准备和开始 | 1~8 人队伍，队长随时开始；人数在开始时锁定 |
| 单人基本不可能 | 单人惩罚：Boss 血量 ×1.30、伤害 ×1.25；且 20 回合硬狂暴 |
| 双人吃大量丹药才比较可能 | 双人满药目标通关率 30%~45%；不吃药 0% |
| 三人吃丹药有机会稳定成功 | 三人满药目标通关率 75%~90% |
| 四人相对稳定但仍需生存丹 | 四人满药目标通关率 92%~99%；不带生存丹 0% |
| 消除大境界差距 | 天道压制：所有人基础气血/双攻/双防拉平到同一基准境界，只保留 ±10%~15% 的养成差异 |
| 极大生存与输出压力 | 真实伤害 AoE、崩山点杀、噬元禁疗、护体盾、软/硬狂暴、终焉读条 |
| 按伤害发奖 | 灵石、材料、装备、专属材料均按实际伤害占比分配；尾刀只做额外小奖 |
| 丰厚稀有掉落 | 传说材料、境界 ±1 装备、专属材料、巨额灵石、周本称号 |

### 2.2 周期与组队

| 项目 | 方案 |
|---|---|
| 刷新 | 每周一 00:05（可配置 `refresh_weekday/hour/minute`） |
| 持续 | 7 天，下周刷新前 5 分钟停止入场 |
| 实例 | 每个队伍独立 Boss 实例，不共享血条；全服共享周伤害榜 |
| 队伍人数 | 1~8 人；推荐 2~4 人 |
| 开始条件 | 队长 `/周本开始`；至少 1 人；开始后锁定名单 |
| 每周次数 | 每人每周 3 次挑战机会；通关并领奖后不可再领奖，但可帮打 |
| 失败 | 全员阵亡或 20 回合硬狂暴 → 团灭，无通关奖励；可重试，消耗次数 |
| 门槛 | 境界 level ≥ 13（金丹）可入场；进入后属性被天道压制，实际门槛不影响强度 |

### 2.3 天道压制（核心）

**目的：消除大境界带来的基础面板差距，只保留职业、装备、功法、灵兽、丹药带来的 build 差异。**

#### 基准境界

- 每周根据全服活跃玩家境界分位数选择基准境界，默认取 **75 分位**，并向下取整到小境界。
- 也可配置固定基准，例如 `baseline_level = 22`（炼虚初期）。
- 所有玩家进入周本后，基础面板按基准境界模板重算，**不读取玩家实际修为等级**。

#### 归一化公式

设基准境界模板为 `T_hp / T_atk / T_def`（由 `realm_attributes` 生成，使用中性职业 + 基准装备预算），玩家实际面板为 `P_hp / P_atk / P_def`：

```text
ratio = P / T
factor = clamp(0.85, 1.15, 0.85 + 0.15 × ratio)
normalized = T × factor
```

- `ratio = 1` 时 `factor = 1.00`；
- 实际面板只有模板 30% 时，`factor ≈ 0.895`，仍保留约 89.5% 模板面板；
- 实际面板达到模板 2 倍时，`factor` 封顶 1.15，只保留 15% 优势。

#### 物法拆分与特效

| 项目 | 处理 |
|---|---|
| 物法拆分 | 保留玩家原物攻/法攻占比，只归一化总攻击 |
| 职业 | 保留职业被动与技能，但数值按周本预算收敛 |
| 暴击 | 基础赠送 +20% 暴击率、+50% 爆伤；个人装备/功法额外加成封顶后总暴击 ≤60%、爆伤 ≤250% |
| 吸血 | 基础赠送 +8%；总吸血 ≤20% |
| 连击/反击/闪避 | 连击 ≤30%、反击 ≤30%、闪避 ≤15% |
| 状态 | 控制类效果对 Boss 只保留 30% 命中率；Boss 自带 60% 状态抗性 |
| 灵兽 | 主战宠攻击 = 主人归一化攻击 ×8%，辅助宠 ×4%；宠物总输出 ≤ 主人 DPS 的 10% |
| 丹药 | 在归一化之后结算，是唯一可以明显突破基准面板的手段 |

#### 示例

以炼虚初期模板 `T_hp = 24.26M / T_atk = 4.30M / T_def = 1.00M` 为例：

| 玩家 | 实际气血 | 实际双攻 | 归一化气血 | 归一化双攻 | 说明 |
|---|---:|---:|---:|---:|---|
| 驯兽神王 | 26.07M | 4.35M | 约 24.5M | 约 4.30M | 高境界小幅压制 |
| 我是秦始皇 | 8.11M | 1.32M | 约 21.8M | 约 3.85M | 低境界大幅补正 |
| 差距 | 3.2 倍 | 3.3 倍 | **1.12 倍** | **1.12 倍** | 大境界差距基本消除 |

> 这样化神中期角色不会因为面板低 3 倍而无法参与，炼虚角色也不会因为面板高 3 倍而单刷。 build 差异仍然存在，但被压缩到约 10%~15%。

### 2.4 战斗机制

周本不使用当前 5 回合 PvP 判定，改为 **最多 20 回合的团队长线战**。每回合：Boss 行动 → 所有存活玩家行动。

| 机制 | 触发 | 效果 | 设计目的 |
|---|---|---|---|
| 天罚 | 每回合 | 全体受到 **6.5% 最大气血** 真实伤害（70% 真伤 + 30% 物/法伤），受狂暴层数加成 | 持续生存压力，逼迫治疗丹 |
| 崩山 | 每 3 回合 | 随机一名存活玩家受到 **16% 最大气血** 物/法伤害 | 点杀，防止无脑站桩 |
| 噬元 | 第 5/10/15 回合 | 全体 **8% 最大气血** 真伤，并获得 2 回合 **治疗 -50%** | 检测生存丹与净化/护盾 |
| 护体 | 70% / 40% 血量 | 获得 **8% 最大气血** 护盾 1 回合；期间反伤 10% | DPS 检测，防止磨血 |
| 狂怒 | 第 6 回合起 | 每回合伤害 +3% | 时间压力 |
| 软狂暴 | 第 16 回合 | 伤害 ×1.5，之后每回合再 +5% | 让“差一点”的队伍有机会但代价极高 |
| 硬狂暴 | 第 20 回合 | 全屏秒杀，直接团灭 | 硬 DPS 门槛 |
| 孤军 | 队伍人数 = 1 | Boss 血量 ×1.30、伤害 ×1.25 | 单人基本不可能 |
| 终焉 | 20% 血量 | 全屏红字警告，3 回合后若未击杀则团灭 | 最终爆发检测 |

**生存压力来源：**

- 天罚/噬元是真实伤害，防御只能减免 30% 的天罚和崩山，**丹药减伤、护盾、治疗是主要生存手段**。
- 崩山随机点名，任何一个人死亡都会降低团队 DPS，形成雪球。
- 噬元禁疗 2 回合，必须在禁疗前抬血或开盾。
- 软狂暴后治疗量跟不上，必须靠输出在 16~19 回合内结束。

### 2.5 丹药系统

**核心思路：丹药是周本的主要“付费/资源”维度，但设置上限与递减，避免无限吃药。**

| 项目 | 方案 |
|---|---|
| 携带上限 | 每人每次最多 **12 枚**：备战 6 枚 + 战中 6 枚 |
| 备战丹 | 攻击、防御、暴击、吸血、减伤等，同类 buff 叠加有上限 |
| 战中丹 | 恢复、护盾、净化、复活；自动在血量 <65% 或死亡时使用 |
| 使用方式 | 战前通过 `/周本备战` 设置丹药清单；战斗自动结算，降低群聊实时操作成本 |
| 消耗 | 真实扣除丹药背包库存；库存不足则无法开始 |
| 复活 | `回生丹 / 涅槃重生丹` 可复活一次，复活后 30% 气血；每场每人最多 1 次 |
| 治疗递减 | 第 1 枚 100%，第 2 枚 90%，……第 6 枚 50%，之后最低 40% |
| 丹毒 | 同一场战斗第 7 枚及之后的恢复丹，额外承受 5% 最大气血反噬（可选） |

#### 丹药恢复按品阶归一化

| 品阶 | 单枚恢复 |
|---|---:|
| 凡品 | 10% 最大气血 |
| 灵品 | 18% |
| 地品 | 28% |
| 天品 | 40% |
| 皇品 | 55% |
| 帝品 | 70% |
| 道品 / 仙品 / 混元先天 | 100% |

#### buff 上限

| buff | 上限 |
|---|---:|
| 攻击加成 | +60% |
| 防御加成 | +60% |
| 暴击率 | +30% |
| 暴击伤害 | +60% |
| 吸血 | +20% |
| 减伤 | 30% |

> 这样“吃大量丹药”能明显提高通关率，但不会被无限叠加破坏；双人需要接近满配丹药，四人也必须带生存丹。

### 2.6 数值公式与标定

#### 标准输出单位 D0

在基准境界下，构造一个“标准输出面板”：

- 基准境界模板气血/双攻/双防；
- 中性职业或队伍中位数职业；
- 装备按该境界 70% 预算；
- 特效按周本上限的 50%；
- 不含丹药。

用真实战斗引擎对 Boss 打 20 回合，记录每回合平均有效伤害，记为 `D0`。

#### Boss 血量

```text
Boss_HP(N) = 40 × D0 × N^0.8 × solo_mult
solo_mult = 1.30（N=1）；否则 1.00
```

- `N`：开始时的队伍人数；
- `40`：基础血量单位，可通过配置 `hp_unit` 调整；
- `0.8`：人数指数，人数越多血量增长越快，但每人分摊仍略降；
- 单人额外 ×1.3，保证单人基本不可能。

#### 为什么是 40 × D0 × N^0.8

- 单人：`40 × 1.3 = 52 D0`；满药 DPS 约 `1.6 D0`，需要 32.5 回合，超过 20 回合硬狂暴 → 基本不可能。
- 双人：`40 × 2^0.65 = 62.7 D0`；满药 DPS 约 `3.2 D0`，需要约 19.6 回合 → 卡在软/硬狂暴边缘，约 35%~45% 通关。
- 三人：`40 × 3^0.65 = 81.6 D0`；满药 DPS 约 `4.8 D0`，需要约 18.0 回合 → 约 80%~90%。
- 四人：`40 × 4^0.65 = 98.6 D0`；满药 DPS 约 `6.4 D0`，需要约 15.4 回合 → 约 95%~99%。

> 换算指数最初定为 `0.8`，用真实引擎（`_execute_attack`/`_take_turn`）标定后调整为 `0.65`：`0.8` 会让 4 人通关率仅约 45%~90%，且 3/4 人差距过大；`0.65` 下 2/3/4 人满药通关率约为 **36.6% / 85.6% / 97.1%**，与设计目标一致。

#### 目标通关率（真实引擎模拟，已按 `hp_exponent=0.65` 标定）

模拟 1000~1500 次/档，满药 = 攻击 +60%、防御 +60%（折算 30% 整体减伤）、6 枚恢复丹、1 枚复活丹；玩家 build 有 ±12% 浮动、暴击 30%~45%、爆伤 170%~210%。

| 队伍人数 | 满药通关率 | 平均回合 | 不带药 | 只带输出药 | 只带生存药 |
|---:|---:|---:|---:|---:|---:|
| 1 | **0.0%** | — | 0% | 0% | 0% |
| 2 | **36.6%** | 18.1 | 0% | 0% | 0% |
| 3 | **85.6%** | 17.1 | 0% | 0% | 0% |
| 4 | **97.1%** | 15.8 | 0% | 0% | 0% |
| 5 | 99.6% | 14.7 | 0% | — | — |
| 6 | 100% | 13.9 | 0% | — | — |
| 7 | 100% | 13.3 | 0% | — | — |
| 8 | 100% | 12.7 | 0% | 98.2% | 48.4% |

**解读：**

- **双人**：必须同时带输出丹和生存丹，且要接近满配；恢复丹人均 4~5 枚，符合“大量丹药”。
- **三人**：输出丹和生存丹都不能少，但恢复丹需求下降到约 4 枚，开始“有机会稳定”。
- **四人**：输出压力明显下降，但仍需约 3~4 枚恢复丹；不带生存丹依然 0%。
- **五人以上**：人数优势明显，但伤害占比被稀释，奖励每人变少；建议保留 8 人上限。

> 真实实现中，玩家 build 差异、暴击随机、Boss 点名、丹药品质都会让曲线更平滑；上表用于确定初始 `hp_unit`，上线后再按实际通关率微调。

### 2.7 与其他玩法的定位

| 玩法 | 定位 | 推荐人数 | 核心压力 |
|---|---|---|---|
| 世界 Boss | 日常/全服伤害木桩，人人可参与 | 不限 | 无，主要是频次与排名 |
| 团本 | 中期多阶段推进 | 2~4 | 阶段血量与奖励倍率 |
| **周常 Boss** | **高难周常，按伤害分配稀有掉落** | **2~4（支持 1~8）** | **生存 + 输出双门槛，丹药消耗** |

周常 Boss 不与世界 Boss 共用伤害百分比、动态血量或 5 回合 PvP 逻辑，避免互相污染。

## 3. 掉落与分配

### 3.1 奖励池

| 奖励 | 基准值（炼虚档） | 说明 |
|---|---:|---|
| 灵石池 | 2,000,000 | 按伤害占比分配；人数越多池越大，按 `N^0.8` 缩放 |
| 传说材料 | 每人 2~9 次 roll | 使用现有 `legend` 掉落表 |
| 装备 | 每人 1~2 件 | 按玩家境界 ±1 品阶，品质按伤害排名加权 |
| 专属材料 | 每人 1~5 个 | 新增 `天外陨核`，用于周本装备/高阶兑换 |
| 周本称号 | 首通/伤害第一 | 例如 `天外镇守者`，提供少量永久属性 |
| 首通加成 | 灵石 +50% | 每个周期首次通关 |

### 3.2 分配公式

设 `share_i = damage_i / total_damage`，`N` 为队伍人数：

```text
灵石_i = 池 × N^0.8 × (0.9 × share_i + 0.1 / N)
        × (1 + 0.35 if 伤害第一)
        × (1 + 0.25 if 尾刀)

材料_roll_i = 2 + floor(8 × share_i) + (3 if 伤害第一) + (2 if 尾刀)
装备_roll_i = 1 + (1 if 伤害第一) + (1 if 尾刀)，最多 2
专属材料_i = 1 + floor(4 × share_i) + (2 if 伤害第一)
```

> 伤害为 0 的玩家不参与分配；挂机不会获得奖励。

### 3.3 分配示例（4 人，总伤害 100%）

| 玩家 | 伤害占比 | 灵石（约） | 材料 roll | 装备 | 专属材料 |
|---|---:|---:|---:|---:|---:|
| 第一 | 40% | 1,050,000 | 2+3+3=8 | 2 | 1+1+2=4 |
| 第二 | 30% | 720,000 | 2+2=4 | 1 | 1+1=2 |
| 第三 | 20% | 480,000 | 2+1=3 | 1 | 1+0=1 |
| 第四 | 10% | 300,000 | 2+0=2 | 1 | 1+0=1 |

> 尾刀额外奖励从独立奖池出，不扣其他人的份额；避免“抢尾刀”导致总奖励通胀。

### 3.4 失败补偿

| 结果 | 奖励 |
|---|---|
| 团灭 | 10% 灵石 + 1 次材料 roll（伤害 ≥5% 才有），无装备/专属材料 |
| 超时/逃遁 | 同上 |
| 通关但未领奖 | 正常按伤害分配；每周只能领一次 |
| 已领奖后帮打 | 无掉落，仅计入周伤害榜；可给少量“侠义”代币（可选） |

#### 真实气血写回与重伤

周本战斗使用归一化面板，但战斗损耗不能完全脱离真实角色：

| 项目 | 规则 |
|---|---|
| 损耗比例 | `1 - 战斗剩余气血 / 归一化最大气血` |
| 写回公式 | `真实战后气血 = max(1, 真实当前气血 - round(真实最大气血 × 损耗比例))` |
| 不回血 | 结果不会高于战斗前真实气血；低血量进入周本不会被“治满” |
| 重伤 | 真实战后气血 ≤20% 触发 `RecoveryManager.is_injured` |
| 开战限制 | `/周本开始` 提示重伤成员；`/周本确认` 二次校验全队，任一成员重伤则拒绝开战且不扣次数/丹药 |
| 战报 | 结算展示逐人战后气血、比例与重伤标记 |

### 4.5 战斗实现建议

不要直接复用 `player_vs_player` 的 5 回合判定。建议新增：

```text
WeeklyBossManager.run_battle(run, members) -> BattleResult
  for round in 1..20:
    apply_boss_mechanics(round)
    for member in alive_members:
      damage = simulate_player_turn(member, boss)
      member.damage += damage
      maybe_use_pill(member)
    check_deaths_and_revive()
    check_enrage_and_wipe()
```

- 玩家回合复用 `CombatManager._execute_attack` 的物法双轨、暴击、连击、吸血、灵兽逻辑；
- Boss 回合单独实现 AoE/点杀/禁疗，不套用 PvP 的 `_take_turn`；
- 每回合只输出摘要（总伤害、Boss 血量、死亡/复活、机制提示），避免 20 回合刷屏；
- 战斗结果写入 `log_json`，`/周本状态` 可查看最近 5 回合。

## 5. 验收用例

| 用例 | 预期 |
|---|---|
| 单人满药挑战 | 通关率 ≤2%，绝大多数在 20 回合硬狂暴团灭 |
| 双人满药挑战 | 通关率 30%~45%；恢复丹人均 ≥4 枚 |
| 三人满药挑战 | 通关率 75%~90% |
| 四人满药挑战 | 通关率 92%~99% |
| 任意人数不带药 | 0% 通关 |
| 只带输出丹、不带生存丹 | 0% 通关（4 人也不应稳定） |
| 只带生存丹、不带输出丹 | 0%~20% 通关（4 人可极限磨过，但不稳定） |
| 低境界角色参与 | 归一化后气血/双攻与高境界差距 ≤15% |
| 高境界角色单刷 | 不会因为面板高而轻松单刷；单人惩罚生效 |
| 伤害第一/尾刀 | 额外奖励从独立池出，不扣其他人份额 |
| 每周重复领奖 | 第二次领取被拒绝，提示“本周已领取” |
| 储物戒满 | 掉落进入“储物戒已满”提示，不丢失 |
| 团灭 | 发放 10% 灵石 + 1 次材料 roll，无装备 |
| 断线/重启 | 进行中的 run 可恢复或标记过期；已通关未结算可补结算 |

## 6. 风险与调参

| 风险 | 处理 |
|---|---|
| 归一化后低境界玩家仍缺功法/装备特效 | 基础赠送 +20% 暴击、+50% 爆伤、+8% 吸血；保证能打出基础输出 |
| 高 build 玩家突破上限 | 特效硬上限 + 丹药 buff 上限；`D0` 用中位数 build 标定 |
| 双人通关率过高/过低 | 优先调 `hp_unit`（40 → 38/42），其次调 `solo_hp_mult` 和恢复丹递减 |
| 四人仍然太简单 | 提高 `hp_exponent`（0.8 → 0.85）或增加“每多一人 Boss 减伤 +2%”；不建议直接加血量，会让双人先死 |
| 战斗太长、群聊刷屏 | 每回合只发摘要；20 回合后强制结算；支持 `/周本状态` 查看 |
| 丹药库存压力过大 | 周本掉落加入恢复丹/材料；或允许用灵石在周本商店补货 |
| 玩家挂机蹭奖励 | 伤害为 0 不参与分配；伤害 <5% 无失败补偿 |
| 小号刷奖励 | 每周领奖唯一约束 + 归一化后小号没有面板优势 + 门槛 level 13 |

## 8. 一句话总结

**当前 Boss 的问题不是数值不够高，而是“没有失败条件、没有生存压力、伤害与面板脱钩”。周常 Boss 必须做成“归一化面板 + 长线团队战 + 真实伤害 + 丹药资源 + 20 回合硬门槛 + 按伤害分配”的独立玩法，才能同时满足单人不可能、双人吃丹、三人稳定、四人仍要生存丹的目标。**
