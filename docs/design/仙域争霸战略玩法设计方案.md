## 1. 设计目标与非目标

### 1.1 目标

1. **半自动**：单次交互 1~3 分钟；攻城等长过程"下令即走"，随时可介入手操。
2. **策略深度集中在少数决策点**：招谁、派谁做什么、打哪里、何时亲自下场、如何利用 ZOC/合围/地形/计略。
3. **抢点动力**：据点产出主玩法资源（灵石/材料/装备）；反向严格隔离。
4. **活的世界**：NPC 自动演进 + 三级随机事件 + 羁绊叙事，避免死服。
5. **网页沙盘唯一载体**：交互上限高，支持拖拽部署、实时战役、浏览器通知。

### 1.2 非目标

| 不做 | 原因 |
|---|---|
| QQ 端指令/图片卡片 | 评审定案 |
| 实时 RTS 微操 | 回合制窗口已足够 |
| 主玩法数值输入 | 隔离红线（唯一例外：主城重建消耗灵石，§8.7） |
| 统一/固定胜利条件 | **开放玩法**（v5 定案）：赛季到时积分结算；主城可花灵石重建，无淘汰 |
| 无限持久世界 | 赛季制解决滚雪球 |
| 附庸/傀儡等复杂外交 | 初版四态（敌对/中立/结盟/停战） |
| 跨服世界 | 一实例一世界 |
| 水军/水战 | 河流已作地形瓶颈+渡河惩罚，专门水战 ROI 低（v5 定案） |
| 天气系统（风向影响火攻等） | 随机性过强易挫败手操；火攻已有森林加成（v5 定案） |
| 野战工事（野外箭塔/营寨） | 与 ZOC 功能重叠，据点建筑已承载（v5 定案） |
| 叛变携城 | 破坏势力信任基础，负面体验大于策略深度（v5 定案） |
| 多兵种混编军团 | v4 已定单军团单兵种，混编稀释克制可读性（v5 复核维持） |

## 3. 资源体系（经济隔离核心）

### 3.1 新玩法资源（自闭环）

| 资源 | 获取 | 消耗 | 备注 |
|---|---|---|---|
| **霸权币** | 据点回合产出、布政/贸易任务、战役胜利、事件 | 招募、练兵、建筑、行军补给、俸禄、外交赠礼 | 与灵石严格隔离，不可互兑 |
| **灵谷** | 灵谷田、屯田、丰收事件 | 部队每回合维持；断粮加速消耗 | 粮仓上限；运粮队转运可被劫 |
| **军资** | 灵脉矿、修筑、商队 | 练兵、建筑、攻城器械、势力科技 | 铁木合并 |
| **募将令** | 寻访、战功商店、事件、稀有据点 | 极品/传世招募 | 稀缺资源 |
| **战功** | 击杀兵力、战役胜利、讨伐魔潮、单挑胜、围城迫降、手操获胜加成 | 战功商店（主玩法资源唯一稳定通道）、续命灵丹、赛季荣誉结转 | 个人货币 |

### 3.2 主玩法产出（单向流出，防通胀）

| 产出 | 来源 | 分配 | 防通胀 |
|---|---|---|---|
| 灵石 | 据点每回合 `等级 × 类型系数` | 100% 归产出玩家钱包 | **个人日限额**（默认 500 万，可配置）；超额占点边际递减（§5.6） |
| 材料 | 灵脉矿/遗迹低概率、战功商店 | 当日据点贡献榜前 X 名 | 限定中低阶 |
| 装备/装备实例 | 战功商店高价（遗迹首占掉落 v4.5.2 起封存） | 个人 | 赛季限量、获得绑定 |
| 丹药/符箓 | 坊市概率、丰收事件 | 个人 | 限量 |

**个人贡献度**来源：驻守该据点、在该据点执行任务、参与该据点攻防战役、围城出兵；按 7 日滑动窗口计算占比。

> **隔离红线**：主玩法境界/装备/属性/丹药不进入任何公式；转生次数/称号仅作外观与名将池解锁荣誉项。
>
> **唯一例外（v5 用户授权）**：势力主城陷落后的「重建据点」消耗主玩法**灵石**（§8.7）——灵石由此单向流入本玩法作为销毁口（sink），不产生任何反向输出，不破坏隔离原则。

### 3.3 个人钱包与势力开销

| 账户 | 归属 | 内容 | 支取权限 |
|---|---|---|---|
| 个人钱包 | user_id | 铜钱 / 粮草 / 精铁 / 灵石、募将令、战功、待领产出 | 本人 |
| NPC 内部国库 | faction_id（仅 NPC） | 国库币 / 灵谷 / 军资 / 灵石储备（💎） | 仅 NPC 经济 AI 使用，玩家不可存取 |

> **v4.5.7 玩家势力去国库**：玩家势力**不再设国库**。科技研究、迁都、俸禄、主城重建、和谈赔款、赎回俘虏等一切势力开销**直接从玩家钱包结算**，不再需要「先把资源捐入国库」；据点产出、灵石、商路收益、坊市货款、掠夺与秘藏也直接进玩家钱包。旧存档的 `strategy_factions.treasury_json` 会在下一次世界 tick 按成员人数均分退回钱包并清空。NPC 势力保留内部模拟国库，仅用于其发展、出征与坊市供货。

> **v4.5.2 联盟经济彻底隔离**：联盟**只共享外交效果与协战类军事效果**（太尉全军攻、祭酒计略/托管智谋、协战/额外行军/盟友道路免粮）。经济经营类——据点产出、灵石分成、招募品质、俸禄与科技研发——全部按**本势力**独立结算；盟主或盟友的司徒、中郎将、科技都不会给其他成员提供加成或代付。

### 3.4 经济预算示例（验证闭环）

以"中期玩家、所在势力占 6 据点、本人任太守"为例的**日均收支**（96 tick/日，15min/tick）：

| 收入项 | 日均（示例） | 支出项 | 日均（示例） |
|---|---|---|---|
| 据点分配（6 点 × 均 70 币/tick × 70% × 个人贡献 15%） | ≈ 4,400 币 | 官职俸禄（在任官职约 10~50 币/人/tick，96 tick/日，势力主钱包支付） | ≈ 1,000~2,000 币 |
| 个人任务（4 次 × 800 币） | ≈ 3,200 币 | 练兵补充（战损 500 兵/日） | ≈ 1,500 币+600 粮 |
| 战役/围城战功折算 | ≈ 500 币等值 | 建筑分摊 | ≈ 800 币 |
| 灵石产出（6 点份额，顶到日限额前） | ≤500 万灵石 | 计略/招募 | ≈ 1,000 币 |
| **净结余** | 温和为正 | 大战期转负 → 驱动"以战养战" | |

结论：和平期小 surplus（养成感），战争期赤字（逼迫抢点/权衡），闭环成立。

## 4. 角色系统

### 4.1 三类角色

| 职责 | 定位 | 主属性 | 部队中作用 | 势力中作用 | 单挑 |
|---|---|---|---|---|---|
| **武将** | 战斗核心 | 武勇/统率 | 主将首选；攻防系数；**唯一可主动发起单挑** | 讨伐/劫掠/练兵/守城 | ✅ 唯一发起方 |
| **军师** | 战术谋略 | 智谋/气运 | 副将提供战术技能与**托管 AI 强度** | 计略/侦察/贸易/科技研究 | ❌ 可应战 |
| **内政官** | 生产建设 | 政务/魅力 | 随军后勤（粮耗 -20%、伤兵恢复 +50%），攻击系数 ×0.5 | 布政/屯田/修筑/寻访/外交 | ❌ 可应战 |

- 编队：1 军团 = 主将 1 + 副将 0~2 + 兵力；职责不可转；候选池按 武:军:政 = 4:3:3 刷新，"举荐信"（战功 200）定向刷新职责。

### 4.2 六维属性

| 维度 | 影响 |
|---|---|
| 统率 | 防御系数、守城加成、士气上限、携粮量；**超编阈值**（带兵上限由官职决定，§4.5/§7.5，兵力>统率×20 士气恢复 -10%） |
| 武勇 | 攻击系数、单挑战力、先手概率、破城伤害 |
| 智谋 | 战术威力、计略成功率、托管 AI 强度、侦察精度 |
| 政务 | 任务产出、建造速度、民心恢复 |
| 魅力 | 招募品质、忠诚增长、外交/劝降成功率 |
| 气运 | 事件吉凶、暴击/闪避、单挑变数、战利品掉率 |

|---|---|---|
| 凡品（白） | 120~180 | 普通池 |
| 良品（绿） | 180~240 | 普通池 |
| 珍品（蓝） | 240~300 | 高级池 |

### 4.5 羁绊网（借鉴全面战争：三国 guanxi）

| 羁绊 | 形成条件 | 效果 |
|---|---|---|
| 同道 | 同职业初始概率生成 | 同军团士气 +3 |
| 知遇 | A 执行寻访招募到 B | 双方忠诚 +10；同势力时 B 任务效率 +10% |

## 5. 大地图与据点系统

### 5.1 世界结构

- **一服一世界**；节点+边网络图；行军沿边每回合 1~2 条边（机动 × 地形）。
- 初始 **36 节点**（模板 24/36/52），`config/strategy_world.json` 存坐标/类型/地形/邻接表；每赛季随机选图+随机化 NPC 分配。
- **连通性（铺路）**：军团只能沿己方/盟友/中立节点连通路径行军；敌方节点挡路需拔除或绕行。
- **战争迷雾**：仅可见 己方/盟友节点及其 1 步邻接的"概况"（归属/等级），驻军/库存精确值需侦察任务或鬼修隐匿侦查；敌方军团在迷雾中显示为"?"棋子（进入己方视野才揭示兵力）。

## 7. 战斗系统（战役）

### 7.1 两态模型

| 形态 | 触发 | 节奏 |
|---|---|---|
| **围城态** | 军团进驻敌据点下达攻城 | 跨 tick 自动推进，可下线，随时可手操介入 |
| **会战态** | 野战遭遇 / 围城介入 / 守方出击 / 讨伐 / 切磋 | hex 棋盘回合制（手操或模拟） |

### 7.2 围城态：自动攻略推进（已定案：手操获胜直接攻克；允许多军团叠加）

```
下令攻城 → 围城态（持久，跨 tick）
  每 tick：城防 -= 攻方攻城强度（Σ各军团：兵力/100 × 器械(1~3) × 武将系数(0.8~1.5)）
          攻方 -= 城防反击（箭塔+守军强度 × 60%，多军团分摊）
          双方粮耗照常；每 3 tick 双方角色伤势 +5
          守方被合围 → 断粮判定（§5.6）；民心 ↓、周边产出 -10%
  ↓
手操介入窗口（任何时刻）：
  在线参战方收弹窗（WS + 浏览器 Notification + 面板红点）
  「亲自督战」→ 90 秒备战 → 会战态（hex）
     攻方手操获胜 → 城防清零【立即攻克】+ 掠夺 +10% + 战功 ×1.5
     守方手操获胜 → 攻方击退 1 节点、围城解除、攻方士气 -20
     手操失败/超时 → 损失照常结算，退回围城态
  ↓
无人手操 → 城防归零城破 → 守方选择：
  ① **巷战一回合**（v5 统一定义：背水一战，攻 +30%/防 -30%，模拟结算）
  ② 直接投降（保全 50% 兵力，角色被俘概率见 §7.9）
  巷战败/投降 → 据点易主、库存被掠 30%、守方角色按 §7.9 被俘判定（城陷档 40%）
围城上限 20 tick（5h）：未破且无人手操 → 攻方粮尽撤退（角色伤势 +10）
```

- 多军团可同时围攻（强度叠加、反击分摊）；后到军团自动加入围城序列。
- 围城期间守方盟友可派军团驰援（进入节点即触发野战会战）。

### 7.3 会战态：六边形战术棋盘

**坐标与地图生成**：

| 项 | 方案 |
|---|---|
| 坐标系 | odd-q 偏移坐标（奇数列下移半格）；hex 距离用 cube 坐标换算 |
| 尺寸 | 野战 13×9；攻城 15×11（含城墙弧线+护城河）；关隘 9×11（狭长走廊） |
| 生成 | `map_seed = hash(battle_id)` 服务端生成；按据点地形模板分布：高地 1~2 处（靠中央随机）、森林斑块 15~20%、河流战场含 1 条渡河线、沼泽 ≤8% |
| 公平性 | 双方部署区**旋转对称**（180°），地形生成后做对称校验，不对称度 >10% 则重掷 seed |
| 可复现 | seed + 指令序列可完整重建战报回放 |

**流程**：

```
会战创建 → 备战窗口（野战 5 分钟 / 围城介入 90 秒）
  WS 弹窗推送 → 各方选手操/托管（逐军团；离线自动托管）
部署阶段：手操拖拽入部署区 hex；托管按军师智谋自动部署+选阵型
  阵型：锋矢(攻+10%)/鹤翼(包抄判定+1方向)/方圆(防+15%)/雁行(远程伤+10%)
回合制（手操 30s/回合超时托管；全托管瞬时模拟）：
  先手序 = 主将武勇 + 御兽/鬼修修正 + d10，逐军团行动：移动 → 行动（攻击/技能/防御/撤退）
  单挑窗口：第 1~3 回合武将可发起斗法（§7.8）
结束：一方总兵力<30% 或 主将被俘/全灭/被完全合围 5 回合 → 溃败（善后见 §7.6）
结算：战功/掠夺/俘虏(§7.9)/伤兵转化/伤势/精锐值 → 战报
```

### 7.4 ZOC 与包抄合围

| 机制 | 规则 |
|---|---|
| ZOC | 军团对相邻 6 hex 形成控制区；**刚性**：敌移动进入即停止；剑修每场 1 次突破 |
| ZOC 取消 | 河流格、己方军团所在格的邻接 ZOC 取消（友军通道）；森林降级**半刚性**（禁 ZOC 格间直通）。水淹使河流临时变沼泽期间按沼泽计，不再取消 ZOC |
| 拦截攻击 | 敌从己方 ZOC 格离开（撤退/绕行）→ 一次拦截（体修锁定型 ×1.5） |
| 夹击/合围 | 受击时统计邻格敌军 n：n=1 ×1.0；n=2 夹击 ×1.15 且士气-2；n≥3 合围 ×1.3 且士气 -5/tick、禁撤退 |
| 完全合围断粮 | 6 邻格全被敌占/敌 ZOC 覆盖持续 5 回合 → 兵力 -8%/回合、士气 -15；可投降（保 30% 兵力、角色高概率被俘）或死战 |
| 撤退封锁 | 被合围者强行撤退承受双倍拦截 |
| **设伏（v5 新增）** | 隐匿行军军团（鬼修/御兽）进入森林格可"设伏"（每场 ≤2 处）：敌军进入相邻格即触发伏击——伏方首回合先手、被伏方士气 -10；侦察任务/鬼修侦查可提前排雷揭示 |

**合围战例**（文字推演）：

> 玩家 A 剑盾步军团（1200 兵）正面钉住敌方重甲军团（1800 兵）于平原 hex E5（正面仅 ×1.0，A 劣势）。A 的盟友 B 率飞剑队（机动 5）绕行森林（半刚性 ZOC 可穿行）于第 3 回合抵达 E5 侧后 D6 —— 敌重甲受击时邻格敌军 n=2 → **夹击 ×1.15**；第 4 回合 A 的军师 legion 进占 F6，n=3 → **合围 ×1.3 + 敌士气 -5/tick + 禁撤退**。重甲机动 2 无法脱出 ZOC 封锁，5 回合后被合围断粮判定，选择投降：B 势力获 540 俘虏兵源转化 + 战功，敌主将被俘（劝降检定开启）。

**编成规则（v5 定案）**：

- **单军团单兵种**（克制、擅长、显示都清晰明确）；多兵种配合通过**多军团协同**实现（钳形夹击/合围/ZOC 连锁，§7.4）。
- **一将一军团、多将多军团同场**：一场战役中每方可派多个军团（多名主将各领一军）参战；军团并发槽 = 2 + 势力等级/2；手操时在己方各军团间切换操作。
- **兵力规模**：固定下限 **100**；上限由**主将官职**决定（无官职 1500 / 中郎将·太守 2000 / 司徒·祭酒 2500 / 势力主·太尉 3000，见 §4.5 官职表）。统率不再决定上限，但**超编软惩罚**保留其成长价值：兵力 > 统率×20 时视为"超编"，士气恢复 -10%、托管 AI 决策质量降一档。
- **补兵规则（v5 新增）**：军团驻于**己方据点**时可从驻军池划拨补员（1 tick 完成，老兵值按骨干制保留）；**野外不可补兵**——强化"打完要回城"的攻防节奏。
- **换将交接（v4.5.1 新增）**：军团处于驻守状态时可替换主将并重选 0~2 名随行。新主将可为**内政官**或**重伤角色**（重伤可任，濒死/陨落不可）且位于军团驻地，随行角色仍须能行动（健康/轻伤）。本军团现役成员可互相改任（副将提拔为主将、主将降为随行）。交接不消耗铜钱/粮草/精铁，兵力、携粮、士气与老兵精锐保留，换下角色回归空闲并留在驻地。新主将带兵上限沿用官职/太守/兵营规则；现有兵力超过新主将上限时**拒绝交接**（需改选上限更高的主将，或解散后按低兵力重编）。**重伤主将出征/操练需至少 1 名健康或轻伤随行**。
- **随军驻守任务（v4.5.4 新增）**：军团处于**驻守（idle）**状态时，主将与随军将领可在军团当前据点执行**本地任务**；侦察/劫掠/运粮等远征任务仍须空闲角色。任务期间角色 `status='task'` 但保留在军团名册，军团仍可补员/操练。**出征、撤退、出击/手操参战、讨伐匪寨**前自动中断全军团在途任务（按召回口径结算），角色恢复随军状态后再出发；任务自然结束/主动停止/体力耗尽/据点失效等路径也会优先恢复 `status='army'`，避免误变 idle 造成重复派遣。换将交接、解散军团前同样先中断在途任务。
- 器械作为军团的"附件"随攻城军团出征（占用军资，不占兵种位）。
- **成本口径（v4.0.24 核对）**：编军 = 兵力 × 兵种募兵铜钱/粮草（破城槌另计铜钱，兵学 L2 造价 -30%），补员沿用同一价目，操练 500 铜钱；**编军、补员、操练、出征、撤退、解散均不消耗精铁**，精铁只用于箭塔/粮仓/据点升级/科技与「纵火」计略。并发军团槽 = `concurrent_base + 势力等级 / 2`（默认 2 起）。

### 9.3 决策评分公式（实现基准）

```
# 每 tick 对每个候选目标节点 T：
output_score(T)  = Σ(资源产出价值折算币) × 性格经营权重(0.5~1.5)
strategic_score(T) = 30·是关隘 + 20·在商路上 + 50·与敌方核心城邻接
                   + 40·占领后可对某敌形成合围断粮 + 25·切断敌商路
threat_score(T)  = 守军战力/己方可集结战力 × 50 + 城防/1000 × 20 + 敌1步内军团战力比 × 30
distance_cost(T) = 最短连通路径边数 × 5
utility(T) = (output_score + strategic_score − distance_cost) × aggression/100 − threat_score
出征条件：max utility > 10；选 utility 最高目标；集结最近 2 据点兵力（守家底线：每据点留 30% 驻军）
内政分配：内政官→政务最高项任务；武将→练兵/讨伐；军师→侦察(开战前)/研究(和平期)/计略(对宿敌)
撤退：军团兵力<30% 或断粮 → 撤最近己方节点；被合围 → 投降判定（保存角色优先，名将必投降保命）
合纵：见 §9.4；橡皮筋：世界和平>24h → 魔潮/流亡事件权重↑
```

### 9.4 合纵制衡

任一玩家势力霸权值（占点加权：仙城3/关隘2/其余1）> 全图 40% → 全 NPC 对其侵略系数 ×1.5 + "合纵檄文"世界事件（全服公告；中立玩家可领"讨逆任务"，战功加倍）。降至 30% 以下解除。

> 威胁值、非接壤减益、寡头霸主例外、自主宣战 / 停战与战争狂热的细化算法见
> `docs/design/仙域争霸_NPC威胁值与战略外交设计.md`（已实施：v4.6.1 / 游戏 v8.1.0）。

### 9.5 难度补偿

NPC 产出 ×1.15~1.3（可配置）；不突破兵力/体力/伤势规则（NPC 名将同样会死——玩家斩杀 NPC 传世名将同样触发全服公告、进英烈祠陈列并授予"斩名将"称号，是重要爽点）。

## 14. Tick 调度与性能

| 项 | 方案 |
|---|---|
| 战略回合 | 15 min/tick（配置 10~30）；`_schedule_strategy_tick()` |
| tick 顺序 | ①任务/计略结算（含细作营救推进）→ ②产出与分配（日限额）→ ③**围城推进**（城防/断粮/手操窗口广播）→ ④行军（含溃逃/追击/俘虏转移）→ ⑤会战触发 → ⑥NPC AI（含匪寨劫掠）→ ⑦事件掷点/到期 → ⑧伤势/体力/忠诚/**俘虏忠诚衰减**/羁绊演化 → ⑨落盘 + WS 增量广播 |
| 耗时预算 | 单 tick 目标 <200ms（36 节点 ×10 势力纯内存）；超时告警日志 |
| 幂等恢复 | `last_tick_at` 落盘；重启补跑 ≤8 tick（超出只结算产出跳过 NPC）；tick 全程持世界锁，玩家写操作遇锁返回 423 重试 |
| 会战会话 | 独立内存会话+每回合落盘；超时/掉线托管兜底；服务器权威 |
| DB | 现有 aiosqlite 串行连接，tick 内批量事务 |

### 26.2 酒馆招募错位修复

**现象**：玩家看到旧页面候选（如「珍品·武将」）并点击招募，实际入册「良品·内政官」。

**根因**：`recruit()` 内部调用 `_tavern()`，候选到期时会**静默重掷**列表；随后仍以旧页面传入的 **序号** 索引新列表，造成同名序号错位，且无任何提示。

**修复**：
- `recruit(..., expected_roll, expected_name)`：本次读取触发重掷（`roll_seq` 变化）→ 返回 `ok=false, refreshed=true`，提示重新选择，**不扣费**；显式校验失败同样拒绝。
- 重掷结果保留（返回失败而非抛错，避免整单回滚导致反复触发重掷）。
- 酒馆快照下发 `roll_seq`；前端到期禁用按钮、按钮携带 `roll + name`、动作失败自动重拉快照。
- 招募纳入 `strategy_audit`，便于回溯「谁在哪个 roll 招了谁」。
