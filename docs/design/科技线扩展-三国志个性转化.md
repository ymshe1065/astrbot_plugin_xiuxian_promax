## 2. 转化原则（结合我方系统，映射到可落地的钩子）

| 单挑 | 战斗单挑触发 | 新增 `duel_rate_bonus` |
| 俘虏 | `roll_captures`/`_capture_char` | 新增 `capture_bonus`/`no_capture` |
| 异常免疫 | 我方"混乱/止步/挑拨"≈ hex 状态（惑敌/挑衅/压制） | 新增免疫键 |
| 火 | hex `SKILLS["fire"]`（`forest_mult`）、火攻技能 | 新增 `fire_damage_mult`/`fire_def_mult` |
| 计略 | `plot_success_rate`/`_settle_plot_task`/`plot_expose` | 已有，扩效果/天数/反制 |

| 医疗 | 疗伤任务/伤兵恢复 | 新增 `heal_mult` |

| 登庸/外交 | 酒馆招募/外交好感 | 新增（或归入第 4 线，见 §7） |

| 城防 | `city_defense_max`/反击 | 新增 `counter_dmg_mult`/城防恢复 |
| 经验 | `gain_exp`/研究经验 | 新增 `exp_mult` |

**与规划的偏差（口径说明）**：
- 「单挑率 +15%」改为「单挑获胜士气 +5、致伤 +10%」：我方单挑为**玩家主动发起**（非自动触发），无「单挑率」概念，故折算为获胜收益。
- 「俘获 +30% / 己方不被俘」并入军事 L7 无双（原 §3 未显式归属，此处补齐）。
- 「角色俸禄 -20%」：俸禄系统已接线（`faction.salary`，角色官职 + 据点太守每 tick 从国库扣铜钱），`salary_mult` 在本势力发薪时生效。**v4.3.17 补充**：发薪另叠乘角色个性/特技——「贪财」×1.20、「节俭」×0.85（`R.char_salary_mult`），即 `实扣 = 基础 × 科技仁政 × 角色个性/特技`。
- 红色（负面）个性本次未引入。
