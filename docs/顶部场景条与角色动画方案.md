# 顶部场景条与角色动画方案

> 状态：**原型完成，尚未接入 `app.js`**。产物在 `webchat_room/static/anim/`，生成器在 `scripts/anim/`。

## 1. 目标

网页聊天室顶部一整条区域做成横版像素场景：小人常态走动，触发指令时切换到对应场景并做对应动作。

- 常态：一直往前走，背景向左滚
- 闭关：停下打坐，云气托举
- 世界 Boss：前冲御剑对砍
- 百宝阁 / 坊市 / 器阁：进店左右张望看货
- 炼丹：炉前炼药
- 静室：脚下法阵运功

接入时把这段渲染逻辑搬进 `app.js` 即可，不新增任何图片请求。

## 3. 尺寸规格

```
逻辑画布  480 × 72（宽度随屏宽自适应，高度固定）
放大倍率  3× 整数（物理高度 216px）
地平线    y = 58
角色      48×48 画布，中心 x=24，脚底对齐 y=44，实际占高 37px
```

顶栏从原来的 160px 增高到 **216px**。已确认可接受。

三条硬约束：
1. **必须是整数倍放大**，否则像素会被插值糊掉
2. **图块宽 = 屏宽**，一屏内不会看到同一丛竹子两次
3. 场景元素全部按 `GY`/`LH` 参数化，改高度不用改绘制代码

## 6. 接入 webchat_room 需要改三处

### ① 握手时带场景

`webchat_room/room_server.py` 的 `hello` 报文里加一个字段，让新连接一进来就是当前场景：

```python
{"type": "hello", ..., "act": current_act}
```

### ② 指令触发时广播

在指令处理链路里，场景切换时推一条：

```python
await broadcast({"type": "act", "act": "boss", "ts": time.time()})
```

### ③ 前端加一个 case

`webchat_room/static/app.js` 的 `onMessage` 里，`case "hello"`（约 598 行）之后加：

```js
case "act":
  setScene(m.act);
  break;
```

`setScene()` 内部做三件事：换场景配置、切角色动作、缓动滚速（闭关要慢慢刹住，Boss 要猛提速）。

### 指令 → 场景映射

| 指令 | scene | 备注 |
|---|---|---|
| 闭关 / 打坐 | `cultivate` | 待确认实际指令名 |
| 挑战世界 Boss | `boss` | 已有指令 |
| 百宝阁 | `shop` | 已有指令 |
| 炼丹 | `alchemy` | 待确认 |
| 储物戒 / 静室 | `bag` | 待确认 |
| 探索 / 秘境 | `cave` | 待确认 |
| 其余（默认） | `wild` | 兜底 |

映射表建议单独放一个 `ACT_MAP` 常量，指令前缀命中即可，未命中一律回落 `wild`。
