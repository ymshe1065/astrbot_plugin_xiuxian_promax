# 模拟修仙 · 新手引导

> 适用：AstrBot 插件 `astrbot_plugin_xiuxian_promax`。
> 定位：**第一次玩的人**照着做就能跑通核心循环；同时作为 AI 向导（`/chat`）引导新手的唯一口径。
> 具体数值以游戏内显示和 `/修仙帮助` 为准，本文只讲顺序、思路和最容易踩的坑。

## 给 AI 的引导要求

- 先确认对方**境界、职业、当前状态**，再给建议；不知道就先问，或引导发 `/我的信息`。
- 一次只给 **2～3 个动作**，每条都写成可以直接复制发送的指令（带 `/`）。
- 不要堆术语、不要贴长表格；玩家追问再展开。
- 本文和知识库都没写的数值，直接说「以游戏内当前配置为准」，**不要编造**。
- 玩家明显卡住（提示忙碌、指令没反应）时，优先给 `/解卡` 和 `/修仙诊断`。

## 1. 30 秒认识这个游戏

这是一个在群里发指令玩的**放置类修仙游戏**，按 QQ 号（或网页账号）单独存档。

```text
创建角色 → 签到 / 闭关攒修为 → 突破境界
→ 做日常、历练、秘境拿资源 → 提升装备 / 丹药 / 灵兽 / 宗门
→ 打世界 Boss、参与魔潮 → 飞升转生 → 再来一世
```

三条最重要的认知：

1. **境界 > 装备**。突破境界带来的提升远大于换一件装备，修为永远优先花在突破上。
2. **放置为主**。闭关、历练、灵田、洞天都是挂机产出，上线只是「收菜 + 决策」。
3. **状态会锁指令**。闭关中、历练中、押镖中时大部分动作指令会被拒绝，先结束当前活动。

## 2. 第一天：按顺序发这几条

```text
/我要修仙 剑修        创建角色（灵修/体修/魔修/剑修/鬼修/佛修/御兽）
/我的信息             看面板：境界、修为、灵石、气血
/签到                 每日签到，领灵石
/闭关                 开始挂机修炼
/出关                 结束闭关，结算修为
/器阁                 看能买的武器
/购买 青铜剑          买第一件装备（先进储物戒）
/装备 青铜剑          穿上它（不穿等于没买）
/突破信息             看下一次突破需要多少修为、成功率多少
/修仙帮助             全部指令速查
```

创号会送启动资金，新手引导四步（创号 → 闭关 → 历练 → 突破）每步还有额外奖励，跟着提示走完即可。

职业怎么选：

| 职业 | 一句话定位 |
| --- | --- |
| 剑修 | 极致物理输出，上手最简单 |
| 灵修 | 均衡，法术路线 |
| 体修 | 血厚防高，但突破失败风险更高 |
| 魔修 | 吸血爆发 |
| 鬼修 | 诡道、持续伤害 |
| 佛修 | 反伤肉盾 |
| 御兽 | 靠灵兽协同作战，后期强 |

选错了不用慌：`/弃道重修 确认` 可以重来（保留仙缘点与永久加成，有冷却与条件限制）。

## 3. 第一周日程

### 每天上线必做（30 秒）

```text
/签到
/洞天收取
/收获
/领取利息
/灵眼收取
```

懒得记就发 `/一键日常`，它会按顺序提示你。

### 挂机线（随时开着）

```text
/闭关 … /出关         修为主产地之一，出关才结算
/开始历练 <路线>      修为产出最高的玩法，走完才发奖
/探索秘境 <ID>        按境界选本，吃丹药符箓加成，不吃修炼加成
/种植 <草> /施肥      灵田产出炼丹材料
```

长时间不上线就开自动代理，让它自动续接：

```text
/自动代理 押镖
/自动代理 宗门任务
/自动代理 灵田
/自动代理 秘境
/自动代理 施肥
/代理状态             查看代理配置
/关闭代理 [任务]      关掉
```

### 攒钱与变强

```text
/存灵石 <数量>        存银行吃利息（别把灵石全放身上）
/丹阁 丹药            买修为丹 / 突破丹
/服用丹药 <名> [数量] 吃丹
/强化 /洗练           装备养成
/我的装备             看已穿戴与属性
```

### 社交与团队

```text
/宗门列表 /加入宗门 <名字>    加入宗门拿藏经阁加成、做宗门任务
/宗门任务 /完成宗门任务
/切磋 @道号 /决斗 @道号       和群友比划
/挑战世界Boss                全服 Boss，每天不限次，两次之间冷却 5 分钟
```

## 4. 玩法体系地图

| 线 | 什么时候接触 | 核心指令 | 常见误区 |
| --- | --- | --- | --- |
| 修炼线 | 创号即开 | `/闭关` `/出关` `/突破信息` `/突破` | 闭关忘了出关；突破不带破境丹 |
| 经济线 | 第一天 | `/签到` `/存灵石` `/领取利息` `/坊市` | 灵石全放身上不放银行 |
| 生产线 | 有丹方/材料后 | `/丹阁` `/炼丹` `/学习丹方` `/制符` `/我的灵田` | 灵田约 48 小时不收会枯萎 |
| 装备线 | 第一天 | `/器阁` `/购买` `/装备` `/强化` `/洗练` | 买了装备不穿；洗练词条绑定装备实例 |
| 战斗线 | 筑基前后 | `/切磋` `/决斗` `/挑战世界Boss` `/探索秘境` | 越级硬打；不看五行克制 |
| 社交线 | 第二天起 | `/加入宗门` `/宗门任务` `/拜师` `/双修` | 接了宗门命令不做会罚灵石并记欠款 |
| 活动线 | 跟着全服广播 | `/魔潮状态` `/抵御魔潮` `/周本` `/江湖事件` `/讨伐` | 活动有时限，错过等下一轮 |
| 长线 | 高境界 | `/飞升` `/仙缘商店` `/弃道重修` | 飞升是转生重置，角色会重新开始 |
| 高风险线 | 有余钱再碰 | `/黑市` `/盘口` `/藏宝图` `/矿脉` `/古方` | 长期期望为负，亏损自负 |

## 5. 新手最常犯的 10 个错

1. **买了装备没穿**：购买后先进储物戒，必须再发 `/装备 <名字>`。
2. **闭关不出关**：修为要 `/出关` 才结算，一直闭着等于白挂。
3. **突破前不看信息**：先 `/突破信息`，带上破境丹再 `/突破`；失败会损失当前总修为的 10%，并有概率掉一个大境界（不会死亡）。
4. **灵田不收**：约 48 小时不收获会枯萎，记得 `/收获` 并 `/施肥`。
5. **灵石乱放**：`/存灵石` 存银行才有利息，身上现金被劫镖/掠夺会损失。
6. **贷款逾期**：会全服广播并掉一个大境界，尽量 `/还款` 保持结清。
7. **修为溢出忘了领**：修为超过当前境界门槛的部分可折算加成，用 `/领取溢出`。
8. **忙碌状态硬发指令**：提示「无法分心他顾」时，先 `/出关`、`/退出历练`、`/完成探索`、`/完成押镖`、`/完成宗门任务`。
9. **不看境界门槛**：装备、功法、秘境、商店都有境界要求，`/物品信息 <名字>` 可以看门槛。
10. **宗门命令不做**：未完成固定罚灵石，灵石不足会记成宗门欠款，欠款未清不能退宗。

## 6. 卡住怎么办

```text
/解卡          强制回到「空闲」，放弃当前进度但不会死
/修仙诊断      体检当前账号，告诉你哪里不对劲
/chat <问题>   直接问 AI 向导，例如：/chat 我为什么突破老是失败
/chatall <问题> 带上当前频道近期聊天记录一起问
/修仙帮助      全部指令速查
```

指令完全没反应时：确认群聊里带了唤醒前缀 `/` 或 @机器人；确认该群在插件白名单内；确认插件已启用。
