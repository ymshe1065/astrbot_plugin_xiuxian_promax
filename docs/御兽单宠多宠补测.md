# 御兽单宠/多宠补测报告

> 测试基础：18级、无装备、无丹药、v13职业方案；御兽技能槽位 5 个。
> 宠物：火灵狐，按 PetManager 的基础比例和 Lv20/Lv40 进化倍率近似。
> 结论：**御兽带宠后严重超模，当前获取成本不足以抵消强度，不能直接上线。**

## 一、御兽槽位与获取成本

18级御兽槽位：

```text
2 + 境界档位3 = 5 个灵兽槽
```

获取成本：

| 宠物数量 | 契约费用 | 说明 |
| ---: | ---: | --- |
| 1只 | 0 | 御兽首次契约免费 |
| 3只 | 200,000 | 额外2只 × 100,000 |
| 5只 | 400,000 | 额外4只 × 100,000 |

纯喂养到指定等级的金币上界：

| 宠物数量 | Lv.20 | Lv.40 |
| ---: | ---: | ---: |
| 1只 | 9,880,000 | 82,160,000 |
| 3只 | 29,640,000 | 246,480,000 |
| 5只 | 49,400,000 | 410,800,000 |

说明：

- 喂养成本按 `等级×1000×0.8` 灵石、每次 +100 经验、升级需 `等级×500` 经验计算；
- 灵兽还能通过主人修为的 30% 自动获得经验，所以实际金币成本可能低于上界；
- 但**首次契约免费**，且 Lv.1 宠物已经能产生巨大战力，金币成本不能作为唯一平衡手段。

## 二、PvP 补测

5回合制，交换先后手，每职业对 300 场，取对六职业平均。

| 灵兽等级 | 1宠 | 3宠 | 5宠 |
| ---: | ---: | ---: | ---: |
| Lv.1 | 99.3% | 100.0% | 100.0% |
| Lv.3 | 99.6% | 100.0% | 100.0% |
| Lv.20 | 100.0% | 100.0% | 100.0% |
| Lv.40 | 100.0% | 100.0% | 100.0% |

即使只带一只**刚契约的 Lv.1 灵兽**，御兽对六职业平均胜率已经达到 99.3%。

这说明问题不在宠物等级或喂养成本，而在：

1. 御兽基础面板本身已经接近平均；
2. 灵兽再额外提供气血、攻击、护主和每回合协战；
3. 宠物数量带来的收益没有足够强的递减；
4. 首次契约免费，最低成本即可获得完整战斗收益。

## 四、成本调整后是否合理

按纯金币喂养计算：

```text
1宠 Lv.20：9,880,000 灵石
3宠 Lv.20：29,640,000 灵石
5宠 Lv.20：49,400,000 灵石
```

而当前玩家灵石大约在 100 万～200 万区间，纯喂养到 Lv.20 已经远超普通玩家资产。

但问题在于：

- 首次契约免费；
- Lv.1 宠物已经有 99.3% PvP；
- 灵兽还能靠主人修为自动升级；
- 额外 2 只宠物只要 200,000 灵石。

所以**加钱不能解决平衡**：低价档已经超模，高价档只是更超模。

## 五、必须调整的方向

### 1. 不能只调获取成本

即使把额外宠物契约费提高到 100 万，第一只仍然免费；而第一只已经 99.3%。

### 2. 必须先砍御兽基础或宠物基础收益

可选方案：

- 降低御兽本体的攻击/防御，使无宠状态低于平均；
- 或降低灵兽的 `hp_ratio` / `atk_ratio`；
- 或对“有宠御兽”设置总伤害预算，宠物伤害最多占主人输出的固定比例。

### 3. 多宠必须强递减

当前机制：

```text
多宠总伤害系数约 1/(1+0.4×(n-1))，再叠加每只灵兽 +5% 攻击
```

5宠时总收益仍然接近 2.5 倍单宠。

建议改为以下之一：

- 只有主战宠造成完整伤害，辅助宠只提供护主/控制/光环；
- 多宠伤害系数改为更强的递减；
- 设置“宠物总输出不超过主人基础 DPS 的 30%～40%”的硬上限。

### 4. 获取成本只作为辅助门槛

可以保留：

- 首次契约免费；
- 额外宠物 100,000；
- 喂养 8 折；

但必须同时满足：

```text
1宠御兽 PvP ≈ 50%～55%
3宠御兽 PvP ≈ 52%～57%
5宠御兽 PvP ≈ 53%～58%
```

成本只能决定“获得速度”，不能决定“是否超模”。

## 六、建议的下一步

1. 先砍御兽本体基础攻击/防御，或降低灵兽基础比例；
2. 把多宠伤害改为强递减或辅助宠不输出；
3. 重新跑 Lv.1/3/20/40 × 1/3/5 宠的测试；
4. 再把契约/喂养成本作为第二层门槛；
5. 最终目标：

```text
1宠：50%～55%
3宠：52%～57%
5宠：53%～58%
PvE DPS：不超过其他职业平均的 110%
```

## 七、当前结论

v13 对无宠物职业已经平衡，但**御兽带宠后不成立**：

```text
1宠 Lv.1：PvP 99.3%
3宠 Lv.1：PvP 100%
5宠 Lv.1：PvP 100%
```

获取成本无法抵消这个强度。御兽需要单独做宠物基础收益和多宠递减，不能直接套用 v13 的御兽基础面板。
