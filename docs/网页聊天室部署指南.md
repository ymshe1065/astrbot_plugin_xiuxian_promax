# 网页聊天室（webroom）依赖安装与部署指南

> 适用版本：插件 v3.35.6 / 数据库 v60 / AstrBot 4.29.x
> 相关文档：[路线 B 实现方案](路线B实现方案_自建聊天室+自定义适配器.md) · [玩家游戏指南](xiuxian_player_guide.md)

网页聊天室由插件内置的 `webroom` 平台适配器和 `webchat_room/static/` 单页前端组成：

- **不需要 Node.js / npm / 前端构建**，页面由 Python 服务直接托管；
- **不需要单独启动前端进程**，聊天室与 AstrBot 在同一个进程、同一个 asyncio 事件循环内；
- 前端源码在 `webchat_room/static/`，改完刷新浏览器即可（已做 `no-cache` 协商缓存）；
- 自己发出的公屏消息可点气泡下方「⋯」选择 **撤回 / 重新编辑**；撤回会广播给所有在线端，重新编辑会把原文带回输入框。
- 储物戒物品芯片点开的小菜单统一使用纯物品名：「回收 / 赠予」会先弹数量窗（默认全部，装备赠予默认 1 件）；「装备」仅对装备/功法显示，槽位已占用时会弹出替换列表（戒指双槽、功法三栏）。

## 一、先选部署方式

| 目标 | 推荐方式 | 需要完整 AstrBot | 机器人真实回复 | 适合场景 |
|---|---|---|:---:|---|
| 正式使用，与 QQ 端共用存档 | **方式一：现有 AstrBot + 本插件** | ✅ | ✅ | 生产部署、已有机器人 |
| 本机没有 AstrBot，但要真实链路 | **方式二：独立运行时** | ✅ | ✅ | 本地联调、演示、测试 |
| 只调页面样式、看板、气泡 | **方式三：轻量 UI 预览** | ❌ | ❌（仅演示桩） | 前端开发 |

> 只有方式一/二会加载修仙插件、读写真实存档、执行真实指令；方式三只起房间服务，不会执行游戏逻辑。

## 二、依赖清单

| 依赖 | 版本要求 | 用途 | 何时需要 |
|---|---|---|---|
| Python | 插件 3.10+；AstrBot 4.29.x 要求 **3.12** | 运行插件与框架 | 全部方式 |
| AstrBot | **4.29.x**（实测 4.29.4） | 消息流水线、平台适配器、WebUI | 方式一、二 |
| `aiohttp` | >= 3.9 | HTTP + WebSocket 房间服务 | 全部方式 |
| `aiosqlite` | >= 0.19 | 玩家存档数据库 | 方式一、二 |
| `Pillow` | >= 9.0 | 图片卡片/帮助图渲染 | 方式一、二 |
| `tzdata` | >= 2024.1 | 时区数据（Windows 尤其需要） | 方式一、二 |
| `lsof` | 系统自带 | `scripts/astrbot_local.sh` 查端口 | 方式二（Linux/macOS） |
| 浏览器 | 现代浏览器 | 访问聊天室页面 | 全部方式 |

插件依赖已写入仓库根目录 `requirements.txt`：

```text
aiosqlite>=0.19.0
aiohttp>=3.9
Pillow>=9.0.0
tzdata>=2024.1
```

安装到 **AstrBot 所在的那个 Python 环境**（不是系统 Python）：

```bash
# 把 <ASTRBOT_VENV> 换成实际的 AstrBot 虚拟环境路径
<ASTRBOT_VENV>/bin/pip install -r /path/to/astrbot_plugin_xiuxian_promax/requirements.txt
```

> 不需要安装 Redis、MySQL、Nginx；账号、头像、玩家存档都落在本地 SQLite/文件目录。
> 聊天消息只做在线广播，不落库；离线期间的消息不会补发。
> 图片渲染字体已随仓库放在 `resources/`，无需额外下载。

## 三、方式一：现有 AstrBot + 本插件（推荐）

### 3.1 安装插件

把仓库放到 AstrBot 的插件目录，目录名建议与插件名一致：

```bash
cd /path/to/AstrBot/data/plugins
git clone https://github.com/iqapi/astrbot_plugin_xiuxian_promax.git
```

开发时也可以软链，改代码后重启即可生效：

```bash
ln -s /path/to/astrbot_plugin_xiuxian_promax \
      /path/to/AstrBot/data/plugins/astrbot_plugin_xiuxian_promax
```

Windows 没有软链时，直接复制目录或使用目录联接：

```bat
mklink /J "C:\AstrBot\data\plugins\astrbot_plugin_xiuxian_promax" "D:\code\astrbot_plugin_xiuxian_promax"
```

### 3.2 安装依赖

使用 AstrBot 运行时自带的 Python 安装，避免装到系统 Python：

```bash
/path/to/AstrBot/venv/bin/pip install -r \
  /path/to/AstrBot/data/plugins/astrbot_plugin_xiuxian_promax/requirements.txt
```

桌面客户端 / 启动器版 AstrBot 的 Python 路径不同，可在 WebUI「关于/运行环境」查看，或直接使用其内置终端执行 `pip install`。

### 3.3 启用 webroom 平台

1. 重启 AstrBot，确认日志出现：

   ```text
   [webroom] 平台适配器注册成功
   【修仙插件】网页聊天室(webroom)平台适配器已就绪
   ```

2. 打开 AstrBot WebUI（默认 `http://127.0.0.1:6185`，以启动日志为准）；
3. 进入「平台适配」→「新增平台适配器」；
4. 类型选择 **`webroom`**（修仙网页聊天室）；
5. 填写：

   | 字段 | 建议值 | 说明 |
   |---|---|---|
   | `host` | `127.0.0.1` | 仅本机访问；局域网访问填 `0.0.0.0` |
   | `port` | `6198` | 聊天室端口，与面板端口不同 |

6. 保存并启用，无需再单独建房间（服务端固定使用 `room_main`）。

> 也可以直接编辑 `data/cmd_config.json` 的 `platform` 数组（注意保留已有平台）：

```json
[
  {
    "id": "webroom",
    "type": "webroom",
    "enable": true,
    "host": "127.0.0.1",
    "port": 6198
  }
]
```

### 3.4 配置白名单与播报

在 WebUI 的插件配置中设置 `ACCESS_CONTROL`，或在
`data/config/astrbot_plugin_xiuxian_promax_config.json` 中修改：

```json
{
  "ACCESS_CONTROL": {
    "WHITELIST_GROUPS": ["room_main"],
    "BROADCAST_GROUPS": ["room_main"],
    "SHOP_MANAGERS": [],
    "BOSS_ADMINS": []
  }
}
```

| 配置 | 作用 | 不填的后果 |
|---|---|---|
| `WHITELIST_GROUPS` | 允许使用插件的「群」，网页房间 ID 为 `room_main` | 留空 = 所有群可用；填了但没有 `room_main` = 网页指令被拒 |
| `BROADCAST_GROUPS` | 世界 Boss/团本/拍卖/江湖事件等播报目标 | 留空会沿用白名单；两者都空则事件仍生成但网页收不到播报 |
| `BOSS_ADMINS` | 可手动生成 Boss/团本的管理员 | 网页玩家用户名为 `web_<账号名>`，绑定 QQ 后为该 QQ 号 |

### 3.5 打开并验证

浏览器访问 <http://127.0.0.1:6198/>，首次使用先在登录页注册账号，然后进入主聊天室。

```bash
curl -s http://127.0.0.1:6198/api/health
# {"ok": true, "adapter": true, "accounts": 1, "rooms": {}}
```

`adapter: true` 表示适配器已注入；`rooms` 在有人上线后会出现 `room_main`。

## 四、方式二：没有 AstrBot，从零搭独立运行时

以 Linux/macOS 为例，固定目录 `~/.astrbot-runtime`（可用 `ASTRBOT_RUNTIME` 覆盖）。

### 4.1 安装 Python 与 AstrBot

```bash
# 需要 Python 3.12（AstrBot 4.29.x 要求）
python3.12 -m venv "$HOME/.astrbot-runtime/venv"

"$HOME/.astrbot-runtime/venv/bin/pip" install -U pip
"$HOME/.astrbot-runtime/venv/bin/pip" install "AstrBot==4.29.4"
```

> 首次安装依赖较多（实测约 600+ MB），网络慢可换镜像源。
> 不锁定版本直接 `pip install AstrBot` 也可以，但本插件的适配器按 4.29.x 内部接口编写，升级大版本前请先测试。

### 4.2 放置插件并安装插件依赖

```bash
mkdir -p "$HOME/.astrbot-runtime/data/plugins"

ln -s /path/to/astrbot_plugin_xiuxian_promax \
      "$HOME/.astrbot-runtime/data/plugins/astrbot_plugin_xiuxian_promax"

"$HOME/.astrbot-runtime/venv/bin/pip" install -r \
  /path/to/astrbot_plugin_xiuxian_promax/requirements.txt
```

### 4.3 首次启动并启用 webroom

AstrBot 以**当前工作目录**作为根目录，必须先 `cd` 到运行时目录：

```bash
cd "$HOME/.astrbot-runtime"
"$HOME/.astrbot-runtime/venv/bin/astrbot" run -p 6199
```

首次启动会生成：

```text
~/.astrbot-runtime/
├── data/
│   ├── cmd_config.json                 # 平台、面板等配置
│   ├── config/                         # 插件配置
│   ├── plugins/                        # 插件目录（软链）
│   ├── plugin_data/                    # 玩家存档 SQLite
│   └── webroom/                        # 聊天室账号、头像、图片
└── venv/                               # AstrBot 运行环境
```

打开 `http://127.0.0.1:6199` 登录面板（初始账号 `astrbot`，密码见启动日志），按 **3.3 / 3.4** 添加 `webroom` 平台并配置白名单，然后 `Ctrl+C` 停止。

### 4.4 用脚本日常启停

```bash
scripts/astrbot_local.sh start      # 后台启动 AstrBot + 聊天室
scripts/astrbot_local.sh status     # 查看 6199 面板 / 6198 聊天室
scripts/astrbot_local.sh logs 80    # 查看最近日志
scripts/astrbot_local.sh restart    # 改代码/改配置后重启
scripts/astrbot_local.sh stop       # 停止
```

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `ASTRBOT_RUNTIME` | `~/.astrbot-runtime` | 运行时根目录 |
| `ASTRBOT_DASHBOARD_PORT` | `6199` | 面板端口，通过 `astrbot run -p` 覆盖配置文件 |
| `ASTRBOT_ROOM_PORT` | `6198` | 仅用于 `status` 检查，需与 webroom 平台配置一致 |

> **端口注意**：AstrBot 配置文件里的 `dashboard.port` 默认可能是 `6185`，但启动脚本用 `-p 6199` 覆盖，所以本机实际面板是 **6199**。聊天室始终由 webroom 平台配置决定（默认 6198）。

### 4.5 Windows 等价操作

`astrbot_local.sh` 依赖 `lsof`，仅适用于 Linux/macOS。Windows 可直接运行：

```powershell
$env:ASTRBOT_RUNTIME = "$HOME\.astrbot-runtime"
Set-Location $env:ASTRBOT_RUNTIME
& "$env:ASTRBOT_RUNTIME\venv\Scripts\astrbot.exe" run -p 6199
```

后台常驻可用「启动器」、任务计划程序或 `nssm`。

## 五、方式三：轻量 UI 预览（不装 AstrBot）

只想调 `webchat_room/static/` 的页面、气泡、看板时使用：

```bash
python3 -m venv .venv
.venv/bin/pip install "aiohttp>=3.9"

.venv/bin/python scripts/dev_webroom.py           # 仅房间服务
.venv/bin/python scripts/dev_webroom.py --demo    # 附带演示机器人回复
.venv/bin/python scripts/dev_webroom.py --port 6200 --host 0.0.0.0
```

- 访问 <http://127.0.0.1:6198/>；
- `--demo` 会自动创建演示账号 **`demo / demo123456`**（昵称「演示道友」）；
- 不加 `--demo` 时在页面自行注册；
- 脚本用轻量桩替换 `astrbot.api.logger` 与数据目录，**不加载修仙插件、不读写真实存档、不执行指令**；
- 因默认同样占用 6198，使用前先 `scripts/astrbot_local.sh stop`，或改用 `--port 6200`。

## 六、运行配置与数据位置

### 6.1 端口

| 服务 | 默认端口 | 配置位置 | 说明 |
|---|---|---|---|
| 网页聊天室 | `6198` | `cmd_config.json` → `platform[].port` | HTTP 页面 + WebSocket + `/media` 图片 |
| AstrBot 面板 | `6199`（脚本） | `astrbot run -p` / `dashboard.port` | WebUI 管理后台 |

同一个端口同时提供：

| 路径 | 用途 |
|---|---|
| `/` | 单页聊天室 |
| `/api/health` | 健康检查 |
| `/api/register`、`/api/login`、`/api/me` | 账号 |
| `/api/commands`、`/api/arg_options` | 指令目录与参数候选 |
| `/ws` | WebSocket（`?token=<登录 token>`） |
| `/media/<file>` | 机器人回复图片 |
| `/avatar/<file>`、`/cards/<file>` | 头像与卡片图片 |

### 6.2 数据目录

| 路径 | 内容 | 是否需备份 |
|---|---|---|
| `data/plugin_data/astrbot_plugin_xiuxian_promax/xiuxian_data_lite.db` | 玩家存档（与 QQ 端共用） | ✅ |
| `data/webroom/accounts.db` | 网页账号、密码哈希、QQ 绑定 | ✅ |
| `data/webroom/secret.key` | 登录 token 签名密钥 | ✅ |
| `data/webroom/imgs/` | 机器人回复图片缓存 | 可选 |
| `data/webroom/avatars/` | 玩家上传头像 | 可选 |
| `data/config/astrbot_plugin_xiuxian_promax_config.json` | 插件配置 | ✅ |
| `data/cmd_config.json` | AstrBot 平台配置 | ✅ |
| `data/logs/`、`astrbot.log` | 运行日志 | 排障时 |

### 6.3 玩家身份

| 场景 | `get_sender_id()` | 说明 |
|---|---|---|
| 未绑定 QQ | `web_<账号名>` | 网页独立存档 |
| 已绑定 QQ | 该 QQ 号 | 与 QQ 端共用同一份玩家存档 |

账号名注册后不可作为身份随意更改；改昵称只影响显示。

## 七、网络访问与安全

默认 `host=127.0.0.1`，**只有本机能访问**。需要局域网/公网访问时：

1. 把平台配置的 `host` 改为 `0.0.0.0`；
2. 放行 6198 端口（云服务器安全组 / 本机防火墙）；
3. Docker 部署需额外发布端口：

   ```bash
   docker run -p 6198:6198 -p 6185:6185 ...
   ```

   容器内 `host` 不能是 `127.0.0.1`，否则宿主机无法访问。

公网部署建议：

- 用 Nginx/Caddy 反向代理并启用 HTTPS，WebSocket 需转发 `Upgrade` / `Connection` 头；
- 网页注册是开放的，若不想公开，可在反向代理层加访问控制，或注册后关闭入口；
- **不要**把 AstrBot 面板（6199/6185）直接暴露公网，面板权限远高于聊天室；
- 登录 token 有效期 7 天，修改密码不会自动踢掉已登录连接，必要时重启服务。

Nginx 关键配置示例：

```nginx
location / {
    proxy_pass http://127.0.0.1:6198;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_read_timeout 3600s;
}
```

## 九、常见问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 6198 打不开 | 平台未启用 / 端口被占 | 看日志是否有「房间服务已启动」；`lsof -i :6198` 查占用 |
| 平台类型里没有 `webroom` | 插件未加载或注册失败 | 确认插件已启用、日志有注册成功；重启整个 AstrBot |
| 页面能开，但发指令没反应 | 白名单不含 `room_main` | `WHITELIST_GROUPS` 加 `room_main` 或留空 |
| 收不到 Boss/拍卖播报 | `BROADCAST_GROUPS` 未配 | 加 `room_main`，或留空让它回退白名单 |
| 聊天室图片 404 | 媒体目录无文件 / 反向代理未转发 `/media` | 检查 `data/webroom/imgs/` 与代理规则 |
| 面板打不开 6185 | 脚本用 `-p 6199` 覆盖了配置 | 访问 6199，或改 `ASTRBOT_DASHBOARD_PORT` |
| 轻量预览没有修仙回复 | `dev_webroom.py` 本来就是桩 | 需要真实回复请用方式一/二 |
| 依赖报 `No module named aiohttp` | 装到了系统 Python | 用 AstrBot 所在 venv 的 pip 重装 |
| 上传头像失败 | 图片超过 4 MB 请求上限 | 压缩到约 2 MB 以内 |
| Windows 时区报错 | 缺 `tzdata` | `pip install tzdata` |

## 十、升级与备份

1. **升级插件**：更新仓库代码 → 重启 AstrBot；数据库迁移在启动时自动执行，日志会打印当前/最新版本。
2. **升级 AstrBot**：本适配器依赖 4.29.x 的平台注册内部接口，升级大版本前先在测试环境验证；失败时日志会告警但不应影响 QQ 端。
3. **备份**：停机或低峰期复制 `data/plugin_data/`、`data/webroom/`、`data/config/`、`data/cmd_config.json`。
4. **回滚**：恢复上述目录 + 回退代码版本后重启；数据库迁移通常只向前，回滚前务必留备份。
