# 经济基准表

> **强制规则**：本表是修仙经济的底层锚点。今后任何影响灵石产出/消耗的改动（物品价格、材料、丹方、押镖、任务、秘境、灵田、拍卖、回收等），必须先依据本表核算，并同步更新本表；未按本表核算的经济改动不得提交。

## 基准定义

- 单位收入源：**押镖**，每趟 30 分钟。
- 全天基准：**48 趟/天**（自动代理全勤）。
- 镖银为**名义值**：不扣劫镖期望损失；劫镖是玩家间转移，不进入经济产出。
- 押镖附带修为（约白板闭关 1/3）不进入灵石基准。
- 境界等级 L0~L2 没有押镖，用历练最优路线金/时 × 24 过渡。

## 定价公式

```text
物品价格 = E(该物品适用境界) × 劳动天数系数 k
```

| 物品类型 | k（劳动天数） | 说明 |
| --- | ---: | --- |
| 武器 | 0.3 ~ 1.5 | 本境界主力装备约 1 天 |
| 防具/饰品 | 0.15 ~ 0.8 | 单件低于武器 |
| 突破丹 | 0.03 ~ 0.3 | 按成功率收益浮动 |
| 修为丹 | 0.01 ~ 0.1 | 按修为量/闭关效率折算 |
| 功能丹 | 0.01 ~ 0.1 | 按效果强度与持续时间 |
| 材料 | 0.005 ~ 0.05 | 按类别与品阶 |
| 符箓 | 0.02 ~ 0.3 | 按效果与持续时间 |
| 丹方卷轴 | 丹药价 × 10% | 学习成本 |

## 加成口径

- 押镖灵石：开镖时即结算 名义镖银 ×（1+称号灵石%）×（1+功法灵石收益）×（1+噬金鼠灵石收益），提示值与结算值一致（被劫后按剩余镖银发放）
- 押镖修为：开镖时即结算 基础酬劳 ×（1+称号修为%）×（1+功法修炼效率）
- 噬金鼠/功法灵石收益统一作用于：押镖、历练、秘境、悬赏、世界Boss、洞天灵田、签到/节日
- 以上加成属于玩家个体增益，不改变本表的名义镖银锚点

## 银行贷款口径（方案A）

- 可贷额度 = min(硬顶 1000 万, max(保底 10 万, 押镖日收入 E(L) × 0.5))
- 欠款身份线：🟡 0.5 天收入 / 🟠 1 天收入 / 🔴 老赖 2 天收入（低境界保底 1万/5万/10万）
- L0~L2 无押镖，用历练过渡收入（324/399/504/天）参与计算
- 逾期惩罚不变：掉落一个大境界

其他产出约束（后续按表补全）：任务/秘境/灵田等所有非押镖灵石产出的每日合计，应作为押镖基准的**比例**记录，避免总产出失控。

## 灵田等级扩展（v6.50.7）

- 等级上限 Lv.5 → **Lv.10**，格数 20 → **40**；Lv.5~Lv.9 升级费用 30 / 60 / 120 / 240 / 480 万，累计 **930 万灵石**。
- 肥力上限继续按 `max(100, 格数×20)`，Lv.10 为 800；满格一茬仍消耗上限 40%，施肥与收获口径不变。
- 以满级 40 格、幽冥草 12h/茬、种1收2、满肥计算，理论单茬 50 万、单日 100 万灵石；相较原 20 格新增 20 格，日增产约 50 万。升级费用相对渡劫/混元日基准收入（1,555~1,944 万）约 0.5 天，作为后期灵石回收项。

## 维护方式

- 镖银常量在 `managers/escort_manager.py`：`ESCORT_GOLD_BASE`、`ESCORT_REALM_MULTIPLIERS`。
- 修改常量后必须运行：

```text
python scripts/generate_economy_baseline.py
```

- 校验表与代码同步：

```text
python scripts/generate_economy_baseline.py --check
```

- 经济相关测试与 PR 提交前必须通过该校验。
