# 修仙人物属性公示表（玩家版）

> 适用版本：v6.35.1  
> 这份表用普通玩家能看懂的方式说明：面板属性从哪来、伤害怎么算、气血灵气怎么恢复。

---

## 先记住五句话

1. **面板主要看境界，不看你攒了多少修为。**
2. **职业决定你的攻防风格和物法比例。**
3. **装备加的是“境界基础的百分比”，不是固定攻击力。**
4. **面板攻击不等于每次伤害，实战还有随机、五行、暴击和减伤。**
5. **防御再高也不是无敌，最高减伤 75%，每次至少掉 1 点血。**

---

## 一、人物面板由哪些部分组成

| 面板属性 | 主要来源 |
| --- | --- |
| 气血上限 | 境界基础 |
| 灵气上限 | 职业初始、心法、丹药等 |
| 物攻 / 法攻 | 境界基础 + 装备百分比 + 永久属性 + 称号 |
| 物防 / 法防 | 境界基础 + 装备百分比 + 永久属性 + 称号 |
| 精神力 | 境界基础 + 装备/心法/永久属性 |
| 暴击、吸血、反伤、连击、闪避 | 功法、装备、称号、符箓等 |
| 战力 | 气血、攻击、防御、精神力综合计算 |

### 境界基础

每个境界都有一套固定基础属性。

- 境界越高，基础越高；
- 同一境界、同一职业，裸装基础相同；
- **当前攒了多少修为，不会直接提高战斗面板**；
- 修为主要用来突破境界。

### 职业风格

| 职业 | 特点 |
| --- | --- |
| 灵修 | 均衡，偏法术 |
| 体修 | 高防御、高气血，偏物理 |
| 剑修 | 高攻击，偏物理 |
| 魔修 | 高攻击，物法均衡 |
| 佛修 | 高防御，偏生存 |
| 鬼修 | 均衡，偏法术 |
| 御兽 | 均衡，配合灵兽 |

## 二、装备是怎么加成的

装备不是直接加固定攻击，而是：

```text
装备加成 = 你的境界基础 × 装备百分比
```

### 举个例子

你的基础物攻是 10,000，装备提供 20% 物伤：

```text
装备物攻 = 10,000 × 20% = 2,000
```

所以同一件装备，给高境界玩家的加成会更高。

### 装备品质

| 品质 | 效果 |
| --- | ---: |
| 一般 | 100% |
| 良好 | 105% |
| 极佳 | 110% |
| 大师 | 115% |

### 装备等级落后

装备需求境界比角色低得越多，效果越差：

```text
每落后 3 个境界，装备效果打 8 折
最低保留 20% 效果
```

### 装备上限

全身装备合计：

| 属性 | 最高 |
| --- | ---: |
| 物伤 / 法伤 | 各 40% |
| 物防 / 法防 | 各 35% |
| 精神力 | 30% |

同属性是**加法**，不是一件一件相乘。

## 三、最终攻击和防御

### 攻击

```text
物攻 = 境界物攻 × (1 + 攻击加成)
     + 装备物攻
     + 永久物攻
     + 称号物攻

法攻 = 境界法攻 × (1 + 攻击加成)
     + 装备法攻
     + 永久法攻
     + 称号法攻
```

攻击加成包括：

- 攻击修炼；
- 炼器；
- 丹药临时增伤；
- 传功攻击加成。

注意：

- 攻击加成主要放大**境界基础**；
- 不会把装备、永久、称号再乘一遍；
- 攻击总加成最高按 +50% 计算；
- 永久属性和称号攻击有折算上限，不会无限叠加。

### 防御

```text
物防 = 境界物防 × (1 + 防御加成)
     + 装备物防
     + 永久物防
     + 称号物防

法防 = 境界法防 × (1 + 防御加成)
     + 装备法防
     + 永久法防
     + 称号法防
```

防御加成会同时影响物防和法防。

## 四、战斗伤害怎么算

每次攻击分成两部分：

```text
物理伤害 + 法术伤害
```

两部分分别计算、分别减伤，最后相加。

### 伤害计算顺序

| 步骤 | 内容 |
| --- | --- |
| 1 | 用物攻、法攻作为基础 |
| 2 | 随机浮动 70%～130% |
| 3 | 计算五行克制 |
| 4 | 判定暴击、连击 |
| 5 | 按对方防御减伤 |
| 6 | 加上灵兽协战伤害 |

### 五行克制

```text
金克木，木克土，土克水，水克火，火克金
```

| 情况 | 伤害 |
| --- | ---: |
| 克制对方 | ×1.30 |
| 被对方克制 | ×0.80 |
| 无克制 | ×1.00 |

### 防御减伤

```text
防御越高，减伤越高
最高减伤 75%
每次攻击至少造成 1 点伤害
```

同境界正常配装，通常大约有 25%～40% 的减伤。

### 暴击

- 暴击率按百分比计算；
- 暴击伤害默认 150%；
- 暴击伤害最高 200%；
- 一次攻击只判定一次暴击，物法两部分同时暴击。

### 连击

- 触发后本次伤害 ×1.5；
- 物法两部分同时生效。

### 闪避

- 触发后本次攻击完全躲开；
- 常规最高 20%。

### 吸血和反伤

```text
吸血 = 最终伤害 × 吸血百分比
反伤 = 受到伤害 × 反伤百分比
```

常规上限：

| 属性 | 最高 |
| --- | ---: |
| 吸血 | 15% |
| 反伤 | 25% |

### 灵兽

- 主战灵兽和辅助灵兽都能协战；
- 多只灵兽一起攻击时，单只伤害会分摊；
- 防守方灵兽可以替主人挡伤害。

## 六、气血和灵气怎么恢复

恢复不是后台每秒跳数字，而是在你**下一条指令**时统一结算。

### 自然恢复

| 项目 | 数值 |
| --- | ---: |
| 时间 | 每 5 分钟 |
| 气血 | 最大气血的 1% |
| 灵气 | 最大灵气的 1% |

离线期间也会累计，上线后一次性结算。

### 调息恢复

```text
/调息
```

| 项目 | 数值 |
| --- | ---: |
| 时间 | 每分钟 |
| 气血 | 最大气血的 5% |
| 灵气 | 最大灵气的 5% |

气血和灵气都满了会自动结束调息。

### 恢复加成

以下来源可以提高恢复量：

- 宗门疗养殿；
- 洞府回春榻、聚灵池；
- 部分功法；
- 部分恢复装备。

### 受伤状态

当前气血低于最大气血的 **20%** 时，会进入受伤状态，部分行动会受限。

## 七、生活属性

普通功法会提供生活加成：

| 属性 | 作用 |
| --- | --- |
| 灵石收益 | 押镖、灵田等灵石收益提高 |
| 掉落几率 | 历练等掉落率提高 |
| 冷却缩减 | 决斗、切磋、押镖、团本、世界 Boss 冷却缩短 |
| 气运 | 气运相关判定提高 |
| 修炼效率 | 修炼获得的修为提高 |

注意：

```text
冷却缩减不是调息恢复
```

它只缩短行动冷却，不会让 `/调息` 回得更快。

---

## 八、战力怎么算

```text
战力 = 当前气血 ÷ 10
     + 总攻击
     + 总防御
     + 总精神力 ÷ 10
```

战力会随着当前气血变化，所以受伤时战力会降低。

## 九、常见问题

### 为什么修为很多，面板不涨？

因为现在是**境界主导**：

```text
战斗属性看境界等级，不看囤积修为
```

修为主要用于突破。

### 为什么装备显示的是百分比？

因为装备加的是：

```text
你的境界基础 × 装备百分比
```

所以高境界穿同一件装备，加成更高。

### 为什么面板攻击很高，打出来却不高？

因为实战还要经过：

- 70%～130% 随机浮动；
- 五行被克制；
- 对方防御减伤；
- 对方灵兽护主。

### 为什么防御很高还会掉血？

减伤最高 75%，而且每次攻击至少造成 1 点伤害。

### 为什么气血会变少？

- 战斗、Boss、奇遇等会正常扣血；
- 突破失败、黑市假货等也会扣血；
- 如果气血上限降低，当前气血会被压到新上限；
- 自动代理结算已经改为只更新奖励字段，不会再覆盖当前气血。

### 为什么灵气上限不是固定的？

灵气上限来自：

```text
职业初始 + 心法 + 丹药 + 其他加成
```

不是单纯按境界模板计算。

## 十、一句话总结

```text
看面板：境界 > 职业 > 装备百分比 > 功法/称号/丹药/灵兽
打架：攻击 → 随机 → 五行 → 暴击 → 防御减伤 → 灵兽
恢复：自然 5 分钟 1%，调息 1 分钟 5%
战力：气血/10 + 攻击 + 防御 + 精神力/10
```
