# 修仙人物属性公式表

> 适用版本：v6.35.1  
> 本文只列玩家实际看到的属性、战斗结算和恢复公式。  
> 所有结果按代码向下取整；随机浮动、暴击、连击、闪避按单次攻击判定。

---

## 一、境界基础

境界基础只由**境界等级**决定，不看你当前攒了多少修为。

| 属性 | 公式 | 说明 |
| --- | --- | --- |
| 境界尺度 `S` | `max(160, 155 + 突破成长累计 + 当前境界门槛 ÷ 10)` | 当前境界修为门槛越高，S 越大 |
| 基础攻击 `A` | `floor(S × 职业攻击系数)` | 由职业决定 |
| 基础物攻 | `floor(A × 职业物理占比)` | 物法双轨的物理基础 |
| 基础法攻 | `A − 基础物攻` | 物法双轨的法术基础 |
| 基础防御 `D` | `floor(S × 0.35 × 职业防御系数)` | 由职业决定 |
| 基础物防 | `floor(D ÷ 2)` | 同上 |
| 基础法防 | `D − 基础物防` | 同上 |
| 基础气血 | `S × 8` | 只由境界决定 |
| 气血上限 | `基础气血 × (1 + 传功气血%)` | 传功加成最多按 ±50% 计入 |
| 基础精神力 | `max(50, floor(S ÷ 5))` | 装备、心法、永久属性另加 |
| 灵气上限 | 当前 `max_spiritual_qi` | 来自职业初始、心法、丹药等，**不使用** `S × 10` 的境界模板 |

### 职业系数

| 职业 | 攻击系数 | 防御系数 | 物理占比 |
| --- | ---: | ---: | ---: |
| 灵修 | 1.00 | 1.00 | 20% |
| 体修 | 0.95 | 1.25 | 90% |
| 剑修 | 1.15 | 0.85 | 95% |
| 魔修 | 1.10 | 0.90 | 50% |
| 佛修 | 0.85 | 1.35 | 50% |
| 鬼修 | 1.00 | 0.90 | 20% |
| 御兽 | 0.95 | 1.00 | 50% |
| 未识别职业 | 1.00 | 1.00 | 20% |

## 二、装备百分比

装备不再提供固定攻防，而是提供**境界基础 × 百分比**。

| 项目 | 公式 |
| --- | --- |
| 单件装备有效率 | `配置百分比 × 品质倍率 × 境界效率` |
| 品质倍率 | 一般 1.00 / 良好 1.05 / 极佳 1.10 / 大师 1.15 |
| 境界效率 | `max(20%, 80% ^ floor(max(0, 玩家境界 − 装备需求境界) ÷ 3))` |
| 装备物攻 | `floor(基础物攻 × 装备物伤率合计)` |
| 装备法攻 | `floor(基础法攻 × 装备法伤率合计)` |
| 装备物防 | `floor(基础物防 × 装备物防率合计)` |
| 装备法防 | `floor(基础法防 × 装备法防率合计)` |
| 装备精神力 | `floor(基础精神力 × 装备精神力率合计)` |

### 装备率上限

| 属性 | 上限 |
| --- | ---: |
| 物伤率 | 40% |
| 法伤率 | 40% |
| 物防率 | 35% |
| 法防率 | 35% |
| 精神力率 | 30% |

补充：

- 同属性各部位**加算**，不是乘算。
- 装备上的“增伤”词条会并入对应物伤/法伤率，每件最多 +10%，最终仍受 40% 上限限制。
- 装备等级低于角色境界时，每落后 3 个境界索引效率 ×80%，最低保留 20%。

## 三、最终攻击与防御

### 攻击

```text
物攻 = floor(基础物攻 × (1 + 物攻加成))
     + 装备物攻
     + 永久物攻
     + 称号物攻

法攻 = floor(基础法攻 × (1 + 法攻加成))
     + 装备法攻
     + 永久法攻
     + 称号法攻

总攻击 = max(1, 物攻 + 法攻)
```

### 攻击加成

```text
物攻加成 = clamp(
    丹药物伤倍率 − 1
    + 传功攻击%
    + 攻击修炼等级 × 1%
    + 炼器等级 × 2%,
    −50%, +50%
)
```

- 攻击修炼最多 20 级，即最多 +20%。
- 炼器最多 15 级，即最多 +30%。
- 丹药临时物伤/法伤倍率最高 1.5，即最多 +50%。
- 传功攻击按传功信息计入。

### 永久属性折算

永久丹药、先天属性等原始物伤/法伤不会全额直接叠加，而是：

```text
永久攻击池 = min(
    基础总攻击 × 永久上限,
    玩家原始物伤 + 玩家原始法伤
)

永久上限 = 30% + 永久上限加成
```

`永久上限加成` 来自永久丹药数据，最高再 +50%，因此永久攻击池最高为基础总攻击的 80%。

永久攻击池再按基础物攻/法攻比例拆成永久物攻、永久法攻。

### 称号攻击

```text
称号攻击池 = min(
    基础总攻击 × 10%,
    称号物攻 + 称号法攻
)
```

再按基础物攻/法攻比例拆分。

### 防御

```text
物防 = floor(基础物防 × (1 + 防御加成))
     + 装备物防
     + 永久物防
     + 称号物防

法防 = floor(基础法防 × (1 + 防御加成))
     + 装备法防
     + 永久法防
     + 称号法防

总防御 = max(0, 物防 + 法防)
```

防御加成：

```text
防御加成 = clamp(
    max(物防丹药倍率, 法防丹药倍率) − 1
    + 炼器等级 × 2%,
    −50%, +50%
)
```

- 防御加成同时作用于物防和法防。
- 永久防御池、称号防御池与攻击一样，分别是基础总防御的 30% 和 10% 上限，再按基础物防/法防比例拆分。

## 四、战斗伤害

每次攻击分成物理、法术两轨，分别计算、分别减伤，最后相加。

```text
物伤 = 物攻 × 随机(0.70 ~ 1.30) × 五行系数 × 暴击倍率 × 连击倍率
法伤 = 法攻 × 随机(0.70 ~ 1.30) × 五行系数 × 暴击倍率 × 连击倍率
```

同一次攻击的物法两轨共用：

- 同一个 70%～130% 浮动系数；
- 同一次五行判定；
- 同一次暴击判定；
- 同一次连击判定。

### 五行系数

| 关系 | 倍率 |
| --- | ---: |
| 克制对方 | 1.30 |
| 被对方克制 | 0.80 |
| 无克制关系 | 1.00 |

五行相克：

```text
金克木，木克土，土克水，水克火，火克金
```

属性来自主修心法或武器；没有属性时不计算五行倍率。

### 减伤

物理伤害看物防，法术伤害看法防：

```text
减伤率 = min(75%, 防御 ÷ (防御 + 防守方境界尺度))
实际伤害 = max(1, floor(原始伤害 × (1 − 减伤率)))
```

- 境界尺度使用的是**防守方的境界尺度**，用于避免高境界防御在低境界数值下过度膨胀。
- 减伤率最高 75%。
- 即使防御极高，也会至少造成 1 点伤害。

### 暴击

```text
暴击率 = 基础暴击率 + 特效暴击率
暴击倍率 = 1.5 + 暴击伤害加成
```

- 单次攻击只判定一次暴击，物法两轨同时暴击。
- 暴击伤害常规上限为 200%。

### 连击

```text
连击触发后，物法两轨伤害 × 1.5
```

连击率受上限限制，常规全局上限 30%。

### 闪避

```text
闪避率 = 防守方闪避%
```

触发后本次攻击完全躲避，伤害为 0。  
常规全局闪避上限 20%。

### 吸血与反伤

```text
吸血量 = floor(最终伤害 × 吸血% ÷ 100)
反伤量 = floor(受到伤害 × 反伤% ÷ 100)
```

- 吸血常规上限 15%。
- 反伤常规上限 25%。

### 灵兽协战

- 主战灵兽和辅助灵兽每回合可追加攻击。
- 多只灵兽同时协战时，合击系数：

```text
1 ÷ (1 + 0.4 × (灵兽数量 − 1))
```

- 灵兽伤害同样按防守方物理防御减伤。
- 防守方灵兽可按 `guard_rate` 替主人承伤。

## 六、气血与灵气恢复

恢复采用“下一条指令时结算”，不是后台每秒跳数。

### 自然恢复

| 项目 | 数值 |
| --- | ---: |
| 结算间隔 | 每 300 秒 |
| 气血恢复 | 最大气血 × 1% × (1 + 自然气血恢复加成) |
| 灵气恢复 | 最大灵气 × 1% × (1 + 自然灵气恢复加成) |

### 调息

| 项目 | 数值 |
| --- | ---: |
| 结算间隔 | 每 60 秒 |
| 气血恢复 | 最大气血 × 5% × (1 + 调息气血恢复加成) |
| 灵气恢复 | 最大灵气 × 5% × (1 + 调息灵气恢复加成) |

- `/调息` 只结算完整分钟。
- 气血和灵气都满时自动结束调息。
- 受伤状态阈值：当前气血低于最大气血的 20%。

### 恢复加成来源

| 来源 | 效果 |
| --- | --- |
| 宗门疗养殿 | 每级：自然恢复 +10%，调息恢复 +5% |
| 洞府回春榻 | 自然气血 +15%，调息气血 +10% |
| 洞府聚灵池 | 自然灵气 +15%，调息灵气 +10% |
| 普通功法/装备 | 各自的自然/调息恢复词条 |

## 七、生活属性

普通功法提供生活加成：

| 属性 | 作用 | 上限 |
| --- | --- | ---: |
| 灵石收益 | 押镖、灵田等灵石收益 | 50% |
| 掉落几率 | 历练等掉落率 | 50% |
| 冷却缩减 | 决斗、切磋、押镖、团本、世界 Boss 冷却 | 35% |
| 气运 | 气运相关判定 | 50 |
| 修炼效率 | 修炼修为获取 | 80% |

> 冷却缩减**不影响** `/调息` 的恢复速度。  
> `/调息` 的恢复速度只由上面的调息恢复公式决定。

## 八、战力

```text
战力 = floor(
    当前气血 ÷ 10
    + 总攻击
    + 总防御
    + 总精神力 ÷ 10
)
```

其中总精神力包含：

```text
基础精神力
+ 装备精神力
+ 心法/功法精神力
+ 永久属性精神力
```

## 十、玩家常见问题

### 1. 为什么修为多了，面板不涨？

因为当前版本是**境界主导**：

```text
战斗属性看境界等级，不看当前囤积修为
```

修为主要用于突破境界。

### 2. 为什么装备面板是百分比？

装备主属性是：

```text
境界基础 × 装备百分比
```

所以同一件装备，在不同境界的角色身上加成不同。

### 3. 为什么实际伤害和面板攻击不一样？

因为实际伤害还要经过：

```text
70%～130% 浮动
五行克制
暴击/连击
对方防御减伤
灵兽协战
```

面板攻击只是基础值。

### 4. 为什么高防御也会掉血？

减伤率最高 75%，且每次攻击至少造成 1 点伤害。  
高防御不是无敌。
