> 数据时间：2026-10-31
> 测试对象：当前线上 18 级御兽玩家 `1610049038`
> 测试口径：当前线上基础系数，真实宠物数据；未计装备、丹药、符箓、功法。

## 二、模拟结果

### PvP

| 配置 | 平均胜率 |
| --- | ---: |
| 无宠 | 31.8% |
| 1宠 | 100.0% |
| 3宠 | 100.0% |
| 5宠 | 100.0% |

### PvE DPS

| 配置 | DPS |
| --- | ---: |
| 无宠 | 251,870 |
| 1宠 | 325,318 |
| 3宠 | 383,852 |
| 5宠 | 434,867 |

### 对比

- 无宠御兽在当前基础系数下偏弱：PvP 31.8%；
- 只带 1 只宠物就达到 100% PvP；
- 5 宠时 PvE DPS 比无宠高约 72.7%；
- 当前线上实际是五只高等级宠物，强度远高于正常职业区间。

## 三、为什么一只宠物就够了

当前御兽五宠配置里，单只太古青龙已经提供：

- 高额宠物 HP；
- 每回合协战伤害；
- 护主承伤；
- 多宠额外攻击加成和主人攻击加成。

即使只取第一只主战宠，PvP 也从 31.8% 直接变成 100%。

这不是“宠物数量多”才产生的问题，而是**第一只宠物的基础收益已经过高**。

## 四、获取成本

当前御兽：

```text
首次契约：免费
额外契约：100,000 灵石/只
```

实际五宠的额外契约费：

```text
4 × 100,000 = 400,000 灵石
```

纯金币喂养到 Lv.50 的上界：

```text
单只约 161,700,000 灵石
五只约 8 亿灵石（实际有修为共享，金币消耗会低很多）
```

当前玩家灵石：

```text
约 132 万
```

所以这五只 Lv.47～50 宠物主要不是靠金币喂养，而是靠：

- 灵兽经验共享；
- 历练/秘境/活动；
- 长期积累。

## 五、结论

### 当前线上御兽强度

```text
无宠：偏弱（31.8% PvP）
1宠：直接超模（100% PvP）
3宠/5宠：完全超模
```

### 成本判断

```text
额外契约 400,000 灵石
首宠免费
```

成本非常低，但收益已经是 PvP 100%。

**当前环境下，御兽不属于“需要高成本换高强度”的职业，而是低成本首宠就能产生断层强度。**

## 六、建议

当前版本不应继续用“增加获取成本”解决问题，因为：

- 首宠免费；
- 1宠已经 100%；
- 五宠只是更强，不是从弱变强的关键。

应优先处理：

1. 降低单只宠物的基础收益；
2. 多宠强递减或只让主战宠打完整伤害；
3. 给宠物总输出设置上限；
4. 再考虑契约/喂养成本；
5. 目标：

```text
御兽无宠：45%～50%
1宠：50%～55%
3宠：52%～57%
5宠：53%～58%
```
